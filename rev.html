More practice for MAL300 (reverse engineering and malware) and EXP400 (binary exploitation). The main guides are in ~/learn: malware analysis, reverse engineering, binary exploitation. These chapters add labs, one per technique.

# MAL300 Reverse engineering and malware (extra labs)

  • [----]dynamic analysis run it in a sandbox and read what it touched: files, registry, networkshell
  • [----]packers and unpacking entropy, stubs, the original entry point and how to tell a packed fileshell
  • [----]reading a check function x86 listing to source: recover the logic of a license checkshell

# EXP400 Binary exploitation (toy programs only)

  • [----]format strings when user input is the format: leaking the stack and why it is fixeddebug
  • [----]mitigations NX, stack canaries, ASLR, PIE and RELRO: what each stops and what it does notshell
  • [----]ROP concepts why return-oriented programming exists and how a defender spots itshell

progress: [####] = all levels read and the lab solved. Saved in your browser. Courses with quizzes and exams: ~/courses.

Everything here is a toy. The programs are made up, the samples are fictional text, and no chapter ships a working exploit, shellcode or malware. The point is to read what a defender sees: logs, disassembly, crash state and mitigations. Run real samples only in an isolated VM with no shared folders and no route to your network.
