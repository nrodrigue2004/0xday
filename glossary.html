An NTFS feature that lets a file carry hidden extra data streams. Sometimes abused to hide payloads.

Learning what normal looks like and flagging what does not fit. Finds the unusual, which is not always the malicious. see: ai: ml-intro

Removing identifying details so data can't be linked back to a person. Pseudonymization replaces them with codes that can be reversed with a key.
Anti-analysis malware
Tricks malware uses to avoid study: detecting VMs and debuggers, delaying, scrambling code.
Antivirus hardening
Software that detects and removes known malware, mostly by signature, with some behavior checks.
API web
A defined way for one program to ask another to do something, such as a web service that returns data when you send it a request. see: guide: rest-apis-and-spring-boot
API key access
A secret string that identifies and authorizes an application calling an API. Don't commit it to Git. see: web: api-security
APIPA network
The 169.254.x.x address Windows assigns itself when it can't reach a DHCP server. A sign DHCP is broken.
Application layer network
OSI layer 7: the protocols programs use directly, such as HTTP, DNS, SMTP and FTP. Not the app itself. see: basics: osi-and-tcpip
AppLocker hardening
Windows feature that restricts which programs can run.
APT threats
Advanced persistent threat: a well-resourced attacker, often state-linked, that stays inside a network for a long time. see: Security+ 2.1
ARM hardware
A CPU architecture common in phones, Macs and Raspberry Pis, known for low power use.

Address Resolution Protocol. Maps an IP address to a MAC address on the local network. ARP spoofing lies about that mapping. see: guide: computer-networks · man cmd

Sending fake ARP replies so traffic for one IP goes to the attacker's MAC; a local man-in-the-middle. see: guide: network-traffic-analysis
Array algorithms
A fixed-size, ordered collection of items accessed by index. see: guide: data-structures-and-algorithms
Artifact (forensics) dfir
A trace left by user or system activity that can be used as evidence: logs, prefetch, registry keys, browser history.
Artificial intelligence ai
Computer systems doing tasks that normally need human intelligence, such as understanding language or recognizing images. see: ai: how-ai-works
Artificial intelligence (AI) concepts
Software that does tasks we associate with human intelligence. Today it mostly means machine learning models, including language models. see: ai: how-ai-works
AS-REP roasting attacks
Asking for authentication data for accounts that don't require Kerberos pre-authentication, then cracking it offline. see: pentest/ad-attacks
ASCII data
American Standard Code for Information Interchange: the table that maps characters to numbers 0-127, one byte each ('A' is 65 or 0x41, 'a' is 97 or 0x61, '0' is 48 or 0x30). see: man numbers
ASLR hardening
Address space layout randomization: loads programs and libraries at random addresses so attackers can't predict where code is. see: rev/mitigations
Assembly language concepts
Human-readable machine instructions, one per CPU operation. Needed for reverse engineering and exploit work. see: guide: c-x86-assembly
Asset management governance
Keeping a current list of every device, application and data store you must protect. You can't protect what you don't know about. see: Security+ 4.2

Encryption with a key pair: a public key to encrypt or verify, a private key to decrypt or sign. Examples: RSA, ECC. see: guide: cryptography-applied · Security+ 1.4

Letting a program start a slow task, like a network call, and continue with other work until it finishes. see: guide: typescript-javascript
ATS career
Applicant tracking system: software that filters and ranks resumes. Plain formatting and matching keywords help. see: jobs
Attack surface concepts
Every place an attacker could try to get in: open ports, apps, accounts, people, vendors. see: Security+ 2.2
Attack vector threats
The path an attacker uses to get in, such as email, an exposed service, a USB drive or a supplier. see: Security+ 2.2
AUP governance
Acceptable use policy: what staff may and may not do with company systems and data. see: Security+ 5.1
Authentication access
Proving who you are (password, key, biometric). Compare authorization: what you may do once proven. see: Security+ 4.6
Authoritative DNS server network
The server that holds the real records for a domain and gives the final answer.

Deciding what an authenticated identity is allowed to do. see: Security+ 4.6 · drill: linux-permissions

Adding or removing servers automatically as demand changes. see: cloud/cloud-basics
Autopsy tools
A GUI forensics platform for examining disk images. see: guide: disk-forensics-autopsy-ftk-imager

The 'A' in the CIA triad: systems and data are there when needed. see: Security+ 1.2

Amazon's cloud platform and the largest. Core pieces: EC2 (servers), S3 (storage), IAM (permissions), VPC (networks).

AWS serverless functions: code that runs on demand without managing a server. Azure Functions is the Microsoft equivalent. see: cloud/aws-basics
Azure concepts
Microsoft's cloud platform. Entra ID (formerly Azure AD) handles identity.
Backdoor malware
A hidden way back into a system that bypasses normal login. see: guide: malware-analysis
Backup resilience
A separate copy of data for recovery. Test restores; a backup you have never restored is a guess.
Backup (3-2-1) resilience
Keep 3 copies of data, on 2 kinds of media, with 1 offsite or offline. Offline copies survive ransomware. see: Security+ 3.4
Bandwidth network
The maximum amount of data a link can carry per second. Latency is the delay; throughput is what you actually get.
Banner grabbing recon
Connecting to a service and reading its greeting to learn its software and version.
Base64 crypto
An encoding that turns bytes into text using 64 characters. It is not encryption.
Baseline hardening
The approved standard configuration of a system. Changes from it are detected as drift.
Bash linux
The most common Linux shell and its scripting language: pipes, loops and variables for automating work at the command line. see: guide: bash-scripting
Bastion host hardening
A hardened server exposed on purpose as the one way in to a private network. Also called a jump box.
bcrypt crypto
A deliberately slow password hashing function with a built-in salt. scrypt and Argon2 are similar.
Beacon malware
A small periodic check-in from malware to its C2 server asking for instructions.
Beaconing threats
A compromised host contacting its controller at regular intervals. The even rhythm is the giveaway. see: drill: read-a-packet-capture · guide: network-traffic-analysis
BGP network
The routing protocol of the internet: networks (autonomous systems) tell each other which IP ranges they can reach. A mistake or hijack can send traffic the wrong way. see: guide: computer-networks
BIA governance
Business impact analysis: working out which systems matter most, and what an outage costs per hour. see: Security+ 5.2 · Security+ 3.4
Bias and variance ai
Bias is error from a model that's too simple. Variance is error from a model too sensitive to the training data. see: ai: ml-evaluation
Big data data
Data too large or fast for ordinary tools, handled by distributed systems. see: dist/dist-fundamentals
Big O notation concepts
A way to describe how running time or memory grows as the input grows: O(n) grows in line with the input, O(n^2) much faster.
Binary concepts
Base 2: numbers written with only 0 and 1, where each place is worth double the one to its right (128 64 32 16 8 4 2 1 for a byte). see: man numbers
Binary search algorithms
Finding an item in a sorted list by repeatedly halving the search range. O(log n). see: guide: data-structures-and-algorithms
BIOS / UEFI concepts
The first code that runs at power-on, which starts the operating system. UEFI is the modern replacement for BIOS.
Bit and byte programming
A bit is a 0 or 1. A byte is 8 bits, enough for 256 values. see: basics/number-systems
BitLocker hardening
Microsoft's full disk encryption for Windows.
Bitwise operation concepts
An operation applied to each bit position separately: AND (both 1), OR (either 1), XOR (they differ), NOT (flip). AND with a mask is how a host finds its network address. see: man numbers
Blind SQL injection vulns
SQL injection where results aren't shown, so the attacker infers data from true/false responses or timing. see: web: injection-and-xss
Block cipher modes crypto
How a block cipher handles more than one block: ECB (insecure, leaks patterns), CBC, CTR and GCM (adds authentication). see: crypto/symmetric-modes
Blockchain concepts
A shared ledger where records are chained together with hashes so they're hard to change. Bitcoin uses it.
BloodHound tools
A tool that maps Active Directory relationships to find the shortest path to Domain Admin. see: pentest/ad-attacks
Blue team concepts
The defenders: monitoring, hardening, detection and response. see: Security+ 4.4
Bluetooth network
Short-range wireless for headphones, keyboards and similar devices. Old pairing methods and open discovery have led to attacks.
BM25 ai
A classic ranking formula for keyword search. It scores passages by how often query words appear, weighted by how rare they are. This site's chat uses it. see: ai: ai-chatbot
Boolean programming
A true or false value.
Boot process os
Power on, firmware (BIOS/UEFI) runs, the bootloader loads, the kernel starts, then services and the login screen.
Bootloader os
The small program that loads the operating system kernel. GRUB on Linux, Windows Boot Manager on Windows.
Botnet threats
A network of infected machines controlled remotely, used for DDoS, spam and credential stuffing. see: Security+ 2.4
Branch programming
A separate line of work in Git. You merge it back when ready. see: guide: git-github
Brand impersonation attacks
Pretending to be a well-known company in messages, sites or ads.
Bridge network
A device that joins two network segments at layer 2. A switch is a multi-port bridge.
Broadcast network
Traffic sent to every device on the local network, such as ARP requests and DHCP discovers.
Broken access control vulns
Users can do or see things they shouldn't, such as other people's data. Number one on the OWASP Top 10. see: web: access-control-and-ssrf
Browser web
The program that fetches and displays web pages, such as Chrome or Firefox. see: basics: how-web-apps-work
Brute force attacks
Trying every possible password or key. Rate limits, lockouts and MFA blunt it. see: guide: password-cracking-john · Security+ 2.4
Brute force attack attacks
Trying every possible value until one works. Slowed down by rate limits, lockouts and long passwords.
Buffer overflow vulns
Writing past the end of a memory buffer so you can overwrite adjacent data, including a return address. see: guide: binary-exploitation · guide: c-x86-assembly
Bug bounty concepts
A company's public offer to pay people who find and responsibly report security flaws, within a stated scope. HackerOne and Bugcrowd host many. See the bug bounty chapter for how to start safely. see: web: bug-bounty
Burp Suite tools
An intercepting proxy for testing web apps: it sits between browser and site so you can read, edit and replay requests. see: web: burp-workflow
Business continuity resilience
Planning so key operations keep running through a disruption. see: Security+ 3.4
Business email compromise (BEC) attacks
A scam where an attacker poses as an executive or vendor by email to get a payment or data. Often no malware at all.
BYOD it
Bring your own device: staff use personal phones and laptops for work. MDM software enforces rules on them.
Bytecode programming
An intermediate code that a virtual machine runs, such as Java bytecode on the JVM. see: guide: java
C programming
A fast, low-level language with manual memory management. Operating systems and many exploits are written in it. see: guide: c-x86-assembly
C# programming
Microsoft's object-oriented language for .NET, used for Windows software and games.
C++ programming
C with classes, templates and a large standard library.
C2 (command and control) threats
The infrastructure an attacker uses to send commands to compromised machines and receive data back. see: drill: read-a-packet-capture
CA (certificate authority) crypto
A trusted organization that signs digital certificates, vouching that a public key belongs to a named site. see: Security+ 1.4
Cache concepts
A fast, temporary copy of data kept close to where it is used so repeated requests are quicker.
Callback programming
A function passed to another function to be called later, often when something finishes. see: guide: typescript-javascript
Capture the flag (CTF) concepts
A security game: you attack deliberately vulnerable targets or solve puzzles to find hidden flag strings. Good practice and sometimes a hiring signal.
CASB cloud
Cloud access security broker: sits between users and cloud services to enforce security policy.
Cat6 and Ethernet cable hardware
Twisted-pair copper cabling with RJ-45 plugs. Cat5e handles 1 Gbps, Cat6 up to 10 Gbps over short runs. Max run is 100 m. see: comptia/netplus
CCNA career
Cisco Certified Network Associate: a networking certification with hands-on routing and switching.
CCPA governance
California Consumer Privacy Act: gives California residents rights over their personal data. see: grc/privacy-law
CDN (content delivery network) network
A network of servers around the world that cache a site's static files close to users, making pages faster and absorbing traffic floods. Cloudflare and Akamai are examples.
CEH career
Certified Ethical Hacker: an EC-Council certification on attack tools and techniques.
Certificate crypto
A signed document tying a public key to a name, such as a website. Your browser trusts it if a trusted CA signed it. see: guide: cryptography-applied
Certificate pinning crypto
An app accepting only a specific known certificate or key, to block fake certificates.
ChaCha20 crypto
A modern stream cipher, fast on devices without AES hardware. Used with Poly1305 in TLS and WireGuard.
Chain of custody dfir
The record of who handled evidence and when, proving it wasn't altered. see: guide: digital-forensics
Change management governance
The process for approving, testing and recording changes so they don't break systems or open holes. see: Security+ 1.3
Chatbot ai
A program that talks with users in text or voice. Some are rule-based and some use language models. see: ai: ai-chatbot
chmod linux
Linux command that changes file permissions, for example chmod 640 file or chmod +x script.sh. see: drill: linux-permissions
chown linux
Linux command that changes a file's owner and group. see: drill: linux-permissions
CI/CD tools
Automation that builds and tests every code change (continuous integration) and ships it to production (continuous delivery). A compromised pipeline is a supply chain risk.
CIA triad concepts
Confidentiality, Integrity, Availability: the three goals security protects. see: Security+ 1.2
CIDR network
Classless Inter-Domain Routing notation, like 10.0.5.0/24: an address plus how many bits are the network part. see: guide: networking-tcp-ip-dhcp-nat-subnets
Cipher crypto
An algorithm that encrypts and decrypts. see: guide: cryptography-applied
CIS Benchmarks hardening
Free configuration guides from the Center for Internet Security for hardening operating systems and apps. see: guide: system-hardening-windows-linux
CISO career
Chief information security officer: the executive responsible for an organization's security.
CISSP career
A senior-level security management certification that requires years of experience.
Class programming
A blueprint for objects: it defines their data and behavior. see: guide: object-oriented-programming-java
Classification ai
Predicting a category, such as spam or not spam. see: ai: ml-classifiers
Cleartext crypto
Data sent or stored without encryption. FTP, Telnet and HTTP are cleartext protocols. see: guide: network-traffic-analysis
CLI and GUI programming
A CLI is a text command-line interface. A GUI is a graphical one with windows and buttons.
Clickjacking web
Tricking someone into clicking something hidden under what they think they're clicking, by layering a transparent frame. see: web: owasp-top-10
Client it
The device or program that asks a server for something, such as a browser or email app.
Client-server network
A design where clients request things and a central server provides them.
Clock speed hardware
How many cycles per second a CPU runs, in GHz.
Cloud cloud
Computing resources rented over the internet instead of owned on site: servers, storage, databases and apps. see: cloud/cloud-basics
Cloud computing concepts
Renting computing (servers, storage, databases) from a provider such as AWS, Azure or Google Cloud instead of owning hardware. You pay for what you use.
CloudTrail cloud
The AWS log of API calls and account activity. Critical for investigating cloud incidents. see: cloud/cloud-security
Clustering resilience
Several servers working together so one can take over when another fails. see: Security+ 3.4
CMMC governance
Cybersecurity Maturity Model Certification: the US DoD's requirement for contractors that handle sensitive government data.
CMOS battery hardware
The small coin battery that keeps the motherboard's clock and BIOS settings. A dead one resets the time. see: guide: hardware-diagnostics-and-repair
CNAME network
A DNS record that makes one name an alias for another name.
Cobalt Strike tools
A commercial adversary simulation tool whose Beacon payload is widely used by red teams and criminals alike.
Code injection attacks
Getting a program to run attacker-supplied code. SQL injection, command injection and DLL injection are kinds of it.
Collision domain network
A network segment where two devices sending at once cause a collision. Each switch port is its own domain; a hub is one shared domain.
Command injection vulns
An attacker's input is passed to a system shell and runs as a command on the server.
Commit programming
A saved snapshot of changes in Git with a message. see: guide: git-github
Compensating control governance
An alternative control used when the normal one isn't possible, such as network isolation for an unpatchable system. see: Security+ 1.1
Compiler concepts
A program that translates source code into machine code (or bytecode) that a computer can run.
Compliance governance
Meeting a rule set such as PCI DSS, HIPAA or GDPR, with evidence to show it.
Computer hardware
A machine that follows instructions to process data, built from a CPU, memory, storage and input and output. see: guide: operating-systems
Computer vision ai
AI that works with images and video. see: ai: ml-intro
Concurrency programming
Making progress on several tasks at once, whether by interleaving or true parallelism.
Confusion matrix concepts
A table counting a classifier's four outcomes: true positives, false positives, false negatives, true negatives. Precision and recall come from it. see: ai: ml-evaluation
Container virtualization
An isolated process (or group of processes) with its own filesystem view, network and limits, sharing the host kernel. Starts in seconds and uses less memory than a virtual machine, but isolation is weaker. see: guide: virtualization-proxmox
Container image cloud
A packaged, read-only template for a container, with app and dependencies. see: guide: virtualization-proxmox
Containment dfir
Limiting the spread of an incident, for instance by isolating a host or disabling an account. see: guide: incident-response
Context window ai
The maximum amount of text a model can consider at once. see: ai: pe-basics
Cookie web
A small value the server asks the browser to store and send back on every request. Session cookies carry the login. The Secure, HttpOnly and SameSite flags limit where they travel and who can read them. see: man http
Cookie flags web
HttpOnly hides a cookie from JavaScript. Secure sends it only over HTTPS. SameSite limits sending it on cross-site requests. see: web: auth-and-sessions
Core hardware
One processing unit inside a CPU. More cores mean more tasks at once.
Correlation soc
Linking events from different sources to spot a pattern, such as a failed login on one system followed by a success on another. see: guide: siem-security-onion
CORS web
Cross-origin resource sharing: how a server lets other origins read its responses in the browser. A browser rule, not a substitute for authentication. see: man http
CPU concepts
The chip that runs program instructions.
Credential harvesting attacks
Collecting usernames and passwords, for instance through fake login pages.
Credential stuffing attacks
Replaying username and password pairs from old breaches against other sites, betting on reuse.
Cron linux
The Linux scheduler. Cron entries that run as root are a favorite privilege-escalation path when the script is writable. see: drill: linux-permissions · guide: linux-server-admin-ubuntu

Injecting script into a page that other users then run in their browser. Stored, reflected and DOM-based are the main kinds. see: Security+ 2.3
Cryptanalysis crypto
Studying ways to break ciphers without having the key. see: crypto/crypto-attacks
Cryptography crypto
The science of protecting information with math: encryption, hashing, signatures and key exchange. see: basics: cia-and-crypto

Secretly using someone's computer or cloud account to mine cryptocurrency.
CSP web
Content Security Policy: a header telling the browser which sources of scripts and content are allowed. It limits XSS. see: web: injection-and-xss
CSPM cloud
Cloud security posture management: tools that find misconfigurations in cloud accounts. see: cloud/cloud-security
CSR crypto
Certificate signing request: what you send a CA to get a certificate. It contains your public key and name. see: crypto/tls-pki
CSRF vulns
Cross-site request forgery: tricking a logged-in user's browser into sending a request they did not intend. see: Security+ 2.3
CSS web
Cascading Style Sheets: the language that styles web pages.
CSV programming
Comma-separated values: a plain text table format.
CVE vulns
Common Vulnerabilities and Exposures: a public ID such as CVE-2021-44228 for one known vulnerability. see: Security+ 4.3
CVSS vulns
Common Vulnerability Scoring System: a 0 to 10 severity score for a vulnerability. Severity is not the same as your risk. see: Security+ 4.3
CWE vulns
Common Weakness Enumeration: a list of types of software weaknesses, such as CWE-79 for XSS. CVE is a specific instance. see: Security+ 4.3
Cyberattack attacks
An attempt to damage, disrupt or gain access to computer systems or data.
Cybersecurity concepts
Protecting computers, networks and data from attack, damage and unauthorized access. see: start
CySA+ career
CompTIA Cybersecurity Analyst: a defensive certification on analysis, detection and response. see: comptia/cysa
Dark web concepts
Parts of the internet reachable only with special software such as Tor. Not the same as the deep web (anything not indexed).
Data data
Raw facts and figures a computer stores and processes. Information is data with meaning.
Data breach data
Unauthorized access to or disclosure of data, whether by an attack or a mistake.
Data classification governance
Labeling data by sensitivity (public, internal, confidential, restricted) so it gets the right protection. see: Security+ 3.3
Data egress cloud
Data leaving a cloud provider's network, which is usually charged for.
Data link layer network
OSI layer 2: moves frames between devices on the same network using MAC addresses. Switches and Wi-Fi work here. ARP and VLANs relate to it. see: basics: osi-and-tcpip
Data masking hardening
Hiding sensitive parts of data, like showing only the last four digits of a card number. see: Security+ 3.3
Data owner and custodian governance
The owner decides how data is classified and used. The custodian looks after it technically. see: Security+ 5.1
Data poisoning ai
Corrupting training data so a model learns wrong or backdoored behavior. see: ai: attacking-ai
Data retention governance
Rules for how long data is kept before it is deleted. see: Security+ 5.1
Data sovereignty governance
The rule that data is subject to the laws of the country where it is stored. see: Security+ 3.3
Data structure concepts
A way to organize data in memory for certain operations: arrays, hash tables, trees, graphs. see: guide: data-structures-and-algorithms
Data warehouse data
A large database built for analysis and reporting across many sources. A data lake holds raw data in its original form.
Database data
An organized store of data that programs query. Relational databases use tables and SQL; NoSQL stores use other shapes such as documents. see: guide: databases-and-sql
DBMS database
Database management system: the software that stores, serves and secures a database.
DCSync attacks
Pretending to be a domain controller to ask for password hashes through directory replication. see: pentest/ad-attacks
DDoS attacks
Distributed denial of service: many machines flood a target so real users cannot reach it. see: Security+ 2.4
Deadlock os
Two or more processes each waiting for something the other holds, so none can continue.
Deauthentication attack attacks
Sending forged Wi-Fi management frames that kick clients off a network, often to capture the handshake when they reconnect.
Debugger tools
A tool that runs a program step by step, with breakpoints and memory inspection. gdb, x64dbg and WinDbg are examples. see: guide: ghidra-and-ida-pro
Deep web threats
The part of the web not indexed by search engines, such as your email or bank account pages. Not the same as the dark web.
Deepfake threats
Audio, video or images made or altered by AI to look real. Used in fraud and impersonation. see: ai: ai-for-attackers
Default gateway network
The router a device sends traffic to when the destination is outside its own subnet. see: guide: networking-tcp-ip-dhcp-nat-subnets
Defense in depth concepts
Layering controls so no single failure lets an attacker through. see: Security+ 1.2 · Security+ 3.2
Denial of service (DoS) attacks
Making a service unavailable by overwhelming it or crashing it. A DDoS uses many machines.
DEP hardening
Data execution prevention (NX): marks memory like the stack as non-executable so injected code can't run there. see: rev/mitigations
Dependency programming
A library or package your code needs. Vulnerable dependencies are a major risk. see: sdl/dependency-scanning
DES and 3DES crypto
Old symmetric block ciphers. DES (56-bit) is broken; 3DES is deprecated. AES replaced them. see: crypto/symmetric-modes
Deserialization vulns
Turning received data back into objects. Untrusted data can run attacker code if the format allows it.
Design pattern programming
A reusable solution to a common design problem, such as Singleton, Factory or Observer. see: cs/patterns
Detection engineering soc
Designing, testing and tuning the rules that detect attacks. see: detect/sigma-rules
Device Manager windows
The Windows tool listing hardware and drivers. A yellow warning icon marks a device with a problem. see: guide: windows-deployment-and-drivers
DevOps concepts
A way of working that joins development and operations: automate building, testing and deploying so releases are small and frequent.
DevSecOps concepts
Building security checks into the DevOps pipeline so they run on every change. see: cs/cicd
DHCP network
Dynamic Host Configuration Protocol: hands out IP address, gateway and DNS to devices when they join. see: guide: networking-tcp-ip-dhcp-nat-subnets
DHCP lease network
The time a client may keep the IP address a DHCP server gave it before renewing.
Dictionary algorithms
A collection of key-value pairs with fast lookup by key. Also called a map or hash map. see: guide: data-structures-and-algorithms
Dictionary attack attacks
Trying passwords from a word list instead of every combination. see: guide: password-cracking-john
Diffie-Hellman crypto
A key exchange method that lets two sides create a shared secret over an open channel. Used in TLS and VPNs. see: crypto/public-key
Digital footprint privacy
The trail of data you leave online: accounts, posts, searches, tracking.
Digital forensics dfir

Service account access
An account used by a program or service, not a person. Often over-privileged and rarely rotated.
Session web
The server's memory of a logged-in user between HTTP requests, found by a random id in a cookie or a signed token. Stealing the id is the same as stealing the login. see: man http
Session fixation web
Making a victim use a session ID the attacker already knows, then taking over that session after login. see: web: auth-and-sessions
Session hijacking attacks
Stealing a valid session cookie or token to act as the logged-in user without knowing the password.
Session layer network
OSI layer 5: starts, manages and ends conversations between applications, including checkpoints and reconnection. see: basics: osi-and-tcpip
SFTP network
File transfer over SSH, port 22. Not the same as FTPS (FTP inside TLS). see: Security+ pairs
Shadow IT governance
Technology that staff use without approval from IT, which no one is securing.
Sharding database
Splitting a large database across several servers by key. see: dist/dist-replication
Shared responsibility model governance
In the cloud the provider secures the infrastructure and you secure what you put on it: your data, accounts, configuration and access.
Shell linux
A program that reads typed commands and runs them. Bash, zsh and PowerShell are shells; the terminal is the window that hosts one. see: guide: linux-command-line
Shell script linux
A text file of shell commands run as a program. see: guide: bash-scripting
Shellcode attacks
A small piece of machine code injected into a process, usually to open a shell. see: guide: binary-exploitation
Shoulder surfing attacks
Watching someone enter a password or read their screen.
SID windows
Security identifier: the unique ID Windows assigns to a user, group or computer.
Side-channel attack attacks
Learning secrets from physical effects like timing, power use or cache behavior instead of attacking the algorithm.
SIEM soc
Security information and event management: collects logs from everywhere and correlates them into alerts. Splunk, Elastic, Wazuh and Security Onion are examples. see: guide: siem-security-onion · man splunk · Security+ 4.4
Sigma soc
A vendor-neutral format for writing detection rules that convert to many SIEM languages. see: Security+ 4.4
Single sign-on (SSO) access
Logging in once to reach many apps, handled by a central identity provider (SAML, OpenID Connect).
SLA governance
An agreement that states what service level to expect, such as 99.9 percent uptime or a four-hour response.
SMB network
Server Message Block: the Windows file and printer sharing protocol, port 445. Attacked by relay and EternalBlue-style bugs.
Smishing / vishing attacks
Phishing by text message (smishing) or by phone call (vishing).
SMTP email
The protocol that sends email between servers, port 25, and from clients on 587 or 465.
Smurf attack attacks
A DDoS that sends ICMP echo requests with a spoofed source to a broadcast address so many hosts flood the victim.
Snapshot virtualization
A saved point-in-time state of a VM or disk that you can roll back to. Not a replacement for backups. see: guide: virtualization-proxmox
Sniffing attacks
Capturing traffic passing on a network to read it. Works on unencrypted protocols and on shared or mirrored links.
SNMP network
Simple Network Management Protocol: lets tools read status from routers, switches and printers. Use v3; v1 and v2c send community strings in cleartext.
Snort tools
An open source network intrusion detection and prevention system with signature rules. see: guide: ids-snort
SOAR soc
Security orchestration, automation and response: playbooks that automate repetitive SOC steps. see: Security+ 4.7
SOC soc
Security operations center: the team that monitors alerts and responds to incidents. see: guide: siem-security-onion · Security+ 4.4
SOC 2 governance
An audit report on a service provider's controls for security, availability, confidentiality, processing integrity and privacy. see: grc/audits-and-compliance
SOC analyst career
Watches alerts and logs, triages possible incidents and escalates real ones. A common first security job. see: careers/soc-analyst
Social engineering attacks
Manipulating people rather than machines: pretexting, phishing, tailgating, vishing. see: Security+ 2.2
Socket network
One endpoint of a network connection: an IP address plus a port.
Software it
Programs and data that tell hardware what to do, as opposed to the physical hardware itself.
Software composition analysis sdl
Scanning your dependencies for known vulnerabilities. see: sdl/dependency-scanning
Sorting algorithm algorithms
A method of putting items in order: bubble sort and insertion sort are simple but slow; merge sort and quicksort are O(n log n). see: cs/sorting
Source code programming
The human-readable text of a program, before it is compiled or run.
SOX governance
Sarbanes-Oxley Act: US law requiring accurate financial reporting and controls at public companies. see: grc/privacy-law
Spaced repetition study
A study method that reviews flashcards at growing intervals, right as you are about to forget. Anki uses it.
Spam email
Unwanted bulk email, often carrying scams or malware.
Spanning Tree Protocol network
STP: switches use it to block redundant links so loops don't flood the network.
Spear phishing attacks
Phishing aimed at a specific person, using details about them to look real.
Spectre and Meltdown vulns
CPU flaws from speculative execution that let a program read memory it shouldn't. Fixed partly in hardware, partly in software.
SPF email
Sender Policy Framework: a DNS record listing which servers may send mail for a domain. see: guide: phishing-analysis
SPL tools
Search Processing Language, the query language of Splunk. see: man splunk
Split tunnel network
A VPN setting where only traffic for the company network goes through the tunnel; the rest goes straight to the internet. A full tunnel sends everything through the VPN. see: basics: vpns-and-tunnels
Splunk tools
A SIEM and log search platform. Queries are written in SPL. see: man splunk
Spoofing attacks
Pretending to be something else: a forged sender address, IP address, MAC address or website.
Spyware malware
Malware that secretly gathers information about a user and sends it out.
SQL data
The language for asking relational databases for data (SELECT), changing it (INSERT, UPDATE) and defining it. see: guide: sql
SQL injection vulns
Putting SQL into an input so the database runs it. Fixed with parameterized queries. see: guide: databases-and-sql · Security+ 2.3
SQLite database
A small database stored in a single file, used inside apps and phones.
sqlmap tools
An automatic SQL injection testing and exploitation tool.
SSD / HDD concepts
Storage devices. An SSD uses flash memory with no moving parts and is much faster than a hard disk drive.
SSH network
Secure Shell: encrypted remote login and file transfer on port 22. Use keys, not passwords. see: guide: linux-server-admin-ubuntu · man linux
SSH key access
A key pair used to log in over SSH without a password. The private key stays with you; the public key goes in ~/.ssh/authorized_keys on the server. see: guide: kali-linux
SSID network
The name of a Wi-Fi network that you see in the list.
SSL stripping attacks
Downgrading a victim's HTTPS connection to HTTP through a man-in-the-middle position. HSTS prevents it.
SSL VPN network
A VPN that runs over TLS (port 443), usually from a browser or small client. Easy to get through firewalls. see: basics: vpns-and-tunnels
SSL/TLS handshake crypto
The opening exchange where client and server agree on keys and the server proves its identity. see: drill: read-a-packet-capture
SSRF web
Server-side request forgery: tricking a server into fetching a URL of the attacker's choice, such as internal services or cloud metadata. Fix with destination allow-lists and egress filtering. see: man http
SSTI vulns
Server-side template injection: user input gets evaluated by the server's template engine, often leading to RCE.
Stack (data structure) algorithms
A last-in, first-out collection: push on top, pop from top. see: guide: data-structures-and-algorithms
Stack and heap concepts
Two regions of program memory. The stack holds function calls and local variables; the heap holds data allocated while running. Overflow bugs target both. see: guide: binary-exploitation
Stack canary hardening
A secret value placed before the return address; if a buffer overflow changes it, the program stops. see: rev/mitigations
Stack overflow vulns
Running out of call stack memory, usually from endless recursion. Not the same as a stack buffer overflow.
Stateful firewall network
A firewall that tracks connections, so it allows replies to traffic you started and blocks unsolicited traffic. see: guide: firewalls-pfsense
Static analysis malware
Examining a file without running it: strings, headers, imports, disassembly. see: guide: malware-analysis
Static and dynamic typing programming
Static typing checks types before running (Java, C). Dynamic typing checks them while running (Python, JavaScript). see: langs/types
Static routing network
Routes entered by hand. Dynamic routing protocols such as OSPF and BGP learn them automatically.
stdin, stdout and stderr linux
The three standard streams of a program: input, normal output and error output. Redirection with >, >> and 2> changes where they go.
Steganography crypto
Hiding a message inside another file, such as an image, so no one suspects it exists.
STIG hardening
Security Technical Implementation Guide: detailed hardening checklists published by the US DoD.
STIX and TAXII soc
STIX is a format for describing threat intelligence. TAXII is the protocol for sharing it.
Stored procedure database
SQL code saved in the database and run by name.
Stored, reflected and DOM XSS vulns
Stored: the script is saved on the server. Reflected: it comes back from a request. DOM: it runs from client-side code. see: web: injection-and-xss
STRIDE concepts
A threat modeling checklist: Spoofing, Tampering, Repudiation, Information disclosure, Denial of service, Elevation of privilege. see: sdl/threat-modeling
Strings tools
Pulling readable text out of a binary. Often the quickest hint about what a program does. see: guide: malware-analysis
Subdomain web
A name under a domain, such as mail.example.com. Forgotten subdomains are common weak spots. see: guide: recon-nmap-metasploit
Subdomain takeover vulns
Claiming a forgotten external service that a DNS record still points to, so you control that subdomain.
Subnet network
A slice of an IP network, defined by a mask. Hosts in the same subnet talk directly. see: guide: networking-tcp-ip-dhcp-nat-subnets
Subnet mask network
A value like 255.255.255.0 that says which part of an IP address is the network and which is the host. /24 is the same thing. see: guide: networking-tcp-ip-dhcp-nat-subnets
sudo linux
Runs a single command as root (or another user) after your password, according to /etc/sudoers. see: man linux
SUID linux
A permission bit that makes a program run as its owner. A root-owned SUID program with a flaw is a path to root. see: drill: linux-permissions · man linux
Supervised learning ai
Learning from examples that come with the correct answer. see: ai: ml-intro
Supply chain attack threats
Compromising a vendor or software dependency to reach its customers. see: Security+ 2.2 · Security+ 5.3
Swap linux
Disk space used as overflow when RAM is full. Windows calls it the page file.
Switch network
A device that connects hosts on one LAN and forwards frames to the right port using MAC addresses. see: guide: networking-tcp-ip-dhcp-nat-subnets
Symmetric encryption crypto
One shared key encrypts and decrypts. Fast; the hard part is sharing the key. see: guide: cryptography-applied
SYN flood attacks
A DoS attack that sends many TCP SYNs and never finishes the handshake, filling the server's connection table.
Syntax and semantics programming
Syntax is the grammar of code. Semantics is what the code means. see: langs/parser
Syslog soc
A standard for sending log messages over the network to a central collector. see: guide: log-analysis
Sysmon windows
A Windows Sysinternals service that logs detailed process, network and file events to the event log. see: man windows-ir · guide: log-analysis
System call os
The way a program asks the kernel to do something, such as open a file or create a process.
systemd linux
The init system on most modern Linux distros. It starts services and is controlled with systemctl. see: guide: linux-server-admin-ubuntu
Systems administrator career
Keeps servers, accounts and updates working. see: careers/sysadmin
Table, row and column database
A table stores records. A row is one record; a column is one field of it. see: basics: relational-databases
Tabletop exercise resilience
A talk-through of an incident scenario with the response team, with no systems touched. see: Security+ 4.8
Tailgating attacks
Following an authorized person through a secured door without using your own credentials. see: Security+ 2.2
Tailscale network
A mesh VPN built on WireGuard that makes devices reachable by private address with almost no setup. see: guide: vpn-tailscale
Task Manager windows
The Windows tool that lists processes and resource use. Ctrl+Shift+Esc opens it.
TCP network
Transmission Control Protocol: reliable, ordered delivery with a three-way handshake. see: drill: read-a-packet-capture · guide: computer-networks
TCP/IP model network
The four-layer practical model of the internet: link, internet, transport and application. The OSI model has seven. see: basics: osi-and-tcpip
Telnet network
An old remote shell protocol on port 23 that sends everything, including passwords, in cleartext. Replaced by SSH. see: Security+ pairs
Temperature ai
A setting that controls randomness in a model's output. Low is predictable; high is varied. see: ai: pe-basics
Terminal linux
The window where you type commands. The shell is the program inside it that interprets them.
Terraform cloud
A tool for defining cloud infrastructure in code and creating it automatically. Ansible automates configuring servers.
TFTP network
Trivial FTP: a bare-bones file transfer over UDP port 69 with no authentication. Used to boot and configure network gear.
Thermal paste hardware
A compound between CPU and cooler that moves heat across tiny gaps. Old or missing paste causes overheating. see: guide: hardware-diagnostics-and-repair
Third-party risk governance
The risk that comes from vendors and suppliers with access to your data or systems. see: Security+ 5.3
Thread concepts
A line of execution inside a process. Threads in one process share memory, which makes them quick and also easy to get wrong (race conditions). see: guide: operating-systems
Threat threats
Anything that could cause harm to systems or data, such as an attacker, malware, or a natural disaster. see: Security+ 2.1
Threat actor threats
Anyone or any group behind an attack: criminals, nation-states, hacktivists, insiders.
Threat hunting soc
Proactively searching a network for attackers who got past automated alerts, starting from a hypothesis.
Threat intelligence soc
Information about attackers and their methods that you use to prioritize defenses. see: Security+ 2.1
Threat modeling concepts
Thinking through what can go wrong with a system before building it, to design defenses. see: sdl/threat-modeling
Three-way handshake network
SYN, SYN-ACK, ACK: how TCP opens a connection. see: drill: read-a-packet-capture
Ticketing system it
Software that tracks each support request from open to resolved.
Tier 1 / Tier 2 analyst soc
Tier 1 triages incoming alerts; tier 2 investigates the real incidents more deeply.
Time complexity algorithms
How the running time of an algorithm grows with input size, written in Big O. see: cs/analysis
Timeline analysis dfir
Putting events from many sources in time order to reconstruct what happened.
TLD network
Top-level domain: the last part of a domain name, such as .com, .org or .edu.
Token ai
A chunk of text, often a word or part of a word, that a language model reads and writes. see: ai: how-ai-works
Tokenization data
Replacing sensitive data (a card number) with a meaningless token and keeping the real value elsewhere. see: Security+ 3.3
Tor network
A network that relays traffic through several volunteer nodes so the destination cannot see who you are. Used for privacy; also used to reach the dark web.
TPM hardware
Trusted Platform Module: a chip that stores keys and checks that boot software hasn't been tampered with. BitLocker and Windows 11 use it.
Traceroute network
A tool that shows each router (hop) along the path to a destination, to find where traffic slows or stops. see: guide: computer-networks
Training data ai
The examples a model learns from. Test data is held back to check it on unseen examples. see: ai: ml-intro
Transaction database
A group of database operations that all succeed or all fail together. see: guide: databases-and-sql
Transformer ai
The neural network design behind modern language models, built around attention. see: ai: how-ai-works
Transport layer network
OSI layer 4: delivers data between applications using ports. TCP gives reliable, ordered delivery; UDP is fast and connectionless. Firewalls often filter here. see: basics: osi-and-tcpip
Tree algorithms
A hierarchical data structure of nodes with one parent each. A binary tree has at most two children per node. see: cs/trees
Triage soc
Quickly judging an alert: is it real, how severe, who needs to act? see: careers/soc-analyst
Trojan malware
Malware pretending to be something useful. see: guide: malware-analysis
True positive soc
An alert that fired correctly because something bad really happened.
Trunk port network
A switch port that carries traffic for many VLANs, tagged with 802.1Q.
TryHackMe career
A site of guided hands-on cybersecurity rooms in the browser. A good place to start practicing. see: resources
TTL network
Time to live: a counter in each IP packet that drops by one at every router. At zero the packet is discarded, which stops loops. Traceroute uses it.
TTP soc
Tactics, techniques and procedures: how an attacker behaves, from goal to exact method. see: detect/attack-mapping
Two's complement concepts
How computers store negative integers: the top bit counts as a negative place value, and you negate a number by flipping all bits and adding 1 (an 8-bit 11111111 is -1). see: man numbers
TXT record network
A DNS record holding free text. Used for SPF, DKIM, DMARC and domain verification.
TypeScript programming
JavaScript with static types, compiled to plain JavaScript. see: guide: typescript-javascript
Typosquatting attacks
Registering a domain or package name that is a typo of a real one, hoping people mistype it.
UAC windows
User Account Control: the Windows prompt that asks before a program gets administrator rights.
UART hardware
A simple serial connection often exposed on devices as a debug console. Common first step in hardware hacking.
Ubuntu linux
A popular, beginner-friendly Linux distribution, widely used on servers and in the cloud. Debian-based. see: guide: linux-server-admin-ubuntu
UDP network
User Datagram Protocol: fast, connectionless, no delivery guarantee. DNS and VoIP use it. see: guide: computer-networks
UEFI / Secure Boot hardening
Modern firmware that checks the boot software is signed before running it. see: Security+ 4.1
umask linux
The setting that removes permissions from newly created files on Linux. see: drill: linux-permissions
Underfitting ai
A model too simple to learn the pattern, so it does poorly even on its training data. see: ai: ml-evaluation
Unicast network
Traffic from one sender to one receiver.
Unicode and UTF-8 programming
Unicode is the standard list of characters. UTF-8 is the common way to store it as bytes, compatible with ASCII.
Unit test programming
A small automated test of one piece of code. see: cs/testing
Unsupervised learning ai
Finding structure in data with no labels, such as clusters. see: ai: ml-intro
UPS hardware
Uninterruptible power supply: a battery that keeps equipment running briefly when power fails and cleans up surges. see: comptia/aplus
URL web
A web address: scheme, host, port, path, query and fragment, such as https://example.com:443/path?x=1. see: basics: http-and-the-web
USB hardware
Universal Serial Bus: the common connector for peripherals. A malicious USB device can act as a keyboard (BadUSB, Rubber Ducky).
Use after free vulns
A memory bug: a program keeps using memory after releasing it, which an attacker may take over. see: guide: binary-exploitation
User space and kernel space os
Kernel space is the privileged part of memory where the OS runs. User space is where normal programs run, with limited rights. see: guide: operating-systems
Username access
The name that identifies an account at login.
Variable programming
A named place in a program that holds a value. see: guide: python
Vector database ai
A database that stores embeddings and finds the items closest in meaning to a query. see: ai: ai-chatbot
Version control programming
Tracking changes to files over time so you can compare, undo and collaborate. Git is the standard. see: guide: git-github
Virtual machine (VM) virtualization
A whole computer simulated in software, with its own virtual CPU, disk and OS, running on a hypervisor. Strong isolation, heavier than a container. see: guide: virtualization-proxmox
Virtual memory os
Giving each process its own address space, mapped to RAM or disk by the OS.
Virtual patching hardening
Blocking an exploit with a WAF or IPS rule when you can't patch the software yet.
Virtualization virtualization
Running several virtual computers on one physical machine using a hypervisor. see: guide: virtualization-proxmox
VirusTotal tools
A website that scans files, hashes and URLs with many antivirus engines. Don't upload sensitive files; they become visible to others.
VLAN network
A virtual LAN: splits one physical switch into separate network segments. see: guide: networking-tcp-ip-dhcp-nat-subnets · Security+ 3.2
VLAN hopping attacks
Sending traffic into a VLAN you shouldn't reach, by switch spoofing or double tagging.
VNC network
Virtual Network Computing: remote desktop sharing over port 5900 with weak default security. Tunnel it.
Volatility tools
The standard open source tool for analyzing memory dumps in forensics. see: guide: memory-forensics-volatility
Volume Shadow Copy windows
Windows snapshots of files and volumes. Attackers delete them to stop recovery; ransomware often does.
VPC cloud
Virtual private cloud: your isolated network inside a cloud provider. see: cloud/cloud-networking
VPN network
Virtual private network: an encrypted tunnel across an untrusted network such as the internet, so remote users or sites can reach a private network safely. WireGuard, OpenVPN, IPsec and Tailscale are examples. see: basics: vpns-and-tunnels · guide: vpn-tailscale
Vulnerability vulns
A weakness that an attacker could use. Management means finding, ranking and fixing them. see: Security+ 4.3 · Security+ 2.3
Vulnerability management governance
The cycle of finding, ranking, fixing and rechecking weaknesses. see: Security+ 4.3
Vulnerability scan vulns
Automated checking of systems for known weaknesses. Nessus and OpenVAS are examples. see: Security+ 4.3
WAF tools
Web application firewall: filters HTTP traffic to block injection and similar attacks. see: Security+ 3.2
WAN network
A network that links distant sites or reaches the internet. The router's internet-facing side is its WAN port. see: guide: computer-networks
Watering hole attacks
Compromising a site that the target group visits, to infect them there.
Wazuh tools
An open source host-based monitoring and SIEM platform. see: guide: siem-security-onion
Web server web
Software that answers HTTP requests with pages or data. Apache, Nginx and IIS are common.
Web shell malware
A script uploaded to a web server that gives an attacker a command interface through the browser.
Web storage web
localStorage and sessionStorage: browser key-value storage readable by any script on the page, so don't keep tokens there.
Webhook web
A URL your service calls when an event happens, so another system gets pushed the news instead of polling.
Website web
A collection of web pages served from a domain. A web application adds logic, accounts and data. see: basics: how-web-apps-work
WebSocket web
A persistent two-way connection between browser and server, used for chat and live updates.
Well-known ports network
Ports 0 to 1023, reserved for standard services such as 22 SSH, 53 DNS, 80 HTTP and 443 HTTPS. see: basics: ports-and-protocols
WEP network
The original Wi-Fi security. Broken in minutes by IV reuse. Never use it. see: Security+ pairs
Whaling attacks
Phishing aimed at senior executives.
Wi-Fi network
Wireless LAN technology (the IEEE 802.11 standards). Secure it with WPA2 or WPA3, never open or WEP.
Windows os
Microsoft's family of operating systems, the most common on business desktops. Managed with Active Directory and PowerShell. see: basics: linux-windows-basics · guide: windows-admin-powershell
Windows Defender windows
Microsoft's built-in antivirus and endpoint protection.
WinRM windows
Windows Remote Management: remote PowerShell over HTTP(S) ports 5985 and 5986.
Wiper malware
Malware that destroys data instead of holding it for ransom.
WireGuard network
A modern VPN protocol with a small codebase, fast and simple to configure: each peer has a key pair and a list of allowed IPs. Tailscale is built on it. see: basics: vpns-and-tunnels
Wireshark tools
The standard graphical packet analyzer; tshark is its command-line twin. see: man wireshark · drill: read-a-packet-capture
WMI windows
Windows Management Instrumentation: a way to query and control Windows systems locally and remotely, used by admins and attackers.
WordPress web
The most popular content management system. Its plugins are a common source of vulnerabilities.
Worm malware
Malware that spreads itself across a network with no user action. see: guide: malware-analysis
WPA2 / WPA3 network
Wi-Fi security standards. WPA3 is newer and fixes weaknesses in WPA2's key exchange. WEP is obsolete and trivially broken.
Write blocker dfir
A hardware or software device that lets you read a disk without changing it. see: guide: disk-forensics-autopsy-ftk-imager
WSL windows
Windows Subsystem for Linux: runs a real Linux environment inside Windows without a separate VM.
X.509 crypto
The standard format of digital certificates. see: crypto/tls-pki
x86 hardware
The CPU instruction set family used in most PCs and servers. x64 or AMD64 is its 64-bit version. see: guide: c-x86-assembly
XML programming
A tag-based data format. Parsers that mishandle it can suffer XXE.
XXE vulns
A flaw in XML parsing where external entities let an attacker read files or make the server request URLs.
YAML programming
A human-friendly data format used in configuration files, Kubernetes and CI pipelines.
YARA tools
A rule language for matching patterns in files and memory, used to identify malware families. see: guide: malware-analysis · man volatility
Zeek tools
A network monitoring tool that turns traffic into detailed logs of connections, DNS, HTTP and files. see: guide: siem-security-onion
Zero day vulns
A vulnerability the vendor does not yet know about, or has had no time to patch. see: Security+ 2.3
Zero trust concepts
Never trust by network location: verify every request, every time, and give minimum access. see: Security+ 1.2 · Security+ 3.1
Zombie process os
A process that has finished but whose parent hasn't collected its exit status yet.
Zone transfer attacks
A DNS feature that copies all records of a zone to another server. If left open to anyone, it leaks every hostname.
