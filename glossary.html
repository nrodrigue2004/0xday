162 terms in plain language. Most link to the guide, Security+ objective, cheatsheet or drill where the idea is used. Type to filter, or pick a category.

A B C D E F G H I K L M N O P R S T U V W Y Z J

ACL access
Access control list: the list of entries on a file, share, router or firewall that says who or what is allowed (or denied) what. see: drill: windows-permissions · drill: linux-permissions · Security+ 4.6
Active Directory windows
Microsoft's directory service. Stores users, groups and computers for a Windows domain and handles login through domain controllers. see: guide: active-directory · man ad-powershell
AES crypto
Advanced Encryption Standard. The standard symmetric cipher; fast, used with 128 or 256-bit keys. see: guide: cryptography-applied · Security+ 1.4
AGDLP windows
Accounts go in Global groups, which go in Domain Local groups, which get Permissions. The tidy way to give Windows groups access to resources. see: drill: windows-permissions
APT threats
Advanced persistent threat: a well-resourced attacker, often state-linked, that stays inside a network for a long time. see: Security+ 2.1
ARP network
Address Resolution Protocol. Maps an IP address to a MAC address on the local network. ARP spoofing lies about that mapping. see: guide: computer-networks · man cmd
ARP spoofing attacks
Sending fake ARP replies so traffic for one IP goes to the attacker's MAC; a local man-in-the-middle. see: guide: network-traffic-analysis
Asymmetric encryption crypto
Encryption with a key pair: a public key to encrypt or verify, a private key to decrypt or sign. Examples: RSA, ECC. see: guide: cryptography-applied · Security+ 1.4
Attack surface concepts
Every place an attacker could try to get in: open ports, apps, accounts, people, vendors. see: Security+ 2.2
Authentication access
Proving who you are (password, key, biometric). Compare authorization: what you may do once proven. see: Security+ 4.6
Authorization access
Deciding what an authenticated identity is allowed to do. see: Security+ 4.6 · drill: linux-permissions
Availability concepts
The 'A' in the CIA triad: systems and data are there when needed. see: Security+ 1.2
Backdoor malware
A hidden way back into a system that bypasses normal login. see: guide: malware-analysis
Backup (3-2-1) resilience
Keep 3 copies of data, on 2 kinds of media, with 1 offsite or offline. Offline copies survive ransomware. see: Security+ 3.4
Beaconing threats
A compromised host contacting its controller at regular intervals. The even rhythm is the giveaway. see: drill: read-a-packet-capture · guide: network-traffic-analysis
BIA governance
Business impact analysis: working out which systems matter most, and what an outage costs per hour. see: Security+ 5.2 · Security+ 3.4
Blue team concepts
The defenders: monitoring, hardening, detection and response. see: Security+ 4.4
Botnet threats
A network of infected machines controlled remotely, used for DDoS, spam and credential stuffing. see: Security+ 2.4
Brute force attacks
Trying every possible password or key. Rate limits, lockouts and MFA blunt it. see: guide: password-cracking-john · Security+ 2.4
Buffer overflow vulns
Writing past the end of a memory buffer so you can overwrite adjacent data, including a return address. see: guide: binary-exploitation · guide: c-x86-assembly
Bug bounty concepts
A program where a company pays researchers for valid vulnerabilities, within a published scope and rules.
C2 (command and control) threats
The infrastructure an attacker uses to send commands to compromised machines and receive data back. see: drill: read-a-packet-capture
CA (certificate authority) crypto
A trusted organization that signs digital certificates, vouching that a public key belongs to a named site. see: Security+ 1.4
CIA triad concepts
Confidentiality, Integrity, Availability: the three goals security protects. see: Security+ 1.2
CIDR network
Classless Inter-Domain Routing notation, like 10.0.5.0/24: an address plus how many bits are the network part. see: guide: networking-tcp-ip-dhcp-nat-subnets
Cipher crypto
An algorithm that encrypts and decrypts. see: guide: cryptography-applied
CIS Benchmarks hardening
Free configuration guides from the Center for Internet Security for hardening operating systems and apps. see: guide: system-hardening-windows-linux
Cleartext crypto
Data sent or stored without encryption. FTP, Telnet and HTTP are cleartext protocols. see: guide: network-traffic-analysis
Cron linux
The Linux scheduler. Cron entries that run as root are a favorite privilege-escalation path when the script is writable. see: drill: linux-permissions · guide: linux-server-admin-ubuntu
Cross-site scripting (XSS) vulns
Injecting script into a page that other users then run in their browser. Stored, reflected and DOM-based are the main kinds. see: Security+ 2.3
CSRF vulns
Cross-site request forgery: tricking a logged-in user's browser into sending a request they did not intend. see: Security+ 2.3
CVE vulns
Common Vulnerabilities and Exposures: a public ID such as CVE-2021-44228 for one known vulnerability. see: Security+ 4.3
CVSS vulns
Common Vulnerability Scoring System: a 0 to 10 severity score for a vulnerability. Severity is not the same as your risk. see: Security+ 4.3
Dark web concepts
Parts of the internet reachable only with special software such as Tor. Not the same as the deep web (anything not indexed).
DDoS attacks
Distributed denial of service: many machines flood a target so real users cannot reach it. see: Security+ 2.4
Defense in depth concepts
Layering controls so no single failure lets an attacker through. see: Security+ 1.2 · Security+ 3.2
DHCP network
Dynamic Host Configuration Protocol: hands out IP address, gateway and DNS to devices when they join. see: guide: networking-tcp-ip-dhcp-nat-subnets
Digital forensics dfir
Collecting and analyzing evidence from devices in a way that holds up, with a documented chain of custody. see: guide: digital-forensics · Security+ 4.9
DKIM email
DomainKeys Identified Mail: the sending mail server signs messages so receivers can check them against a key in DNS. see: guide: phishing-analysis
DLP data
Data loss prevention: tools that detect and block sensitive data leaving, such as card numbers in an email. see: Security+ 3.3
DMARC email
Tells receivers what to do with mail that fails SPF or DKIM and where to report it. Policies: none, quarantine, reject. see: guide: phishing-analysis
DMZ network
A network segment between the internet and the internal network that holds public-facing servers. see: Security+ 3.2 · guide: firewalls-pfsense
DNS network
Domain Name System: turns names into IP addresses. Mostly UDP port 53. see: guide: computer-networks · drill: read-a-packet-capture
DNS tunneling attacks
Hiding data inside DNS queries and answers to sneak it out. Look for long, odd names and high volume. see: guide: network-traffic-analysis · man wireshark
Domain controller windows
A Windows server that holds the Active Directory database and authenticates domain logins. see: guide: active-directory
Dropper malware
Malware whose job is to download or unpack the real payload. see: guide: malware-analysis
EDR tools
Endpoint detection and response: agent software that records host activity, detects attacks and lets analysts contain a machine. see: Security+ 4.4 · Security+ 4.8
Encoding crypto
Reshaping data into another form (base64, URL encoding). Not encryption: anyone can reverse it. see: drill: regex-for-logs
Event ID windows
A number identifying a type of Windows event, such as 4624 successful logon or 4625 failed logon. see: man windows-ir · guide: log-analysis
Exfiltration threats
Stealing data out of a network. see: drill: read-a-packet-capture
Exploit vulns
Code or a technique that takes advantage of a vulnerability. see: guide: recon-nmap-metasploit
False positive soc
An alert that fired but was not an attack. Too many make analysts stop trusting the alert. see: Security+ 4.4
Firewall network
Allows or blocks traffic by rules on address, port and protocol. Stateful firewalls track connections. see: guide: firewalls-pfsense · Security+ 3.2
Forensic image dfir
A bit-for-bit copy of a drive, hashed to prove it was not altered. see: guide: digital-forensics
FTP network
File Transfer Protocol: old and cleartext. Use SFTP or FTPS instead. see: guide: computer-networks
Fuzzing vulns
Throwing malformed or random input at a program to find crashes and bugs. see: guide: binary-exploitation
GPO windows
Group Policy Object: a bundle of Windows settings pushed to users and computers by Active Directory. see: guide: group-policy
Hardening hardening
Reducing attack surface: remove what you do not need, patch, lock down settings. see: guide: system-hardening-windows-linux · Security+ 4.1
Hash crypto
A one-way fingerprint of data. Same input, same output; you cannot reverse it. Used to check integrity and store passwords. see: guide: cryptography-applied · guide: password-cracking-john
Honeypot tools
A decoy system built to be attacked so you can observe the attacker. see: Security+ 1.2
HTTP status codes network
200 OK, 301/302 redirect, 401 unauthenticated, 403 forbidden, 404 not found, 500 server error. see: drill: regex-for-logs
HTTPS / TLS crypto
HTTP carried inside TLS, giving encryption and server identity. TLS is the modern name for SSL. see: Security+ 1.4
Hypervisor virtualization
Software that runs virtual machines. Type 1 runs on bare metal (Proxmox, ESXi); type 2 runs on an OS (VirtualBox). see: guide: virtualization-proxmox
IAM access
Identity and access management: how accounts, authentication, permissions and lifecycle are managed. see: Security+ 4.6
ICMP network
The protocol behind ping and traceroute: error and diagnostic messages for IP. see: guide: computer-networks
IDS / IPS tools
Intrusion detection (alerts) and prevention (blocks) systems that match traffic against signatures or behavior. Snort and Suricata are examples. see: guide: ids-snort · Security+ 4.4
Incident response soc
The process for handling a security event: prepare, detect, contain, eradicate, recover, learn. see: guide: incident-response · Security+ 4.8
Indicator of compromise (IOC) soc
A clue that a system was breached: a hash, IP, domain, file name, registry key. see: Security+ 2.4
Integrity concepts
The 'I' in CIA: data is correct and has not been altered without authorization. see: Security+ 1.2
IP address network
A number identifying a device on a network. IPv4 like 10.0.5.23; IPv6 is much longer. see: guide: networking-tcp-ip-dhcp-nat-subnets
ITIL it
A set of IT service management practices (incident, problem, change management) used by help desks. see: guide: help-desk-ticketing-osticket · Security+ 1.3
Kerberos windows
The ticket-based authentication system in Active Directory. Attacks include Kerberoasting and golden tickets. see: guide: active-directory
Kill chain threats
A model of an attack as steps: recon, weaponize, deliver, exploit, install, command and control, actions. see: Security+ 2.4
Lateral movement threats
An attacker moving from one compromised machine to others inside the network. see: Security+ 2.4 · guide: active-directory
LDAP windows
Lightweight Directory Access Protocol: how clients query directories such as Active Directory. see: guide: active-directory
Least privilege access
Give accounts only the access they need, nothing more. see: Security+ 1.2 · drill: linux-permissions
Living off the land threats
Attacking with tools already on the system (PowerShell, certutil, wmic) so there is no malware file to find. see: man cmd · man powershell
Log soc
A record of events written by a system or app. The raw material of detection and forensics. see: guide: log-analysis · drill: parse-logs-with-pipes
MAC address network
The hardware address of a network card, 48 bits, used on the local network. Can be spoofed. see: guide: computer-networks
Malware malware
Any software built to harm: viruses, worms, trojans, ransomware, spyware, rootkits. see: guide: malware-analysis
Man-in-the-middle (MITM) attacks
An attacker sits between two parties and reads or alters their traffic. see: Security+ 2.4
MFA access
Multi-factor authentication: two or more of something you know, have or are. Phishing-resistant forms (FIDO2 keys) beat SMS codes. see: Security+ 4.6
MITRE ATT&CK soc
A public catalog of attacker tactics and techniques (T1110 brute force, and so on) used to describe and detect behavior. see: Security+ 2.4 · man wireshark
NAT network
Network address translation: many private addresses share one public address. see: guide: networking-tcp-ip-dhcp-nat-subnets
NetFlow soc
Summaries of who talked to whom, how much and when, without the packet contents. see: guide: network-traffic-analysis
NIST CSF governance
NIST Cybersecurity Framework: Identify, Protect, Detect, Respond, Recover (and Govern in version 2). see: Security+ 5.1
NTFS windows
The Windows file system, with per-file permissions (ACLs), encryption and journaling. see: drill: windows-permissions
OAuth access
A standard for delegated access: 'let this app read my calendar' without giving it your password. see: Security+ 4.6
OSI model network
Seven layers for thinking about networks: physical, data link, network, transport, session, presentation, application. see: guide: computer-networks
OSINT recon
Open-source intelligence: research from public sources such as search, social media, DNS records and breach data. see: guide: recon-nmap-metasploit
OWASP Top 10 vulns
A list of the most common web application risks (injection, broken access control, and so on). see: Security+ 2.3
Packet network
One chunk of data on a network, with headers saying where it came from and where it goes. see: drill: read-a-packet-capture · man wireshark
Packet capture (pcap) soc
A recording of network packets, made with tcpdump or Wireshark. see: drill: read-a-packet-capture · guide: network-traffic-analysis
Passkey / FIDO2 access
A phishing-resistant login that uses a key pair stored on your device or a security key. see: Security+ 4.6
Patch hardening
A software update that fixes a bug or vulnerability. see: Security+ 4.3
Payload malware
The part of an attack that does the damage once it lands; also, the data portion of a packet. see: guide: recon-nmap-metasploit
Penetration test concepts
An authorized, scoped attempt to break in to find weaknesses before real attackers do. see: guide: recon-nmap-metasploit · Security+ 5.5
pfSense network
An open source firewall and router distribution used in homelabs and small businesses. see: guide: firewalls-pfsense
PGP / GPG crypto
Tools for encrypting and signing email and files with public keys. see: guide: cryptography-applied
Phishing attacks
Fraudulent messages that trick people into giving up credentials or running something. Spear phishing targets a person; whaling targets executives. see: guide: phishing-analysis · Security+ 2.2
PKI crypto
Public key infrastructure: the CAs, certificates and rules that make public-key trust work. see: Security+ 1.4
Port network
A number (0-65535) that picks which service on a host a packet is for. see: guide: computer-networks · man nmap
Port scan recon
Probing a host to see which ports answer. Nmap is the standard tool. see: man nmap · drill: read-a-packet-capture
Privilege escalation attacks
Going from a low-privilege account to a higher one, such as root or SYSTEM. see: drill: linux-permissions · Security+ 2.4
Proxmox virtualization
An open source hypervisor platform for running VMs and containers. The platform behind my homelab. see: guide: virtualization-proxmox
Purple team concepts
Red and blue working together so each attack teaches a detection.
Ransomware malware
Malware that encrypts files and demands payment, often after stealing the data first. see: Security+ 2.4 · Security+ 3.4
RAT malware
Remote access trojan: malware that gives an attacker remote control. see: guide: malware-analysis
RBAC access
Role-based access control: permissions attach to roles, people get roles. see: Security+ 4.6
Red team concepts
The attackers in an exercise: they emulate real threats to test the defenders.
Regex tools
Regular expression: a pattern language for matching text. see: drill: regex-for-logs · drill: parse-logs-with-pipes
Reverse engineering malware
Taking a compiled program apart to learn what it does. see: guide: reverse-engineering
Reverse shell attacks
A shell where the victim connects out to the attacker, getting around inbound firewall rules. see: guide: recon-nmap-metasploit
Risk governance
Likelihood times impact. You can accept, avoid, transfer (insure) or mitigate it. see: Security+ 5.2
Rootkit malware
Malware that hides itself and other malware at a low level, often in the kernel. see: guide: malware-analysis · man volatility
Salt crypto
Random data added to a password before hashing so identical passwords get different hashes. see: guide: password-cracking-john · guide: cryptography-applied
Sandbox malware
An isolated environment where untrusted code runs safely so you can watch it. see: guide: malware-analysis
SIEM soc
Security information and event management: collects logs from everywhere and correlates them into alerts. Splunk, Elastic, Wazuh and Security Onion are examples. see: guide: siem-security-onion · man splunk · Security+ 4.4
Sigma soc
A vendor-neutral format for writing detection rules that convert to many SIEM languages. see: Security+ 4.4
SOAR soc
Security orchestration, automation and response: playbooks that automate repetitive SOC steps. see: Security+ 4.7
SOC soc
Security operations center: the team that monitors alerts and responds to incidents. see: guide: siem-security-onion · Security+ 4.4
Social engineering attacks
Manipulating people rather than machines: pretexting, phishing, tailgating, vishing. see: Security+ 2.2
SPF email
Sender Policy Framework: a DNS record listing which servers may send mail for a domain. see: guide: phishing-analysis
SPL tools
Search Processing Language, the query language of Splunk. see: man splunk
SQL injection vulns
Putting SQL into an input so the database runs it. Fixed with parameterized queries. see: guide: databases-and-sql · Security+ 2.3
SSH network
Secure Shell: encrypted remote login and file transfer on port 22. Use keys, not passwords. see: guide: linux-server-admin-ubuntu · man linux
SSL/TLS handshake crypto
The opening exchange where client and server agree on keys and the server proves its identity. see: drill: read-a-packet-capture
Subnet network
A slice of an IP network, defined by a mask. Hosts in the same subnet talk directly. see: guide: networking-tcp-ip-dhcp-nat-subnets
SUID linux
A permission bit that makes a program run as its owner. A root-owned SUID program with a flaw is a path to root. see: drill: linux-permissions · man linux
Supply chain attack threats
Compromising a vendor or software dependency to reach its customers. see: Security+ 2.2 · Security+ 5.3
Symmetric encryption crypto
One shared key encrypts and decrypts. Fast; the hard part is sharing the key. see: guide: cryptography-applied
Syslog soc
A standard for sending log messages over the network to a central collector. see: guide: log-analysis
Sysmon windows
A Windows Sysinternals service that logs detailed process, network and file events to the event log. see: man windows-ir · guide: log-analysis
Tailscale network
A mesh VPN built on WireGuard that makes devices reachable by private address with almost no setup. see: guide: vpn-tailscale
TCP network
Transmission Control Protocol: reliable, ordered delivery with a three-way handshake. see: drill: read-a-packet-capture · guide: computer-networks
Threat intelligence soc
Information about attackers and their methods that you use to prioritize defenses. see: Security+ 2.1
Three-way handshake network
SYN, SYN-ACK, ACK: how TCP opens a connection. see: drill: read-a-packet-capture
Tokenization data
Replacing sensitive data (a card number) with a meaningless token and keeping the real value elsewhere. see: Security+ 3.3
Trojan malware
Malware pretending to be something useful. see: guide: malware-analysis
UDP network
User Datagram Protocol: fast, connectionless, no delivery guarantee. DNS and VoIP use it. see: guide: computer-networks
UEFI / Secure Boot hardening
Modern firmware that checks the boot software is signed before running it. see: Security+ 4.1
umask linux
The setting that removes permissions from newly created files on Linux. see: drill: linux-permissions
VLAN network
A virtual LAN: splits one physical switch into separate network segments. see: guide: networking-tcp-ip-dhcp-nat-subnets · Security+ 3.2
VPN network
An encrypted tunnel across an untrusted network. WireGuard, OpenVPN and Tailscale are examples. see: guide: vpn-tailscale
Vulnerability vulns
A weakness that an attacker could use. Management means finding, ranking and fixing them. see: Security+ 4.3 · Security+ 2.3
Vulnerability scan vulns
Automated checking of systems for known weaknesses. Nessus and OpenVAS are examples. see: Security+ 4.3
WAF tools
Web application firewall: filters HTTP traffic to block injection and similar attacks. see: Security+ 3.2
Wazuh tools
An open source host-based monitoring and SIEM platform. see: guide: siem-security-onion
Wireshark tools
The standard graphical packet analyzer; tshark is its command-line twin. see: man wireshark · drill: read-a-packet-capture
Worm malware
Malware that spreads itself across a network with no user action. see: guide: malware-analysis
YARA tools
A rule language for matching patterns in files and memory, used to identify malware families. see: guide: malware-analysis · man volatility
Zero day vulns
A vulnerability the vendor does not yet know about, or has had no time to patch. see: Security+ 2.3
Zero trust concepts
Never trust by network location: verify every request, every time, and give minimum access. see: Security+ 1.2 · Security+ 3.1
Cookie web
A small value the server asks the browser to store and send back on every request. Session cookies carry the login. The Secure, HttpOnly and SameSite flags limit where they travel and who can read them. see: man http
Session web
The server's memory of a logged-in user between HTTP requests, found by a random id in a cookie or a signed token. Stealing the id is the same as stealing the login. see: man http
REST API web
An HTTP API where URLs name things and methods (GET, POST, PUT, PATCH, DELETE) say what to do to them, usually exchanging JSON. see: man http
JWT web
JSON Web Token: header.payload.signature. The payload is readable by anyone, the signature proves it was not changed. Check expiry, audience and the allowed algorithm. see: man http
IDOR web
Insecure direct object reference, a form of broken access control: changing an id in a request returns another user's data because the server never checked ownership. see: man http
SSRF web
Server-side request forgery: tricking a server into fetching a URL of the attacker's choice, such as internal services or cloud metadata. Fix with destination allow-lists and egress filtering. see: man http
CORS web
Cross-origin resource sharing: how a server lets other origins read its responses in the browser. A browser rule, not a substitute for authentication. see: man http
Parameterized query web
A SQL statement with placeholders where values are sent separately from the query text, so input can never change the query. The main defense against SQL injection. see: man rdbms · guide: databases-and-sql
Primary key / foreign key web
A primary key uniquely identifies a row. A foreign key in another table points at it, which is how relational databases link records. see: man rdbms · guide: databases-and-sql

Written in my own words. If a term is missing, it will be added; this is a study aid, not a standard.
