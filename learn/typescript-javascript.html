The language of the browser, and of a lot of malware droppers. Learn JavaScript from first values to closures, run real code in the sandbox, then decode an obfuscated payload.

1simple2mid3complex4hands-on

01 simple // the idea in plain words

JavaScript runs in every browser and, through Node.js, on servers. A program is a list of statements. You store values in variables with const (can't be reassigned) or let (can), and print them with console.log.

The sandbox runs real JavaScript with node -e '<code>':

$ node -e 'const name = "0xDay"; console.log("hello, " + name)'
$ node -e 'console.log(7 * 6, typeof 42, typeof "42")'

A function is a reusable block that takes inputs and returns an output:

$ node -e 'function double(n) { return n * 2 } console.log(double(21))'

TypeScript is JavaScript plus type labels (function double(n: number): number). The compiler checks the types and then strips them out, so what actually runs is plain JavaScript.

02 mid // how it's actually used

Most real JavaScript is moving data around: arrays (lists), objects (key/value records) and JSON (objects as text, the format every web API speaks).

The three array methods you'll see everywhere:

  • map transforms every item
  • filter keeps items that pass a test
  • reduce folds the list into one value

ports.js in the sandbox holds a fake scan result. Read it, then run it:

$ cat ports.js
$ node ports.js

Arrow functions (p => p.open) are just short functions. Template strings use backticks and ${}:

$ node -e 'const hosts = ["10.0.0.5", "10.0.0.9"]; hosts.map((h, i) => console.log(`${i}: ${h}`))'
$ node -e 'console.log(JSON.stringify({ user: "nathan", admin: false }))'

03 complex // what the pros do

1. Strings are just numbers

Every character has a numeric code. "A".charCodeAt(0) is 65, and String.fromCharCode(65) is "A". That's the basis of almost every obfuscation trick: shift, XOR or encode the codes so the text doesn't look like a URL anymore.

$ node -e 'console.log([..."hi"].map(c => c.charCodeAt(0)))'
$ node -e 'console.log(String.fromCharCode(104, 105))'

2. XOR and base64

XOR (^) flips bits with a key, and XOR-ing twice with the same key gives you the original back: (c ^ k) ^ k === c. Base64 (btoa / atob) turns bytes into safe printable text. Droppers often stack them: XOR the URL, then base64 it.

$ node -e 'const k = 0x2a; const x = 104 ^ k; console.log(x, x ^ k)'
$ node -e 'console.log(btoa("hi"), atob("aGk="))'

3. Closures, async and why attackers love eval

  • A closure is a function that remembers variables from where it was created, the trick behind private state and module patterns
  • async/await lets code wait on network calls without freezing the page
  • eval(string) runs a string as code, so a dropper only needs to *decode* a string and eval it. As an analyst you do the opposite: swap eval for console.log and read what it would have run

Never run an unknown script to "see what it does". Copy only the decoding logic, and print instead of executing.
