Python is the security field's glue language. Learn it from variables to parsing logs with real Python running in your browser, then write a script that finds a brute-force attacker.

1simple2mid3complex4hands-on

01 simple // the idea in plain words

Python reads almost like English, which is why it's the first language for most security people. The sandbox runs real Python (Pyodide, the first run downloads it once).

Values go in variables, print shows them, and f-strings drop variables into text:

$ python3 -c 'name = "0xDay"; print(f"hello, {name}")'
$ python3 -c 'print(7 * 6, type(42), type("42"))'

A list holds items in order, and a for loop walks through them:

$ python3 -c 'for p in [22, 80, 443]: print("checking", p)'

Indentation is syntax in Python. The body of a loop or if is whatever is indented under it.

02 mid // how it's actually used

Files, strings and dictionaries

Most security scripts do the same thing: open a file, go line by line, split the line, keep counts. A dictionary maps keys to values, perfect for counting.

$ cat ~/scripts/count_status.py
$ python3 ~/scripts/count_status.py

Useful string methods: line.split() (split on spaces), .strip(), .startswith(), "x" in line. And collections.Counter counts anything in one line:

$ python3 -c 'from collections import Counter; print(Counter("mississippi").most_common(2))'

03 complex // what the pros do

Regular expressions and the standard library

re finds patterns (IPs, emails, hashes), ipaddress understands networks, hashlib hashes, base64 and json decode the formats you see everywhere, datetime parses timestamps:

$ python3 -c 'import ipaddress; print(ipaddress.ip_address("10.0.20.44") in ipaddress.ip_network("10.0.0.0/8"))'
$ python3 -c 'import hashlib; print(hashlib.sha256(b"0xday").hexdigest())'

Writing scripts that last

  • wrap the logic in functions and use if __name__ == "__main__":
  • take inputs from sys.argv or argparse instead of hard-coding paths
  • handle bad lines with try/except instead of crashing on line 40,000
  • for real work: requests (HTTP), scapy (packets), pandas (big tables), pwntools (CTFs)

Edit scripts in the sandbox with nano file.py, save with Ctrl+S, exit with Ctrl+X.
