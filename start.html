# 0. orient

Pick a target so the rest has a direction. One evening.

  1. Pick a career path ~30m

    Skim all eight paths. Choose a primary and a backup. Everything below serves that choice.

  2. Read the skills matrix ~15m

    Know what is already proven and what is thin before studying anything.

  3. Skim ~/courses and try a placement exam ~20m

    Eleven courses wrap what is already on the site, each with module quizzes and an exam. Pass an exam at 80% and that course is tested out, which shortens the path below.

  4. Read the cert roadmap ~15m

    Security+ first, the rest follow. Write down the exam date.

  5. Set a weekly study goal in the log ~5m

    Three to five days a week. Streaks beat intensity.

# 1. foundations

Networking, operating systems and vocabulary. Security+ assumes all of it.

  1. OSI and TCP/IP ~45m

    Layers, encapsulation, what a packet is. Read it twice.

  2. Ports and protocols ~45m

    Memorize the common ones. They show up on the exam and in every log.

  3. CIA triad and crypto basics ~40m

    Confidentiality, integrity, availability; hashing versus encryption.

  4. Linux and Windows basics ~45m

    Filesystems, users, processes, services on both.

  5. Linux command line ~60m

    Do the lab in the sandbox, don't just read it.

  6. TCP/IP, DHCP, NAT and subnets ~60m

    Subnet by hand until it stops hurting.

  7. Operating systems ~60m

    Processes, memory, scheduling, permissions.

  8. Skim the glossary ~15m

    Terms are linked to guides. Look up anything unfamiliar as it appears.

  9. What is machine learning? ~45m

    Plain English: spam filters, training versus prediction, overfitting, the confusion matrix. No math needed.

# 2. everyday tools

Scripting, Git, SQL and Windows administration. Used in every job on the list.

  1. Bash scripting ~60m

    Loops, pipes, small scripts that parse logs.

  2. Python ~60m

    The default glue language for security work.

  3. Git and GitHub ~45m

    Branches, PRs, undoing mistakes.

  4. SQL ~60m

    Selects, joins, aggregates. Analyst and SOC roles both want it.

  5. Windows admin and PowerShell ~60m

    Users, services and event logs from the shell.

  6. Active Directory ~60m

    OUs, groups, authentication. Most corporate networks are this.

  7. One week of dojo katas ~90m

    Short daily drills in the language your target path uses.

# 3. Security+ (SY0-701)

The first cert. Work the domains in order, then drill weak spots until they stop being weak.

  1. Domain 1: general security concepts ~4.0h

    Controls, CIA, zero trust, crypto, PKI. Objectives 1.1 to 1.4.

  2. Domain 2: threats, vulnerabilities, mitigations ~5.0h

    Threat actors, attacks, indicators, hardening. 2.1 to 2.5.

  3. Domain 3: security architecture ~4.0h

    Cloud, segmentation, resilience, data protection. 3.1 to 3.4.

  4. Domain 4: security operations ~7.0h

    Biggest domain: monitoring, IR, identity, automation. 4.1 to 4.9.

  5. Domain 5: governance, risk, compliance ~4.0h

    Policies, risk math, audits, awareness. 5.1 to 5.6.

  6. Acronym trainer ~20m

    Run it daily until accuracy is high. Cheap points on the exam.

  7. Performance-based question sims ~60m

    PBQs are what people fail on. Practice the format.

  8. Scenario cards ~45m

    Pick the best answer under realistic wording.

  9. Weak-spot drill ~45m

    Targets whatever you keep missing. Repeat until clean.

  10. Book the exam ~30m

    Practice scores steady above target, then schedule. Target: Q1 2027.

# 4. defensive skills

What a SOC analyst does day to day. This is where the first security job comes from.

  1. Log analysis ~60m

    Read logs, find the one line that matters.

  2. Drill: parse logs with pipes ~45m

    grep, awk, sort, uniq until it's reflex.

  3. Drill: regex for logs ~45m

    Patterns for IPs, users, timestamps.

  4. Network traffic analysis ~60m

    Wireshark filters, following streams.

  5. Drill: read a packet capture ~45m

    Find the exfiltration in a real capture.

  6. SIEM with Security Onion ~60m

    Alerts, dashboards, pivoting.

  7. IDS with Snort ~60m

    Rules, what they catch, false positives.

  8. Incident response ~60m

    The lifecycle, and what to write down.

  9. Phishing analysis ~45m

    Headers, URLs, attachments. A daily SOC task.

  10. Digital forensics ~60m

    Disk images, timelines, evidence handling.

  11. System hardening ~60m

    Baselines on Windows and Linux.

  12. Firewalls with pfSense ~60m

    Rules, NAT, segmentation.

# 5. labs and proof

Reading is not evidence. Build, break and write it up so an interviewer can check.

  1. Extend the homelab ~3.0h

    Add one thing: a log source, a detection rule, a segment. Document it.

  2. Drill: Security Onion intrusion hunt ~90m

    End-to-end hunt, then write the report.

  3. One TryHackMe or CTF room ~60m

    One room a week. Log it and write up the interesting ones.

  4. Recon with Nmap and Metasploit ~60m

    Know the attacker side so the detections make sense.

  5. Publish one write-up ~2.0h

    Post it. Link it from the resume.

# 6. going deeper

Optional for SOC, central for malware and exploit roles. Do these after the first application round, not before.

  1. Password cracking ~45m

    Hashes, wordlists, why policy matters.

  2. Applied cryptography ~60m

    Where crypto actually breaks.

  3. C and x86 assembly ~90m

    Prerequisite for reversing.

  4. Reverse engineering ~90m

    Ghidra and IDA basics.

  5. Malware analysis ~90m

    Static first, then dynamic, in an isolated VM.

  6. Binary exploitation ~90m

    Stack, heap, mitigations.

  7. Big-O and data structures ~45m

    Needed for software interviews.

  8. Cloud fundamentals ~90m

    IAM, storage, networking and logging in a cloud provider.

  9. Web and databases track ~90m

    HTTP, auth, injection, schema design.

# 7. job hunt

Start this at stage 3, not at the end. Applications teach you what the market wants.

  1. Pick a resume view and fix the headline ~30m

    One per role: IT, Cyber, Software / Data.

  2. Read the bullet bank ~30m

    Match real experience to a posting's keywords.

  3. Start the application tracker ~15m

    Log every application the day you send it.

  4. Interview prep: your own projects ~90m

    Be able to explain every line on the resume.

  5. Practice the path's interview questions ~60m

    Easy, normal and hard tiers per path.

  6. Send five applications this week ~2.0h

    Quantity early, tailoring later. Follow up after a week.
