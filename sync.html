~/sync

Your progress (quizzes, checklists, flashcards, labs, settings) is saved in this browser. Link it once and it also saves itself to a secret GitHub Gist you own, then loads on every other device you link. Nothing goes to any server of mine, and nothing is stored in the site's repo.

Status: checking

Link this device (about a minute)

  1. Open github.com/settings/tokens/new (classic token, the gist box is already ticked). Set expiration to "No expiration", click Generate, copy the token.
  2. Paste it here and press link:

On your other device, do the same with the same token: it finds the gist by itself. If both devices already hold progress, the most recently changed copy of each item wins, so use the export below first if you want a backup.

Linked

It saves a few seconds after each change and when you leave a page, and loads when you open the site.

Backup file

Works with or without linking: download everything, or load a file made on another device.

How safe is it

  • The token is kept only in this browser's storage (not synced, not exported, not in the repo). It can do one thing: read and write your gists. Revoke it any time at github.com/settings/tokens.
  • A secret gist is not listed publicly but anyone with its link could read it. It holds only study progress. Do not put anything private in notes fields you sync.
  • Merging is per item, newest change wins. Two devices changing the same item between syncs keeps the later one.
