~/cases

Real exploits and malware, explained for defenders. Each case has the story, the timeline, the root cause, a short excerpt of the publicly documented vulnerable code with the patch, how it was detected, and the lessons.

Education only. No case contains a working exploit or working malware. Where code is shown it is a short, abridged excerpt of the public source and its fix, explained line by line. Labs use fictional toy programs with the same bug class, so you find the bug and fix it. Summary table: man cases.

  • [----]Morris worm (1988) The first internet worm: a gets() overflow, a debug backdoor and weak passwords. Lab: fix the bugdebug
  • [----]Heartbleed (2014) A missing bounds check in OpenSSL leaked server memory. Real code, line by line. Lab: count the leakdebug
  • [----]WannaCry and EternalBlue (2017) A leaked SMB exploit, a ransomware worm and a kill switch, at concept level. Lab: find unpatched hostsshell
  • [----]Stuxnet (2010) Malware built to break centrifuges: zero-days, signed drivers, air gapsshell
  • [----]Log4Shell (2021) A log line that fetched code: JNDI lookups in Log4j 2. Real code, patch, and detection. Lab: hunt it in logsshell
