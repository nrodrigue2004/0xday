~/web

The web half of the job: what the OWASP Top 10 means in practice, how to drive Burp Suite, how login and sessions break, and how APIs fail. Each chapter goes simple, mid, complex and ends in a hands-on lab against a made-up app.

Course: WEB300 has the module checklist, quizzes and an exam. Every target here is fictional. PortSwigger Web Security Academy is the free practice ground this section points at; it is the best hands-on material there is, so we summarize and link rather than copy it.

  • [----]OWASP Top 10 All ten categories in plain words, what each looks like in a real app and the fix. Lab: sort a scan report by categoryshell
  • [----]Burp Suite workflow Proxy, scope, Repeater, Intruder, Decoder and the habits that keep testing clean. Lab: find the tampered request in a Burp logshell
  • [----]injection and XSS SQL, command and template injection plus XSS: how each works, how to confirm it safely and how to fix it. Lab: read the vulnerable codeshell
  • [----]authentication and sessions Password storage, MFA, cookies, session fixation and JWT mistakes. Lab: decode a weak tokenshell
  • [----]access control, CSRF and SSRF IDOR, privilege escalation, CSRF tokens and server-side request forgery. Lab: find the broken authorization in an access logshell
  • [----]API security The OWASP API Top 10, mass assignment, rate limits and GraphQL pitfalls. Lab: triage an API gateway ticketticket
  • [----]bug bounty How programs work, reading scope, a safe first-hunt routine, writing a report and the legal lines. Lab: decide which hosts are in scopeshell

progress: [####] = all levels read (plus lab solved, if any). Saved in your browser. Reference: man web-sec
