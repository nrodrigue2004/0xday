~/bullets

Every bullet on the resume in one place, built from the same data as ~/resume, so the two cannot disagree. Paste a job posting and it ranks the bullets that fit and lists the keywords the resume doesn't cover yet, with a guide to study for each. It only reorders what is true: don't add a claim you couldn't defend in an interview.

    Add bullets with [+], then copy the set into an application or a tailored resume. Order is the order you added them.

      # writing a good one

      • Lead with a strong verb: built, configured, investigated, reconstructed, automated.
      • Then the thing, then the tool, then the outcome if you truly have one.
      • Numbers only when real. "7-VM environment" is a number you can defend; an invented percentage is not.
      • One line each. If the interviewer asks "tell me more" and you can't, cut the bullet.
