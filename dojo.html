~/dojo

Daily drills. A kata is a small problem you solve from a blank file, over and over, until the moves are automatic. Martial artists run kata to stay sharp; I run these across every language I ship in, from Python scripts to C and raw x86.

Each kata starts simple and the set climbs to hard. Write the code yourself, hit run, and the tests go green or tell you exactly what broke. Hints are there if you want them, and the reference solution unlocks after your first attempt. Visitors are welcome to grab a belt too.
