~/code

A practice path for the programming a security job actually uses: Python, shell, PowerShell, SQL, git and the data structures behind detection logic. Every chapter has three levels (simple, mid, complex), a hands-on lab in the browser, and its commands on the cheatsheets.

Each lab is a small piece of real work: parse an auth log, enrich alerts with an API response, rank assets in an IDS table, find the commit that deleted the logs, write a sliding-window brute-force detector. Do them in order, or jump to whichever language the job post asks for.

  • [----]1 · script · Python for automation read logs, parse JSON, enrich with an API, write a tool that exits cleanlylab
  • [----]2 · shell · Bash pipelines and scripts grep, awk, sort, uniq, loops, set -euo pipefail, cronlab
  • [----]3 · windows · PowerShell for admins object pipelines, event logs, CSV, Invoke-RestMethod, functionslab
  • [----]4 · data · SQL for analysts group, join and count your way through an alert tablelab
  • [----]5 · history · Git for your scripts history, blame, bisect, secrets and guardrails for automationlab
  • [----]6 · structures · Data structures in practice dict, set, deque and heap solving real detection problemslab

progress: [####] = all levels read and the lab solved. Saved in your browser.

  • ~/dojo: daily katas in nine languages. Chapters here teach the task, the dojo is the reps.
  • ~/bigo: why a set beats a list and a window beats a counter. The cost tables behind stage 6.

Scripts here run against made-up logs and public example IPs only. Never point automation at systems or APIs you are not allowed to use, and keep keys in the environment, not the file.
