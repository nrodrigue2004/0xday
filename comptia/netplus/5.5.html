5.5 Tools and Protocols

study notes

Software Tools

  • Protocol analyzer (Wireshark): decodes captured frames from wired or wireless links. Devices can capture natively and export files. Some sites capture all packets to disk for later search.
  • nmap (network mapper, an active scanner): finds hosts in a range (even with layer-2 scans on the same subnet, so rogue devices can't hide), open ports, services and versions, OS guesses, and runs scripts (NSE). Unexpected open ports (the example showed 22, 80, 443, 548 AFP, 2049 NFS) need investigation.
  • CDP (Cisco proprietary) and LLDP (vendor-neutral, IEEE) are discovery protocols: neighbors announce name, addresses, port, native VLAN and software, so you learn the wiring and config without logging in.
  • Speed tests: measure download and upload before and after a change and at different times of day. Test sites differ by distance and load; your ISP's own site is often the most accurate (also fast.com, speedtest.net).

Command Line Tools

  • ping: ICMP echo request/reply; shows reachability, TTL, round-trip time, loss. Ctrl+C prints statistics (continuous ping on Linux and macOS; Windows -t). First test on any problem.
  • traceroute (tracert on Windows): maps the routers on the path by sending packets with TTL 1, 2, 3 and so on; each router answers ICMP time exceeded, revealing its IP and latency (three probes per hop). * means ICMP is filtered or lost. Compare traces to find where a path breaks. Windows uses ICMP echo; Linux and macOS default to UDP and can change the payload.
  • nslookup (deprecated) and dig: query DNS directly (A, MX, TXT and more) and choose a server (dig @1.1.1.1 example.com). Several A records can exist for redundancy.
  • tcpdump (Linux/macOS; WinDump on Windows): CLI packet capture with filters, saves pcap files for Wireshark.
  • netstat: -a all connections and listeners, -n numeric (no DNS), -b (Windows) shows the executable, shows states (established, waiting, closing).
  • ipconfig (Windows; /all adds MAC, DHCP, DNS), ifconfig (Linux/macOS, deprecated) and ip address (modern Linux) show IP settings.
  • arp -a: local ARP cache of IP-to-MAC pairs (works on every OS). Pinging a host fills the entry; use the MAC to look it up in a switch's MAC table.

Hardware Tools

  • Tone generator + inductive probe: put an analog tone on a wire, hold the probe near cables to find the far end in a bundle. Many probes also test continuity.
  • Cable tester: continuity only (pins 1 to 8 in order, shorts, opens, crossed wires); it doesn't certify a category. Certifier does the category tests.
  • Taps: copy traffic to an analyzer. Physical tap (breaks the link at install; passive = unpowered, common on fiber; active = powered, regenerates the signal). Port mirror / SPAN: switch copies a port's traffic to another port; limited by the mirror port's bandwidth (a 2 Gb stream cannot fit a 1 Gb mirror), so use a tap for heavy links.
  • Wi-Fi analyzer: shows channels, strengths, APs and interference; spectrum analyzer shows every signal on a range of frequencies (microwave ovens, non-Wi-Fi sources) and signal-to-noise ratio.
  • Visual fault locator (VFL): a fiber flashlight; light leaks out where the fiber is broken or bent too much.

Basic Network Device Commands

  • Syntax varies by vendor but the ideas match. Examples (Cisco-style): show mac address-table, show ip route (codes: C connected, S static, R RIP, plus a more specific route wins), show interface (up/down, line protocol, speed, duplex, MTU, CRC, drops, input/output errors, rates), show running-config (active config; show startup-config for stored), show arp, show vlan, show power inline (PoE use: for example 370 W capacity, 40 W used, 330 W free).

flashcards

self-check

1. You need to find which wall jack cable in a thick bundle goes to a switch port. Tool?

  • a) Tone generator and inductive probe
  • b) Spectrum analyzer
  • c) Visual fault locator
  • d) Port mirror
answer

a) Trace the tone at the far end.

2. Pings succeed to the gateway but not to a remote site. Which tool shows where the path stops?

  • a) traceroute
  • b) ipconfig
  • c) arp
  • d) show vlan
answer

a) Hop-by-hop path.

3. Which command shows a switch CRC counter and duplex?

  • a) show interface
  • b) show arp
  • c) show vlan
  • d) show route
answer

a) Interface statistics.

4. To capture all traffic crossing a busy 10 Gb link without loss, best choice?

  • a) Port mirror to a 1 Gb port
  • b) Physical tap
  • c) nmap
  • d) tracert
answer

b) A tap avoids mirror port oversubscription.

short lab: Command picker

Pick one command for each: (1) who is using TCP 443 on this PC, (2) MX records for example.com, (3) which switch port has MAC aa:bb:cc:dd:ee:ff, (4) is PoE power left on the switch.

walkthrough

(1) netstat -ano (or -b). (2) dig example.com MX. (3) show mac address-table address aa:bb:cc:dd:ee:ff. (4) show power inline.
