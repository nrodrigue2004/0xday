2.1 Routing Technologies

study notes

Static Routing

  • A router reads the destination IP, looks it up in its routing table, and sends it out the interface toward the next hop. Directly connected subnets are known automatically. If there is no matching route the packet is discarded.
  • Static route = admin types it by hand on each router: destination/prefix via next-hop. Example: on router 1, send 10.10.20.0/24 to next hop 10.10.40.2 and 10.10.30.0/24 to 10.10.50.2.
  • Pros: instant, no CPU or memory overhead, no protocol traffic, predictable and fairly secure, ideal for stub networks (one link in and out) or small networks. Cons: does not scale to hundreds of routers, easy to mistype and create a routing loop, no automatic rerouting when a link fails.

Dynamic Routing

  • Routers discover routes and tell each other via routing protocols (updates are often multicast). They adapt automatically to added or removed routers. Costs: CPU and memory, plus initial planning and config.
  • EIGRP: Cisco-centric, easy to set up, converges fast, loop avoiding, efficient updates (admin distance 90).
  • OSPF (open shortest path first): open standard, multi-vendor, a link-state protocol used inside one autonomous system (AS) (everything you control). Picks the lowest cost (based on bandwidth, link state, delay) and can load-balance equal-cost paths (admin distance 110).
  • BGP (border gateway protocol): the exterior gateway protocol that routes between autonomous systems and runs the internet and WAN/ISP connections ("three napkins protocol").
  • RIP: old, hop count metric (admin distance 120).
  • Choose by what decides the best route (link state, hop count, speed), convergence speed, and vendor environment.

Routing Technologies

  • Reading an entry (Cisco style): code letter (C connected, S static, R RIP, D EIGRP, O OSPF, B BGP), destination/prefix, [AD/metric], via next-hop, age, outgoing interface.
  • Best-match order: 1) longest prefix (most specific route wins; for 192.168.1.6 a /32 beats /24 beats /16), 2) lowest administrative distance (trust of the source: connected 0, static 1, EIGRP 90, OSPF 110, RIP 120; lower is better), 3) lowest metric within one protocol (RIP = hop count, EIGRP and OSPF use their own calculations; metrics are not comparable across protocols).
  • FHRP (first hop redundancy protocol): two routers share a virtual IP used as the clients' default gateway. The active router owns it and the standby takes it over if the active router disappears, so clients never change settings (HSRP, VRRP are examples).
  • Subinterfaces: one physical router interface split into virtual ones (e1/1.10, e1/1.20) so each VLAN on a trunk gets its own IP address ("router on a stick").

Network Address Translation

  • IPv4 ran out, NAT lets many private hosts share public addresses (private ranges in RFC 1918). Static/dynamic NAT swaps one private address for one public address (source address rewritten on the way out, destination rewritten on the way back).
  • NAT overload / PAT (port address translation): many inside hosts share one public IP, told apart by translated port numbers kept in the NAT table (10.10.20.50:3233 becomes 94.1.1.1:1055, the next host gets 94.1.1.1:1056). This is what your home router does.

flashcards

self-check

1. A routing table has 10.0.0.0/8 via R1 (OSPF) and 10.1.0.0/16 via R2 (RIP). Traffic for 10.1.5.5 goes where?

  • a) R1 because OSPF has lower AD
  • b) R2 because /16 is more specific
  • c) Both
  • d) Dropped
answer

b) Longest prefix match is applied before administrative distance.

2. A small branch with one ISP link needs routing with minimal overhead. Best?

  • a) BGP
  • b) OSPF
  • c) Static/default route
  • d) EIGRP
answer

c) Stub network.

3. A hundred laptops share one public IP address. What feature?

  • a) Static NAT
  • b) PAT
  • c) FHRP
  • d) VXLAN
answer

b) Port translation distinguishes sessions.

short lab: Read a route line

Interpret R 10.0.30.0/24 [120/1] via 10.10.50.2, 00:00:14, Serial0/3/1.

walkthrough

RIP-learned route to 10.0.30.0/24, administrative distance 120, metric 1 hop, next hop 10.10.50.2, learned 14 seconds ago, leaves via Serial0/3/1.
