study notes

Understanding the OSI Model

The OSI model is a seven-layer vocabulary for describing where something happens on a network. It is not a protocol suite and real traffic is TCP/IP, but "that's a layer 2 problem" means the same thing to everyone. One layer holds many protocols, and several layers often collapse into one in practice.

Top to bottom: 7 Application, 6 Presentation, 5 Session, 4 Transport, 3 Network, 2 Data link, 1 Physical (mnemonic: All People Seem To Need Data Processing).

layernicknamewhat lives heretroubleshooting hint
1 Physicalsignalscables, fiber, radio, adapters, hubsbad cable or fiber, interference, loopback tests, cable testers
2 Data linkswitching, MAC layerEthernet frames, MAC (EUI-48/EUI-64) addresses, switches, bridges, access points (802.11 to 802.3)MAC table, port problems, VLANs
3 NetworkroutingIP addresses, subnet masks, routers, fragmentationwrong IP/mask/gateway, routing
4 Transportpost officeTCP and UDP, port numbers, segmenting and reassemblyfirewall port blocks, ports not listening
5 Sessioncontrolsetting up, maintaining, ending and restarting sessions, tunneling and control protocols
6 Presentationformattingcharacter encoding, encryption and decryption (TLS)
7 Applicationwhat you seeHTTP/HTTPS, FTP, DNS, POP3 and the app itselfthe application's own errors
  • Any hardware address, switch behavior or frame is layer 2. Anything with an IP or a subnet mask is layer 3. Anything with a TCP/UDP port is layer 4.
  • A Wireshark decode reads bottom-up through the layers: frame summary (L1), Ethernet II with MAC addresses (L2), IP (L3), TCP with ports (L4), then TLS and the application (L5-7 together). Destination port 443 tells you it is HTTPS.
  • Layers 5-7 are often lumped together because TLS-wrapped applications blur them.

flashcards

self-check

1. A user can ping the server by IP but a specific app on TCP 8080 fails while others work. Which layer is the most likely culprit?

  • a) Layer 1
  • b) Layer 2
  • c) Layer 4
  • d) Layer 6
answer

c) Reachability by IP is fine (layers 1-3). A single port failing points to the transport layer (listener or firewall rule).

2. A switch keeps flooding traffic for one host. Which address does it use to decide where to forward?

  • a) Source IP
  • b) Destination MAC
  • c) Destination port
  • d) VLAN name
answer

b) Switches forward on destination MAC, so it is layer 2.

short lab: Place each item on a layer

Place each on the OSI layer: (1) 00:1A:2B:3C:4D:5E (2) 10.4.4.9/24 (3) TCP 443 (4) a CAT6 patch cable (5) an HTTP GET (6) TLS handshake.

walkthrough

(1) layer 2 (MAC), (2) layer 3 (IP and mask), (3) layer 4 (port), (4) layer 1, (5) layer 7, (6) layer 6 (encryption), with the session setup arguably layer 5.
