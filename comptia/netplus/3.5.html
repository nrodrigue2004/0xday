3.5 Network Access

study notes

VPNs

  • A VPN encrypts traffic across a public network to a VPN concentrator (often the firewall). Client-to-site: VPN client software on a laptop, started manually or always-on. Site-to-site: concentrators at two sites build a permanent encrypted tunnel; users are unaware. Clientless VPN: runs in an HTML5 browser (web cryptography API), no software to install.
  • Full tunnel: all client traffic goes through the VPN (corporate controls everything but it adds a detour for internet traffic). Split tunnel: only corporate-bound traffic uses the VPN, other traffic goes straight to the internet (more efficient, less visibility and protection).

Remote Access

  • SSH (TCP 22): encrypted remote terminal, replaces Telnet (TCP 23, clear). RDP for remote Windows desktops, VNC (uses the RFB protocol, many OSes) for graphical control. API: automate device management with the device's own language, with error handling, instead of scripts over CLI.
  • Console: direct serial connection to a device (RJ45 serial, DB9, or USB-to-serial) with a text CLI. Works even when the network is down. Jump server (jump box): a hardened, MFA-protected host you reach through VPN or SSH, then hop to internal devices. Keep it patched.
  • In-band management: reach the device over the network via its management IP using SSH or a web GUI (sometimes a dedicated management interface). Out-of-band management: a path that does not use the production network: serial console/COM port, a separate management network, even a modem on a phone line or a COM server to dial in when everything else is down.

flashcards

self-check

1. A switch is unreachable by IP after a bad config push. Best way to fix remotely?

  • a) SSH
  • b) Out-of-band console via COM server or modem
  • c) RDP
  • d) SNMP
answer

b) The management path that does not rely on the broken network.

2. A remote user wants to browse the corporate intranet and also the public internet without detours through HQ. Which?

  • a) Full tunnel
  • b) Split tunnel
  • c) Site-to-site
  • d) GRE
answer

b) Only corporate traffic is tunneled.

short lab: Pick the access method

For each: (1) help desk fixes a user's Windows desktop, (2) engineer edits a core router from home, (3) core router crashed and lost its IP config.

walkthrough

(1) RDP (or VNC) to the desktop. (2) VPN, then jump server, then SSH to the router. (3) Console or out-of-band serial access.
