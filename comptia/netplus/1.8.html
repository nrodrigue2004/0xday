1.8 Network Environments

study notes

Software Defined Networking

  • Every network device has three planes. Data plane (infrastructure layer): the forwarding itself (moving frames between interfaces, trunking, encryption, NAT). Control plane: the tables and logic that decide where traffic goes (routing, switching, NAT, firewall rule tables). Management plane (application layer): how admins configure it (SSH, console, web GUI). SDN splits these into software so they can be virtualized and centrally controlled.
  • SD-WAN: a WAN built for cloud-era traffic. It is application aware (it knows it is email or a database and sends it straight to the nearest cloud service instead of back through HQ), transport agnostic (fiber, 5G, DSL all fine), has central policy management (one console pushes policy to all SD-WAN routers) and zero-touch provisioning (devices update themselves when services move).

Virtual Extensible LAN (VXLAN)

  • Problem: apps and VMs span multiple data centers (data center interconnect, DCI) with different IP schemes and links. VLANs top out around 4,000 networks and are layer 2 only. VXLAN supports about 16 million virtual networks (24-bit VNI) and runs over a layer 3 network.
  • Each data center has a VTEP (VXLAN tunnel endpoint, often the top-of-rack switch). Networks are named by a VNI. The original Ethernet frame is encapsulated in VXLAN inside UDP inside IP, routed across, then decapsulated on the far side, so VMs in different sites feel they are on the same LAN.

Zero Trust

  • Edge-only security leaves the inside wide open. Zero trust: every user, device and application is untrusted until verified, with authentication, encryption, extra firewalls and monitoring everywhere.
  • Policy-based / adaptive authentication weighs who, where, from which IP, what connection and what time. Inside HQ in work hours = password; unknown foreign IP over VPN at 3 a.m. = more factors or deny.
  • Authorization follows: role (help desk can read, the manager can edit), location, whether it is a managed laptop with a valid certificate. Least privilege: only the rights the job needs, never admin by default (malware on an admin's box gets admin everywhere).
  • SASE (secure access service edge): security in the cloud near the apps, with a client on every device. "Next-generation VPN." Combines networking (QoS, routing) with ZTNA, firewall as a service and DNS security, always on, for users anywhere reaching apps anywhere.

Infrastructure as Code

  • IaC: describe servers, networks, firewalls and apps in files and let the platform build them. Rebuild identically in another data center, version changes, redeploy. Cures configuration drift, enforces compliance, makes test = production, and documents the build.
  • Playbooks: scripted response steps (breach investigation, ransomware recovery: remove from network, wipe, reimage, redeploy). Centralized in SOAR (security orchestration, automation and response).
  • Source / version control (Git): one central repository, tracked changes, branches for testing, merging, conflict detection when two people edit the same line.

IPv6 Addressing

  • IPv4: 32 bits, 4.29 billion addresses, exhausted, extended by NAT. IPv6: 128 bits, hexadecimal, eight 16-bit groups separated by colons. Example fe80::5d18:652:6ffd:8f52.
  • Compression rules: drop leading zeros in each group, and replace one run of all-zero groups with :: (only once per address). 2601:04C3:4002:BE00:0000:0000:0000:0066 becomes 2601:4C3:4002:BE00::66. 2600:DDDD:1111:0001:0000:0000:0000:0001 becomes 2600:DDDD:1111:1::1.
  • IPv4 and IPv6 cannot talk directly. Bridges: dual stack (host runs both, separate routing tables, the common method today), tunneling (6to4: IPv6 over IPv4, needs a relay, no NAT, removed from Windows. 4in6: IPv4 over IPv6; both rare now), NAT64 + DNS64 (DNS64 hands an IPv6-only client a synthesized IPv6 address that points at the NAT64 router, which translates to the real IPv4 server).

flashcards

self-check

1. Admin logs in to a switch over SSH to change a setting. Which plane?

  • a) Data
  • b) Control
  • c) Management
  • d) Physical
answer

c) Admin access is the management plane.

2. Two data centers use different IP schemes but VMs must act as if on the same LAN. Best fit?

  • a) VLAN
  • b) VXLAN
  • c) APIPA
  • d) 6to4
answer

b) VXLAN overlays layer 2 over a layer 3 network.

3. Which technique prevents a dozen servers from drifting apart in configuration?

  • a) IaC
  • b) Dual stack
  • c) PoE
  • d) QoS
answer

a) One definition applied everywhere.
