1.3 The Cloud

study notes

Designing the Cloud

  • Cloud traits: elasticity (scale up and down with demand), access from anywhere, multitenancy (many customers share one infrastructure, which is what makes it cheap).
  • NFV (network function virtualization): routers, switches and firewalls become virtual appliances on the hypervisor. Same functions, deployed with a click instead of a truck and a rack.
  • VPC (virtual private cloud): a private, isolated chunk of cloud holding your web servers, databases, load balancers and virtual network gear. Big orgs use one VPC per app or business unit.
  • Transit gateway: a cloud router that links many VPCs. A VPN into the transit gateway gives remote users access to all of them.
  • Internet gateway: makes a VPC reachable from the public internet. NAT gateway: lets private instances reach out to the internet without being reachable from it. VPC endpoint: a private connection from a VPC to another service or provider so traffic never crosses the open internet (useful to reach a private subnet).
  • Security lists (applied to whole subnets/VCNs, coarse) vs security groups / network security groups (attached to individual virtual NICs, fine-grained, but more to administer). Rules are protocol + port + source/destination (single IP or CIDR block, IPv4 or IPv6), inbound and outbound, like a stateful firewall in front of the instance. Need more? Add a virtual firewall.

Cloud Models

  • Deployment: public (anyone, run by a provider), private (your own virtualized data center), hybrid (both).
  • Service models (who manages what): SaaS the finished app, you just log in and bring data (Gmail, Office 365). PaaS the provider gives the platform and tools, you build and maintain the app (Salesforce platform). IaaS (HaaS) you get raw compute, storage and network, and you install, patch and secure the software and data. Responsibility moves toward the provider as you go IaaS to PaaS to SaaS, but you always own your data, accounts and devices. On-prem is all yours, including the building.

flashcards

self-check

1. A company runs private VMs in a cloud and needs them to download patches without being reachable from the internet. Best component?

  • a) Internet gateway
  • b) NAT gateway
  • c) Transit gateway
  • d) Load balancer
answer

b) NAT gateways allow outbound-only access.

2. You need to deploy your own custom app and let the provider handle the OS and runtime. Which model?

  • a) SaaS
  • b) IaaS
  • c) PaaS
  • d) On-prem
answer

c) PaaS provides the platform. You supply the application.

short lab: Sketch a small cloud network

Design on paper: two app tiers in separate subnets, only the web tier public, remote admins via VPN, tier-to-tier traffic only on the DB port. Name the cloud components you use.

walkthrough

Web subnet behind an internet gateway, app/DB subnets private. NAT gateway for outbound patches. VPN to a transit gateway (or the VPC) for admins. Security group on the DB allows only the app tier on its DB port (for example TCP 3306); web security group allows TCP 443 from anywhere.
