3.1 Summarize concepts related to attack methodology frameworks

study notes

Frameworks give a shared vocabulary for describing and predicting attacks.

  • Cyber Kill Chain (Lockheed Martin), seven linear phases: Reconnaissance → Weaponization → Delivery → Exploitation → Installation → Command and Control → Actions on Objectives. Defender idea: break any link and the attack fails. Weak at insiders and lateral movement because it is linear.
  • Diamond Model: every event has four vertices: adversary, capability, infrastructure, victim. Pivot between them: find an attacker domain (infrastructure), then other victims hitting it. Also has meta-features such as timestamp, phase, result, direction, methodology.
  • MITRE ATT&CK: matrix of tactics (columns, the why) and techniques/sub-techniques (the how, T1566.001), with real-world groups, software and detections. Use it for detection coverage gaps, hunt ideas and reporting. Not linear, not every technique is used.
  • Pick: kill chain for explaining stage and where to block, diamond for linking intrusions and attribution, ATT&CK for detail and coverage.

flashcards

self-check

1. An attacker sends a malicious attachment. Which kill chain phase?

  • a) Reconnaissance
  • b) Delivery
  • c) Installation
  • d) C2
answer

b) Delivery is transmitting the weapon.

2. You found attacker infrastructure and now want to find other victims of the same actor. Model?

  • a) Kill chain
  • b) Diamond Model
  • c) STRIDE
  • d) CVSS
answer

b) Pivoting from the infrastructure vertex.

short lab: Map an intrusion

Phish email with macro doc → PowerShell downloads implant → implant calls 203.0.113.9 hourly → attacker dumps LSASS → exfil to cloud storage. Give kill chain phases and ATT&CK tactics.

walkthrough

Kill chain: delivery (email), exploitation (macro), installation (implant), C2 (hourly beacon), actions on objectives (cred dump, exfil). ATT&CK tactics: Initial Access (T1566), Execution (T1059.001), Command and Control, Credential Access (T1003.001), Exfiltration (T1567).
