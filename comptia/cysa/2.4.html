CS0-004domain 2.0 · Vulnerability Management2.4

2.4 Explain concepts related to control types, risks, and vulnerability management

study notes

  • Control types (what it is): administrative (policy, training), technical (firewall, encryption), physical (locks, cameras). Control functions (what it does): preventative (stops), detective (spots), responsive (reacts), corrective (fixes or restores).
  • Risk: inherent (before controls), residual (after controls), risk appetite (how much the organization will accept). Strategies: accept, transfer (insurance, vendor contract), avoid (stop the activity), mitigate (reduce with controls).
  • Policies, governance and SLOs: policy sets the rule (patch criticals within 7 days), governance assigns owners and review, service-level objectives turn them into measurable targets.
  • Application security: SAST reads source code without running it (early, many false positives). DAST attacks the running app (finds runtime and config flaws, later in the cycle). SAMM (OWASP Software Assurance Maturity Model) assesses and improves secure development practices.
  • Third-party risk: vendors and libraries can carry flaws. SCA finds vulnerable open-source components, SBOM is the ingredient list of your software so you can quickly answer "are we affected by this CVE".

flashcards

self-check

1. A company decides to stop offering a risky legacy feature entirely. Strategy?

  • a) Accept
  • b) Transfer
  • c) Avoid
  • d) Mitigate
answer

c) Eliminating the activity avoids the risk.

2. A new Log4j-like CVE is announced. What helps you find affected software fastest?

  • a) SBOM
  • b) SAMM
  • c) DAST
  • d) Honeypot
answer

a) The SBOM lists the components you ship.

walkthrough

(1) responsive, (2) detective, (3) corrective, (4) preventative.
