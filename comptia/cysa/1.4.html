1.4 Explain threat intelligence and threat-hunting concepts

study notes

Threat actors

  • APT: well-funded, patient, targeted, persistent. Usually nation-state or state-linked, with custom tooling and long dwell time.
  • Insider threat: current/former employee or contractor with legitimate access. Intentional or accidental. Detect with DLP, UEBA and access reviews.
  • Others to separate: hacktivists (ideology), organized crime (money), script kiddies (low skill).

TTPs and models

  • TTPs describe how an adversary operates: tactic = goal, technique = method, procedure = the specific implementation.
  • MITRE ATT&CK catalogs tactics and techniques (Initial Access, Execution, Persistence, Privilege Escalation, Defense Evasion, Credential Access, Discovery, Lateral Movement, Collection, C2, Exfiltration, Impact). Heat maps overlay your detection coverage or an actor's techniques on the matrix to show gaps.
  • Pyramid of Pain ranks IoC types by how much it hurts the attacker when you block them. Bottom to top: hash values, IP addresses, domain names, network/host artifacts, tools, TTPs. Hashes are trivial to change, TTPs are painful.
  • Attribution (who did it) is hard and rarely needed to defend. Do not over-invest.

Confidence

Rate intel on timeliness (stale IPs lie), relevance (does it touch your sector/tech?) and accuracy (corroborated by multiple sources?). Low-confidence intel gets monitored, high-confidence gets blocked.

Sources

  • OSINT: public (news, social media, paste sites, WHOIS, Shodan, vendor blogs). Closed-source: paid feeds, government, private vendors. Sharing: ISACs/ISAOs, MISP communities, STIX/TAXII formats.

Indicators of compromise

Collect, analyze (is it real, scope, context), apply (detections, blocks, retro-hunts). Atomic IoCs stand alone (IP, hash, domain). Behavioral IoCs describe actions (Office spawns PowerShell, then LSASS access). Atomic ages fast, behavioral lasts.

Threat modeling and deception

  • STRIDE: Spoofing, Tampering, Repudiation, Information disclosure, Denial of service, Elevation of privilege, a checklist to find threats per component.
  • Threat mapping ties threats to your assets and attack paths. Deception: honeypots, honeytokens, decoy accounts. Any touch is a high-fidelity alert.

Hunting

Proactive, hypothesis-driven search that assumes breach and does not wait for alerts. Flow: hypothesis (from intel or ATT&CK) → pick data → query → investigate → document → turn findings into detections.

flashcards

self-check

1. A feed lists an IP flagged 14 months ago. Which confidence factor is weakest?

  • a) Relevance
  • b) Timeliness
  • c) Accuracy
  • d) Attribution
answer

b) Old IPs get reassigned, so the indicator is probably stale.

2. Which IoC is the cheapest for an attacker to change?

  • a) File hash
  • b) TTP
  • c) Toolset
  • d) Process behavior
answer

a) One recompile changes it.

short lab: Write a hunt hypothesis

Write one hunt hypothesis for ATT&CK technique T1053.005 (Scheduled Task) on Windows. State the data source, the query logic, and what a hit would look like.

walkthrough

Hypothesis: attackers persist with scheduled tasks created from user-writable paths. Data: Windows event 4698 (task created) plus Sysmon process creation for schtasks.exe. Query: tasks whose action path is under AppData, Temp or Public, or whose command line has -enc. A hit: task named like a system task ("GoogleUpdateTaskX") running a script from AppData, created by a non-admin user soon after a phishing email. Result becomes a permanent detection rule.
