study --objective 1.3 --exam CS0-004

CS0-004domain 1.0 · Security Operations1.3

1.3 Given a scenario, use tools to determine malicious activity

study notes

Know what each tool is for and what its output looks like. Exam scenarios hand you a snippet and ask what it means.

Decode and parse

  • CyberChef: browser "recipe" tool for base64, hex, XOR, URL decoding, gunzip, regex extraction. Chain operations on the fly.

Packets and network sensors

  • Wireshark: GUI packet analysis. Display filters: ip.addr == 10.0.0.5, tcp.port == 4444, http.request, dns, tcp.flags.syn == 1 && tcp.flags.ack == 0. Follow TCP stream shows a whole conversation.
  • tcpdump: CLI capture, BPF filters: tcpdump -i eth0 -w cap.pcap host 10.0.0.5 and port 443. -nn skips name resolution.
  • Snort / Suricata: signature IDS/IPS. Rules look like alert tcp $EXTERNAL_NET any -> $HOME_NET 22 (msg:"SSH brute"; flags:S; threshold:...; sid:1000001;). Suricata is multi-threaded and also writes EVE JSON.
  • Zeek: not signatures. It turns traffic into structured logs (conn.log, dns.log, http.log, ssl.log, files.log), ideal for hunting.

Logs and intelligence

  • SIEM: collects, normalizes, correlates and alerts (Splunk, Elastic, Sentinel). Know queries by shape: filter, group, count, sort.
  • Threat intel platforms: OTX (community pulses of IoCs), MISP (open-source sharing platform), OpenCTI (knowledge graph for CTI).

Endpoint

  • EDR/XDR: endpoint telemetry with response (isolate host, kill process). XDR also pulls in email, network and cloud. MDM manages mobile devices (wipe, policy).

Reputation and file analysis

  • WHOIS, AbuseIPDB, GEO-IP for domain/IP age, ownership, abuse reports and location. A domain registered three days ago is suspicious.
  • strings finds readable text in binaries (URLs, commands). VirusTotal checks hashes/files against many engines (do not upload sensitive files, upload the hash). YARA rules match patterns in files or memory: rule X { strings: $a="cmd.exe /c" condition: $a }.
  • Sandboxes (Joe Sandbox, Cuckoo) run a sample safely and report behavior (files, registry, network). Beware sandbox-aware malware that sleeps.
  • MXToolbox checks mail records (MX, SPF, DKIM, DMARC) and blacklists.
  • UEBA (for example OpenUBA) baselines user behavior and flags deviations.

Patterns, formats, scripts

  • Regex: \d{3}-\d{2}-\d{4} (SSN-like), (?:\d{1,3}\.){3}\d{1,3} (IPv4), [A-Za-z0-9+/=]{40,} (base64 blob).
  • Formats: JSON (objects, key/value), XML (tags), YAML (indentation, config and rules), EVTX (Windows event log, read with Event Viewer or Get-WinEvent).
  • Scripting: Python for parsing and API calls, PowerShell for Windows admin and hunting (Get-WinEvent, Get-Process), shell for quick grep/awk pipelines.

flashcards

self-check

1. You need a quick view of every DNS query a host made last week, from sensor data. Best source?

  • a) Zeek dns.log
  • b) strings
  • c) YARA rule
  • d) MXToolbox
answer

a) Zeek records protocol metadata like DNS in structured logs.

2. Which is a signature-based network IDS/IPS?

  • a) Zeek
  • b) Suricata
  • c) CyberChef
  • d) OTX
answer

b) Suricata (like Snort) matches rules against traffic.

short lab: Pull the beacon out of a conn.log

Given Zeek-style lines of ts, src, dst, dport, bytes: ten rows from 10.0.0.23 to 185.220.1.9:443 at 60-second intervals, 412 bytes each, plus normal browsing to many hosts. Which host is beaconing, how do you prove regularity, and what do you do next?

walkthrough

10.0.0.23. Compute the deltas between timestamps: near-constant 60 s gaps and a constant byte size is machine-driven. Then enrich 185.220.1.9 (WHOIS age, AbuseIPDB, OTX), find the process behind the connection with EDR, check for other internal hosts talking to it, block the IP at the firewall and isolate the host.
