1.8 macOS

study notes

Files, Apps and Folders

  • .dmg: Apple disk image (like an ISO; mounts as a drive). .pkg: installer package that runs an install script. .app: application bundle (a folder of many files; Finder > right-click > Show Package Contents). macOS has no .exe.
  • App Store: central place for apps and updates (Updates tab; automatic or manual). Uninstall most apps by deleting the .app (drag to Trash); some bundle an uninstaller.app.
  • Folders: /Applications (like Program Files), /Users (home directories; your home is /Users/name), /Library (shared support files, fonts, scripts), ~/Library (per-user, hidden by default), /System (core OS files, like \Windows).
  • Apple ID is personal. Businesses use a Managed Apple ID through Apple Business Manager, which integrates with Active Directory and an MDM.
  • Time Machine: automatic backups: hourly for 24 hours, daily for a month, weekly for older months; oldest are deleted when the volume fills. Configure in System Settings; local drive or network volume.
  • Security: some anti-malware built in, but no single AV console; third-party AV exists. Malware is mostly written for Windows but macOS is not immune. Software Update (System Settings > General) updates the OS itself, separate from App Store app updates; betas are optional and risky. Rapid Security Response (RSR) pushes urgent security fixes fast (on by default; also iOS/iPadOS; a letter after the version means an RSR was applied).

System Settings (System Preferences)

  • Windows Control Panel equivalent. Displays (arrangement, resolution, brightness, color), Network (wired/wireless, IPv4/IPv6, DNS, 802.1X, proxies), Printers & Scanners (share, queues, supply levels), Privacy & Security (per-app access to location, files, camera, microphone, photos), Accessibility (vision, hearing, Zoom, third-party app access), Time Machine.

macOS Features

  • Mission Control (Control+Up or three-finger swipe up) shows all windows; Spaces are multiple desktops.
  • Keychain: encrypted password/certificate/notes store unlocked by your login password.
  • Spotlight: search with Command+Space.
  • iCloud: syncs calendar, mail, photos, messages; iCloud Drive for files; built-in backups.
  • Gestures: customizable trackpad swipes and pinches.
  • Finder: file manager (like File Explorer), includes network and screen-sharing locations. Dock: quick launch; dots mark running apps.
  • Continuity: hand off tasks between Mac, iPhone and iPad, use iPhone as a webcam, AirDrop, text forwarding.
  • Disk Utility: partition, format, repair, create images. FileVault: full-disk encryption (like BitLocker) in Privacy & Security. Terminal: command line. Force Quit: Command+Option+Esc, or Option+right-click the Dock icon.

flashcards

self-check

1. A user wants to remove a downloaded Mac app. Easiest:

  • a) Run uninstall.exe
  • b) Drag the .app to Trash
  • c) Use msconfig
  • d) Run regedit
answer

b) Bundles delete cleanly.

2. Which feature encrypts the entire Mac drive?

  • a) Keychain
  • b) FileVault
  • c) Spotlight
  • d) Time Machine
answer

b) FileVault.

3. Which app is hung; keyboard shortcut to kill it?

  • a) Command+Space
  • b) Command+Option+Esc
  • c) Control+Up
  • d) Command+Tab
answer

b) Force Quit window.

4. Company-owned Macs need centralized Apple ID control. Use:

  • a) Personal Apple ID
  • b) Managed Apple ID with Apple Business Manager
  • c) Keychain
  • d) iCloud Drive
answer

b) Managed IDs.

short lab: Mac backup plan

Describe how to protect a Mac user's data from a failed SSD.

walkthrough

Enable Time Machine to an external or network volume, turn on iCloud Drive/Photos sync if allowed, and keep FileVault on; test a restore.
