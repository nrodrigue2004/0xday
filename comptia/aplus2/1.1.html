1.1 Operating Systems

study notes

Operating Systems Overview

  • The OS sits between hardware and applications: it moves data between storage, memory and CPU, handles input and output, manages files, and ships its own maintenance utilities. Apps are written for one OS; a Windows executable will not run on Linux, though document formats (and web apps) move freely.
  • Windows: biggest market share, huge hardware/software support, many editions (10, 11, Server). Downsides: the biggest malware target, and driver quality depends on each hardware vendor.
  • Linux: free and open source, many distributions, runs on almost anything, community support only (no single vendor); newer hardware may lack drivers.
  • macOS: Apple hardware only, polished, security-minded, tightly integrated; costs more and has less industry support.
  • Chrome OS: Google, built on the Linux kernel, browser-centered, light, needs a network connection for most apps.
  • iPadOS: a tablet version of iOS (Safari desktop browser, Sidecar second display, keyboard and multitasking). iOS: closed source, Apple hardware only; apps built with Apple's SDK on macOS and approved by Apple before the App Store. Android: open source, Linux-based, run by the Open Handset Alliance, many hardware makers, apps via Google Play and third-party stores.
  • Watch end of life (each vendor sets its own) and keep systems patched.

File Systems

  • Partitions must be formatted with a file system before data is stored.
  • NTFS: Windows default; compression, encryption, quotas, permissions. Linux/macOS read it (modern ones write too). ReFS: resilient, self-repairing, huge volumes, server-oriented, not widely deployed.
  • FAT32: old, max volume 2 TB and file size 4 GB. exFAT: for flash drives, files over 4 GB, works across Windows, macOS, Linux.
  • ext4: Linux and Android standard. XFS: high-performance, large-volume Linux file system with journaling and low fragmentation. APFS: Apple, tuned for SSDs, built-in encryption and snapshots (iOS, iPadOS, macOS).

flashcards

self-check

1. You need a USB drive with a 10 GB file usable on Windows, macOS and Linux. Format?

  • a) FAT32
  • b) exFAT
  • c) APFS
  • d) ext4
answer

b) exFAT has no 4 GB file limit and is cross-platform.

2. Which OS runs only on the vendor's own hardware and is closed source?

  • a) Android
  • b) Linux
  • c) iOS
  • d) Chrome OS
answer

c) iOS.

3. Which file system is Windows' default?

  • a) ext4
  • b) NTFS
  • c) XFS
  • d) APFS
answer

b) NTFS.

short lab: Pick the file system

Choose a file system: (1) Linux database server with huge volumes, (2) Windows 11 system drive, (3) MacBook SSD, (4) camera memory card shared across OSes.

walkthrough

(1) XFS. (2) NTFS. (3) APFS. (4) exFAT.
