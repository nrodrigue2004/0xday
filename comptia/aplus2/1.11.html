1.11 Cloud Productivity

study notes

Cloud Productivity Tools

  • Many organizations run email in the cloud (Microsoft 365/Outlook, Google Workspace). Providers offer high-speed redundant connectivity, built-in backups, strong physical and logical security.
  • Cloud storage (Google Drive, OneDrive, iCloud Drive) with desktop clients that synchronize a local folder to the cloud and other devices; choose to mirror or store only online.
  • Collaboration: video meetings, shared and co-edited documents in real time, instant messaging, work from anywhere.
  • Identity synchronization: cloud identity providers (Microsoft Entra ID, Okta, Google Identity) keep user records synchronized across directories, so one change (add or remove a user) propagates everywhere.
  • Cloud licensing: manage and reassign license keys centrally; reclaim unused licenses to save money.
