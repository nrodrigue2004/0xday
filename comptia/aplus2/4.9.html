4.9 Remote Access

study notes

Remote Desktop and VPN

  • RDP (Microsoft Remote Desktop Protocol, TCP 3389) has clients on all platforms. VNC uses RFB (Remote Frame Buffer), open source. Open remote desktop ports with weak passwords are brute-force targets; add MFA. Scammers also use remote tools: verify who is asking.
  • VPN: encrypts traffic across public networks to a VPN concentrator (often in a next-gen firewall). Client software or OS built-in VPN. Use MFA at login.
  • SSH: encrypted terminal, TCP 22; Telnet (TCP 23) is cleartext. Harden with key pairs, disable root login, disable passwords (certificate only), IP allow lists.

Management Tools

  • RMM (Remote Monitoring and Management): MSP console to patch, remotely connect, monitor and inventory many customers; a high-value target, so protect with MFA, tight access and auditing.
  • SPICE (Simple Protocol for Independent Computing Environments): remote console for virtual machines with efficient graphics and shared clipboard/folders.
  • WinRM (Windows Remote Management): send a script to a Windows host (needs authentication), run it remotely and receive results with no interactive session (e.g. Get-WmiObject Win32_Service).
  • Third-party tools: screen sharing (GoToMyPC, TeamViewer), video conferencing (Zoom, WebEx), file sync (Dropbox, Box, Google Drive), endpoint management (Citrix Endpoint Management, ManageEngine Desktop Central). Always use MFA and limit to authorized users.

flashcards

self-check

1. An unexpected open TCP 3389 on a workstation indicates:

  • a) Remote Desktop is running
  • b) SSH
  • c) DNS
  • d) Telnet
answer

a) RDP.

2. Secure remote CLI to a Linux server:

  • a) SSH
  • b) Telnet
  • c) RDP
  • d) VNC without password
answer

a) Encrypted.

3. An MSP's RMM needs extra protection because:

  • a) It controls many customers' endpoints
  • b) It is slow
  • c) It uses SPICE
  • d) It uses Telnet
answer

a) High-value target.

4. Run a PowerShell script on a remote server and get results back with no desktop session:

  • a) WinRM
  • b) RDP
  • c) VNC
  • d) SPICE
answer

a) Windows Remote Management.

short lab: Secure remote support

Design a remote support setup for a branch with 10 PCs and a Linux server.

walkthrough

VPN with MFA to the branch, RDP only through VPN (no internet exposure), SSH with keys and no root, restrict by IP, audit logs, vetted remote support tool.
