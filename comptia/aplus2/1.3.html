1.3 Microsoft Windows

study notes

Windows Editions

  • Core 2 covers Windows 10 and Windows 11 (all in-support versions are in scope). There is no Windows 9. Windows 10 support for Home and Pro ended 14 Oct 2025, but it is still seen in production. Windows 11 (Oct 2021) is 64-bit only, new Start menu and taskbar, snap layouts, Teams integration, touch improvements and Copilot.
  • Home: consumer. Microsoft account/OneDrive, Defender, no domain join, no BitLocker (Win 11 Home has Device Encryption, recovery key stored in the Microsoft account), no group policy, Remote Desktop client only, 128 GB RAM max (64-bit).
  • Pro: business. Domain join, BitLocker, Remote Desktop host and client, group policy, Hyper-V, 2 TB RAM max.
  • Pro for Workstations (Win 10): up to four CPUs, 6 TB RAM, ReFS.
  • Enterprise: volume licensing, up to 6 TB RAM, AppLocker, BranchCache, granular UX control; MDM/MAM management (Win 11), ReFS.
  • 32-bit Windows (Win 10 only) caps at 4 GB RAM.
  • N editions (Europe) ship without media player and multimedia tools; add the Media Feature Pack from Settings > Apps > Optional features.

Enterprise Features

  • Active Directory Domain Services (AD DS): central, distributed database of users, computers, permissions; centralizes authentication. A workgroup manages each device separately (home). Domain-joined PCs get a standard locked-down desktop; at home you can customize freely.
  • Remote Desktop: the RDP client runs on nearly any OS; the Remote Desktop service runs on Pro/Enterprise only.
  • EFS encrypts chosen files/folders (part of NTFS); BitLocker is full-disk encryption (OS and data). Both help if a laptop is lost.
  • Group policy: gpedit.msc for a single machine (local policy), gpmc.msc Group Policy Management Console for domains.

flashcards

self-check

1. An employee needs to RDP into their office PC. Minimum edition?

  • a) Home
  • b) Pro
  • c) N
  • d) Starter
answer

b) Home cannot host RDP.

2. Which provides full-disk encryption on Pro?

  • a) EFS
  • b) BitLocker
  • c) AppLocker
  • d) BranchCache
answer

b) BitLocker.

3. An IT team manages 5,000 PCs centrally. Which database?

  • a) Registry
  • b) Active Directory Domain Services
  • c) Workgroup
  • d) MMC
answer

b) AD DS.

4. A 32-bit Windows 10 PC shows 4 GB usable even with 16 GB installed. Why?

  • a) Home edition
  • b) 32-bit RAM cap
  • c) Bad slot
  • d) Device Encryption
answer

b) 4 GB limit.

short lab: Choose the edition

Pick an edition: (1) kiosk at home with no domain, (2) 3,000-seat company with AppLocker and volume licensing, (3) small office needing BitLocker and domain join.

walkthrough

(1) Home. (2) Enterprise. (3) Pro.
