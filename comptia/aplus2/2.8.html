2.8 Mobile Device Security

study notes

Mobile Security Controls

  • Device encryption: iOS/iPadOS encrypt data with the passcode as key; Android uses PIN/pattern/passcode and is usually on by default.
  • Screen locks: facial recognition, PIN, fingerprint, Android swipe pattern. Failed-attempt protections: iOS can erase after 10 failures (keep cloud backups); Android locks the device and requires Google login or wipe.
  • MDM profiles: standards (passcode complexity, lock screen, allowed apps, email/ActiveSync settings, VPN, certificates) in an XML profile built with Microsoft Intune or Apple Configurator and pushed to devices. Can enforce policy like no cameras in a secure building.
  • Updates: OS (patches and features) and app updates, usually automatic.
  • Antimalware: iOS is a closed ecosystem (App Store only), so malware needs an unpatched vulnerability. Android is more open (install from any site), so riskier. AV and content filtering exist for both.
  • Locator apps: GPS map of the device, play a sound, display a message, mark as lost, remote wipe.
  • Backups: cloud backup is continuous and works while mobile; restore by signing in on a new device.
  • Firewalls: usually no firewall apps (traffic is mostly outbound); enterprises use MDM controls instead.
  • Policies/procedures: company-owned and BYOD devices managed together from one MDM.

flashcards

self-check

1. A phone is lost. Fastest data protection:

  • a) Remote wipe via MDM/locator
  • b) Call the carrier
  • c) Wait
  • d) Ignore
answer

a) Wipe.

2. A company bans cameras in the lab. Use:

  • a) MDM profile restricting the camera
  • b) Poster
  • c) Autoplay
  • d) Cable lock
answer

a) Enforce by policy.

3. Which platform allows side-loaded apps from any website?

  • a) Android
  • b) iOS
  • c) Both equally restricted
  • d) Neither
answer

a) Open ecosystem.

short lab: BYOD policy

List four controls for employee phones accessing company email.

walkthrough

Enroll in MDM, require passcode and encryption, separate work data partition with remote wipe of work data, and enable VPN/updates.
