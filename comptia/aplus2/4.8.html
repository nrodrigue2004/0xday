4.8 Scripting

study notes

Script Types

LanguageExtensionEnvironment / notes
Batch.batWindows command prompt, from DOS/OS/2
PowerShell.ps1Windows admin automation, cmdlets, AD admin
VBScript.vbsWindows scripting, Office macros
Shell script.shLinux/Unix, starts with shebang #!/bin/sh
JavaScript.jsRuns in browsers; unrelated to Java
Python.pyCross-platform general purpose scripting

Use Cases

  • Unattended and faster than humans; spot problems early; handle repetitive tasks.
  • Restarts after patches or to work around memory leaks; run overnight.
  • Login scripts map network drives. Install/upgrade scripts map the repository, install, disconnect, reboot. Backup scripts run at off-hours (e.g. 1 a.m.). Monitoring (CPU, memory, network via SNMP), automated inventory, vulnerability scans and update deployment.
  • Risks: scripted malware distribution if the source is infected, registry changes breaking other apps, syntax errors causing outages. Always test first, back up and plan rollback.

flashcards

self-check

1. A file ending in .ps1 is a:

  • a) PowerShell script
  • b) Batch file
  • c) Python script
  • d) VBScript
answer

a) PowerShell.

2. A script's first line is #!/bin/bash. It is a:

  • a) Linux shell script
  • b) Batch file
  • c) JavaScript
  • d) Registry file
answer

a) Shebang.

3. Which language is best for one script across Windows, macOS and Linux?

  • a) Python
  • b) Batch
  • c) VBScript
  • d) PowerShell only
answer

a) Cross-platform.

4. Before pushing an update script to 500 PCs:

  • a) Test on a small group
  • b) Run it everywhere
  • c) Delete backups
  • d) Disable logging
answer

a) Staged testing.
