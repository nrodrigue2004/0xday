3.4 Troubleshooting Security

study notes

Desktop Security Symptoms

  • Network unreachable due to malware: malware blocks access to AV sites; patch the exploited OS hole, malware cleaner, or wipe and restore from a known good backup.
  • Browser notifications from sites ("your AV expired") are scams; control notification permissions in browser settings; scan if installed.
  • Fake antivirus pop-ups with phone numbers are hoaxes (often just an executable displaying the message): delete it; never pay or call. Remove carefully or restore from backup.
  • Altered files: renamed system files, missing documents, changed permissions or access denied are signs of malware; clean or restore.
  • Notification overload: Settings > System > Notifications, control per app.
  • Windows Update failing: check internet, firewall/filtering, bandwidth limits, and the Windows Update troubleshooter (Settings > System > Troubleshoot > Other troubleshooters).
  • Pop-ups despite the blocker: likely malware.
  • Certificate warnings: click the padlock to view issuer/expiry; causes: wrong FQDN, untrusted CA, expired, wrong system clock.
  • Browser redirection (search results go elsewhere): malware or hijack; scan, restore.
  • Slow browser: update, close tabs, clear cache/cookies, check Task Manager (a site running a JavaScript crypto miner can peg the CPU), try a different browser.

flashcards

self-check

1. A user sees a full-screen warning with a support number. Correct response:

  • a) Close it and scan; do not call
  • b) Call to resolve
  • c) Pay the fee
  • d) Reboot only
answer

a) Scareware.

2. Windows Update fails; the firewall recently changed. Check:

  • a) Whether Update traffic is blocked
  • b) Wallpaper
  • c) Pagefile
  • d) Audio driver
answer

a) Filtering.

3. Browser CPU at 100% on one page that has no video. Likely:

  • a) Cryptominer script
  • b) Dead battery
  • c) Wrong DNS
  • d) Missing driver
answer

a) Mining in JS.

short lab: Redirected searches

A user's Google searches land on an ad site. List four steps.

walkthrough

Check browser extensions and proxy/hosts file, update AV and scan, remove adware or hijack, clear cache and reset the browser; restore from backup if persistent.
