3.6 Multifunction Devices

study notes

Multifunction Devices

  • MFD: print, scan, copy, fax, network and phone line, web printing. Enterprise units need power, network and space. They need the correct driver for the OS and 32-bit or 64-bit version.
  • Printer languages: PCL (HP's printer command language) and PostScript (Adobe, high-end/print houses); the driver must match how the printer is set.
  • Connections: USB (type A to type B), Ethernet RJ45, Bluetooth (short range), 802.11 in infrastructure mode (through an AP) or ad hoc mode (direct one-to-one).
  • Sharing: Windows printer share (Sharing tab; depends on the host PC being on) vs a print server on the printer or network (jobs queue there; web management page).
  • Print options: duplex (both sides), portrait/landscape, tray selection (letter, legal, envelopes, bypass tray), quality (draft, resolution, color or grayscale, color saving).
  • Security: Windows printer Security tab permissions (print, manage printer, manage documents); badge release; secured print (PIN at the printer); audit logs (who printed, pages, color) and Windows Event Viewer.
  • Scanning: flatbed scanner and ADF (automatic document feeder). Scan to email, SMB folder, Microsoft/network share, or cloud (Google Drive, Dropbox).

self-check

1. A user cannot print after a Windows upgrade; the old PCL driver is installed but the printer is set to PostScript. Fix?

  • a) Change IP
  • b) Install a driver matching the printer language
  • c) Replace PSU
  • d) Enable duplex
answer

b) Language and driver must match.
