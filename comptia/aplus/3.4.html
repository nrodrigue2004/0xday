3.4 Motherboards

study notes

Motherboard Form Factors

  • The motherboard holds CPU, RAM, expansion slots, connectors. Choose by case size, expansion needs and airflow. ATX (1995): standard desktop board, plentiful slots and RAM, 20/24-pin power. ITX family (VIA, 2001, Mini-ITX): small, same mounting holes as ATX so it fits ATX cases; for media centers and small-form-factor PCs, thin clients.

Motherboard Expansion Slots

  • A bus is the communication path between components. PCI (1994): parallel; 32-bit or 64-bit; 3.3 V or 5 V keyed; legacy. PCIe (PCI Express): serial, point-to-point lanes (x1, x2, x4, x8, x16, x32, "by"), each lane full duplex; more lanes = more bandwidth. A hook locks the card; fasten the bracket screw.

Motherboard Connectors

  • Main power: originally 20 pins, now 24-pin (+3.3, +5, +12 V); keyed and latched; unplug mains first. 4-pin (or 8-pin) ATX 12 V near the CPU for CPU power (labels: CPU, P4, ATX12V).
  • SATA (storage), eSATA (external, via card or onboard), M.2 (SSD, screw).
  • Pin headers: front panel buttons and LEDs (power, reset, HDD light), front USB 2/3, front audio (AAFP), TPM header, fan headers.

Motherboard Compatibility

  • Intel vs AMD: different CPUs and sockets; you can't swap; cost vs performance changes with time. Lift the retention cover, place the CPU, close.
  • Server boards: multiple CPU sockets, many RAM slots, rack-mount fit. Desktop: one CPU, 2 to 4 RAM slots, a few slots. Small form factor: minimal. Laptop: proprietary, designed for power efficiency, CPU throttles when hot, mostly not upgradeable; replace with the exact board.

The BIOS

  • BIOS (basic input output system) is firmware (now flash memory) that initializes CPU and RAM, runs POST (checks CPU, RAM, video, input, not a full diagnostic), finds the boot drive and boot loader. Some boards have a backup BIOS for failed upgrades.
  • Legacy BIOS: text menus, basic config, no drivers or extensions. UEFI (unified extensible firmware interface, from Intel's EFI): standardized, graphical, supports UEFI drivers; tabs for main/system info, security (passwords), advanced (boot options), UEFI drivers.

BIOS Settings

  • Enter setup at boot with the vendor key (Delete, F2, F10, F12 or similar). VMs: Hyper-V and VMware Workstation Player expose BIOS; VirtualBox does not (use a UEFI simulator to practice).
  • Windows fast startup (hibernate-style shutdown) skips the key prompt. Bypass: hold Shift while clicking Restart, use Settings > Update & Security > Recovery > Advanced startup > Restart now, msconfig, or interrupt boot three times.
  • Back up settings before changes: export if offered, write them down, or photograph the screen.
  • Hardware control: disable devices in BIOS so the OS can't see them. Boot order: for example USB, then SSD, then HDD, plus network and optical; enable or disable boot sources.
  • Disable USB ports in high-security places (the 2008 DoD ban followed a worm on a USB stick).
  • Fan control: intelligent cooling profiles (performance vs quiet); fans must be on motherboard fan headers.
  • Secure boot (UEFI): checks digital signatures of the boot loader against keys stored in the firmware; blocks tampered boot code. OS must be signed; disable it only if the OS can't support it.
  • Passwords: user password (required to start), supervisor/administrator password (needed to change settings); stored in firmware flash, not the OS. Forgot it? Reset the BIOS by shorting the CLRTC / clear CMOS jumper (power off, short pins, then power on). The older term CMOS persists.
  • CMOS battery (CR2032, 3 V): only keeps date and time on modern boards; a dead battery resets the clock at each boot.
  • TPM (trusted platform module): hardware chip with its own processor and persistent storage for cryptographic keys; used by full-disk encryption (BitLocker); hardened against brute force; enable/disable in BIOS. HSM (hardware security module): appliance or card for managing many keys, with crypto acceleration; smart-card/USB versions for personal keys.

CPU Features

  • 32-bit CPUs address 2^32 values (4 GB RAM); 64-bit addresses vastly more (OS-limited). Drivers must match the OS type. x86 = 32-bit, x64 = 64-bit. A 64-bit OS runs 32-bit and 64-bit apps; a 32-bit OS runs only 32-bit. Windows installs 32-bit apps in Program Files (x86).
  • ARM: efficient, low power and heat, mobile and IoT, spreading to laptops.
  • Multi-core (dual, quad ...): several cores plus caches and often a memory controller and integrated GPU in one package. Hyper-Threading (HTT) / SMT: one core appears as two, gaining about 15 to 30 percent; needs CPU and OS support.
  • Virtualization extensions: Intel VT and AMD-V; enable in BIOS if your hypervisor needs them.

Expansion Cards

  • Install: power off, open case, align key and slot, press down, screw in; then install the driver (current one from the vendor, Device Manager or an installer; some require uninstalling the old driver first).
  • Sound card: better audio in/out (1/4 inch, line-in, S/PDIF digital). Video card: discrete GPU vs integrated graphics; plug the monitor into the card, not the board. Capture card: video input (HDMI, SDI over coax with BNC). NIC: add or multi-port Ethernet. Before buying, check slots, OS requirements, vendor compatibility lists and forums.

Cooling

  • Airflow: cool in at the front, warm out at the back; cable management matters. Case, card and CPU fans; board fan controller; quieter fans possible. Some systems are passively cooled (silent, small).
  • Heat sink: copper or aluminum fins; hot after use. Thermal paste/grease: pea-sized dot between CPU and heat sink for good contact. Thermal pad: solid, cleaner, slightly less effective, single use (replace each time). Heat sink plus fan on top is common.
  • Liquid cooling: CPU block, tubes, radiator with fans, pump; for gaming, graphics and overclocking.

self-check

1. A small HTPC next to the TV needs a tiny board that fits an ATX case later if needed. Choose:

  • a) Mini-ITX
  • b) Server board
  • c) PCI card
  • d) SO-DIMM
answer

a) Mini-ITX uses ATX-compatible holes.

2. A GPU requires the highest bandwidth. Slot?

  • a) PCI 32-bit
  • b) PCIe x16
  • c) PCIe x1
  • d) M.2 B key
answer

b) More lanes means more bandwidth.

3. POST finds no keyboard and halts. What happens next?

  • a) OS loads normally
  • b) An error appears; check input device
  • c) BIOS flashes
  • d) CPU throttles
answer

b) POST verifies basic input.

short lab: Case, board, power

You are building a media PC in a small case with Mini-ITX. Which power and storage connectors do you plan for?

walkthrough

24-pin main plus 4/8-pin CPU power, SATA power for 2.5 inch SSD or an M.2 SSD (no power cable), front-panel headers for power and USB.
