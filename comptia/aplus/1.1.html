1.1 Laptop Hardware

study notes

Laptop Hardware

  • Laptops are compact and repair difficulty varies by maker; use the manufacturer's service manual for keyboard, display and other swaps. You get fast with whichever brand your employer buys most.
  • Battery: lithium-ion or lithium-polymer. No memory effect, but each charge cycle wears capacity, so old batteries get replaced. Some are modular (slide and lock out), others sit inside the case. Batteries are model-specific.
  • Keyboard: the most used part, usually attached by a ribbon cable and easy to replace. Small laptops drop the numeric keypad and double up keys with Fn functions (brightness, help). Keycaps and the mechanics under them are fragile, so follow the maker's removal steps. A USB external keyboard works around a bad internal one.
  • Memory: SO-DIMM (small outline DIMM) in a slot behind a panel. Some laptops solder memory to the motherboard, so you can't upgrade it.
  • Storage: older 2.5 inch HDD (spinning, SATA); 2.5 inch SATA SSD (no moving parts, same form factor, big speed gain); M.2 SSD (tiny card, one screw, no cable). Open the back or one access cover, unscrew, slide out, replace.
  • HDD to SSD migration: either install the OS fresh and move documents and apps (slow), or clone/image the drive with imaging software (many SSD makers include a tool). A drive-to-drive clone copies sector by sector and needs both drives connected at once; one image file can build many machines.
  • Wireless cards: built into newer boards; older laptops use Mini PCI / Mini PCI Express cards for 802.11 (WLAN), Bluetooth (WPAN) and cellular (WWAN). Cards connect to antenna wires.
  • Biometrics: needs OS support plus hardware. Windows Hello face (camera) or fingerprint reader; use with a password for two factors.
  • NFC: tap a phone or watch to authenticate (useful in shared environments like hospitals and warehouses).

flashcards

self-check

1. A user wants more RAM in a thin laptop, but the spec says LPDDR on board. What is true?

  • a) Add a SO-DIMM
  • b) It is soldered; it cannot be upgraded
  • c) Use an M.2 card
  • d) Update BIOS
answer

b) Soldered memory is not upgradable.

2. Fastest way to move a customer's whole Windows install to a new SSD?

  • a) Reinstall Windows and copy files
  • b) Clone/image the drive
  • c) Use RAID 0
  • d) Use NFC
answer

b) Imaging moves OS, apps and data.

short lab: Swap the drive

Plan an HDD-to-M.2 upgrade for a laptop with one M.2 slot and one 2.5 inch bay. Give the steps.

walkthrough

Back up first. Power off, unplug the AC and battery. Open the access cover, ground yourself, insert the M.2 SSD and fasten the screw. Clone the HDD to it (or fresh install), set the boot order in BIOS to the SSD, test, then reassemble. Keep the HDD as data storage or wipe it.
