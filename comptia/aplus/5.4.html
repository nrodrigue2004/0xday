5.4 Troubleshooting Displays

study notes

Video and Display Issues

  • No signal / black: reseat or replace cables; select the right input on the monitor; check brightness/contrast; swap a known-good monitor. If black once Windows loads, boot in VGA/low-resolution mode to test the driver.
  • Flicker or color problems: check cable, VGA pins; adjust refresh rate and resolution; try disabling hardware acceleration. Flicker is usually a loose cable; otherwise the monitor driver mismatch or failing display.
  • Wrong resolution (blocky text): LCDs have fixed pixels; use native resolution, or a scaled factor with the same aspect ratio.
  • Burn-in / image sticking: a static image leaves a ghost. Prevent with pixel shift and screen savers; on LCD, display white for a long time.
  • Dead pixel: always black, cannot be fixed, replace the display (clean the screen first to check it is not dirt).
  • Wrong colors: check monitor tint, presets, factory reset, driver color settings, and OS night light features.
  • No sound from monitor speakers: check monitor volume, and which audio input (separate cable or HDMI) is selected.
  • Dim image: brightness, power-saving auto dimming; if the image is faint but visible, the backlight has failed (replace display).
  • Projectors: metal halide lamps are bright, hot and costly (as much as $350). Let the fan run after shutdown so the lamp cools. Intermittent shutdown with fan running means overheating; clean vents and replace filters.

flashcards

self-check

1. Text looks stretched and blocky after a driver update. Fix?

  • a) Set native resolution
  • b) Replace backlight
  • c) Reseat RAM
  • d) Replace the cable
answer

a) Resolution mismatch.

2. A display shows a dim, barely visible image. Cause?

  • a) Backlight failure
  • b) Dead pixel
  • c) Burn-in
  • d) Wrong DNS
answer

a) Backlight.

3. A projector shuts down with the fan still running. Check?

  • a) Vents and filters
  • b) The mouse
  • c) Battery
  • d) DNS
answer

a) Overheating.

short lab: Flicker

A monitor flickers on and off at random. Give a three-step plan.

walkthrough

Reseat or replace the cable, match the resolution and refresh rate to the monitor's spec, test a known-good monitor to decide whether to replace it.
