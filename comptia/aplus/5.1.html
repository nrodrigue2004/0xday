5.1 Troubleshooting

study notes

Change Control

  • Before you change anything on a production system, get it approved and documented. Change control sets the scope, risk, rollback plan, schedule (a change window) and sign-off. Fixing a problem is a change like any other.

The Troubleshooting Process

  • 1. Gather information: ask the user what happened, what changed, what the exact error is; try to reproduce it; check logs and recent updates. Back up first if you might touch data.
  • 2. Establish a theory of probable cause. Start with the obvious (Occam's razor: the simplest explanation is usually right) but question everything, including things "that can't be it".
  • 3. Test the theory. If confirmed, move on. If not, form a new theory or escalate.
  • 4. Plan of action with a rollback path, then get change approval.
  • 5. Implement the fix, inside the change window if it is a production system.
  • 6. Verify full system functionality and put preventive measures in place (so it does not return).
  • 7. Document findings, actions and outcome in the ticket or knowledge base; this helps the next tech.

flashcards

self-check

1. Before swapping a failing drive, what comes first in the process?

  • a) Document outcome
  • b) Gather information and back up data
  • c) Verify functionality
  • d) Implement fix
answer

b) Identify the problem first, protect data.

2. A test shows your theory was wrong. Next?

  • a) Document and close
  • b) Form a new theory or escalate
  • c) Implement the fix anyway
  • d) Reboot everything
answer

b) Return to theory stage.

3. Where is the change window relevant?

  • a) Gathering info
  • b) Implementing a change on production
  • c) Documenting
  • d) Theory
answer

b) Changes happen in the approved window.

short lab: Order the steps

Put in order: document, test theory, gather information, verify and prevent, implement, plan with rollback, establish theory.

walkthrough

Gather information, establish theory, test theory, plan with rollback, implement, verify and prevent, document.
