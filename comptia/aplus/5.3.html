5.3 Troubleshooting Storage

study notes

Storage Failures

  • "Cannot read from source disk", slow response, constant activity light, HDD clicking ("click of death"): failing drive. Back up first if possible, then check cables, heat, and PSU load (new hardware may starve the drive). Run the manufacturer's diagnostics.
  • "Drive not recognized", "boot device not found", "operating system not found": check cables, BIOS boot order, stray USB media, a disabled drive in BIOS, another SATA/M.2 port, and try the drive in another computer.
  • HDDs always eventually fail. Recovery companies are costly and can still fail; so keep backups. An SSD may fail by becoming read-only.

RAID

  • Hardware RAID controllers report failures at boot (e.g. "integrated RAID exception, volume inactive"). Use the RAID manager to see which drive failed.
  • RAID 0 (2+ drives): one failure loses everything. RAID 1 (2+): survives one failure. RAID 5 (3+): survives one failure. RAID 10 (4+): survives one failure per mirror pair.

SMART and Performance

  • SMART is built-in drive health reporting (spin-up time, seek errors, power-on hours); rising error counts warn of failure. If a drive reports failing, back up and replace now.
  • IOPS measures input/output operations per second: HDD about 200, SSD up to about a million; read and write differ.

Missing Drives

  • Internal drive missing in the OS: check BIOS, then cables, reseat M.2, else replace. External USB: check power and port. Network share: reconnect or re-run the login script.

flashcards

self-check

1. An HDD clicks loudly and errors appear. First action?

  • a) Defrag
  • b) Back up data
  • c) Format
  • d) Run chkdsk /r
answer

b) Save the data first.

2. After a new add-in card, the HDD shows errors. Possible cause?

  • a) Overloaded power supply
  • b) Bad monitor
  • c) Wrong time zone
  • d) Dead CMOS battery
answer

a) Insufficient power.

3. Which RAID survives only one drive failure and needs at least 3 drives?

  • a) 0
  • b) 1
  • c) 5
  • d) none
answer

c) RAID 5.

short lab: No OS found

A PC says "operating system not found" after a user left a USB stick plugged in. Explain.

walkthrough

BIOS tries USB first in its boot order and finds no OS there. Remove the stick or reorder boot devices.
