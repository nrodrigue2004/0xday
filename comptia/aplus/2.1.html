2.1 Ports and Protocols

study notes

Introduction to IP

  • Encapsulation: application data goes in a TCP or UDP segment, inside an IP packet, inside an Ethernet frame (header, payload, trailer). IP is the delivery truck: it moves a box between IP addresses and doesn't care what's inside. TCP and UDP sit at OSI layer 4 (transport) and add multiplexing with port numbers.
  • TCP (transmission control protocol): connection-oriented, formal setup and teardown, acknowledged "reliable" delivery, reorders out-of-order data, retransmits lost data, flow control. Used by HTTPS and SSH.
  • UDP (user datagram protocol): connectionless, no acknowledgment, no flow control. Fast, used for real-time traffic (voice, video) and short exchanges like DHCP and TFTP; the application handles any resends.
  • Ports: the "room" in the house, 0 to 65,535, separate sets for TCP and UDP. Well-known (non-ephemeral) server ports are fixed (0 to 1023, for example 80 and 443). The client picks a random ephemeral source port (OS-assigned, typically 1,024 to 65,535) per conversation. A flow = server IP + protocol + server port + client IP + client port. Changing a port is not security; scanners find open ports.

Common Network Ports

  • FTP TCP 20 (data) and 21 (control): file transfer, login (or anonymous), list/add/delete/rename.
  • SSH TCP 22 (encrypted terminal); Telnet TCP 23 (clear text, avoid).
  • SMTP TCP 25: server to server and client sending mail. POP3 TCP 110: download mail to one client. IMAP4 TCP 143: manage a mailbox synced across devices.
  • DNS UDP/TCP 53: names to IPs (UDP in normal queries).
  • DHCP UDP 67 (server) and 68 (client): lease pool; reservations give fixed IPs.
  • HTTP TCP 80; HTTPS TCP 443.
  • SMB/CIFS (Windows file and print): TCP 445 direct; older NetBIOS over TCP/IP: UDP 137 name service, TCP 139 sessions (also UDP 138 datagram).
  • SNMP UDP 161 (queries), UDP 162 (traps, alerts to the manager). v1 and v2 clear text; v3 adds authentication, integrity, encryption.
  • LDAP TCP 389: directory queries (Active Directory).
  • RDP TCP 3389: Windows remote desktop (whole desktop or a single app).

flashcards

self-check

1. A technician must allow remote desktop access through a firewall. Which port?

  • a) 22
  • b) 3389
  • c) 445
  • d) 143
answer

b) RDP uses TCP 3389.

2. A mail client syncs the same inbox across a phone and a laptop. Which protocol?

  • a) POP3
  • b) IMAP
  • c) SMTP
  • d) SNMP
answer

b) IMAP manages the mailbox on the server.

3. Which pair is clear text and should be replaced by an encrypted alternative?

  • a) SSH and HTTPS
  • b) Telnet and HTTP
  • c) SMB and LDAP
  • d) DNS and DHCP
answer

b) Telnet and HTTP send data unencrypted.

short lab: Name that port

Write the port and protocol: (1) secure terminal, (2) web, secure, (3) send email, (4) Windows file share, (5) directory lookup, (6) SNMP trap.

walkthrough

(1) TCP 22 SSH. (2) TCP 443 HTTPS. (3) TCP 25 SMTP. (4) TCP 445 SMB. (5) TCP 389 LDAP. (6) UDP 162.
