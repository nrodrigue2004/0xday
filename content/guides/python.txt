tagline: Python is the security field's glue language. Learn it from variables to parsing logs with real Python running in your browser, then write a script that finds a brute-force attacker.
:: simple
Python reads almost like English, which is why it's the first language for most security people. The sandbox runs **real Python** (Pyodide, the first run downloads it once).

Values go in variables, `print` shows them, and **f-strings** drop variables into text:

```
$ python3 -c 'name = "0xDay"; print(f"hello, {name}")'
$ python3 -c 'print(7 * 6, type(42), type("42"))'
```

A **list** holds items in order, and a `for` loop walks through them:

```
$ python3 -c 'for p in [22, 80, 443]: print("checking", p)'
```

> Indentation is syntax in Python. The body of a loop or `if` is whatever is indented under it.
:: mid
### Files, strings and dictionaries
Most security scripts do the same thing: open a file, go line by line, split the line, keep counts. A **dictionary** maps keys to values, perfect for counting.

```
$ cat ~/scripts/count_status.py
$ python3 ~/scripts/count_status.py
```

Useful string methods: `line.split()` (split on spaces), `.strip()`, `.startswith()`, `"x" in line`. And `collections.Counter` counts anything in one line:

```
$ python3 -c 'from collections import Counter; print(Counter("mississippi").most_common(2))'
```

### Core data types and when to pick them
`list` is an ordered, changeable sequence; `tuple` is fixed; `dict` maps keys to values (fast lookup); `set` holds unique items (fast membership test and set math). Strings are immutable. Comprehensions build collections in one line: `[x.upper() for x in names if x]`, `{k: v for k, v in pairs}`, `{ip for ip in ips}`.

### Functions, errors and files
```
def parse(line):
    parts = line.split()
    return {"ip": parts[0], "status": int(parts[8])}

try:
    with open("access.log") as f:
        rows = [parse(l) for l in f]
except FileNotFoundError:
    print("no log")
```
`with` closes the file for you. `try/except` should catch the specific error you expect, never a bare `except:`. `f"{name}: {count}"` formats strings. Slicing: `s[1:4]`, `s[-1]`, `s[::-1]`.

### Modules you will use all the time
`os` and `pathlib` (paths), `sys` (arguments), `re` (regex), `json`, `csv`, `datetime`, `collections.Counter` (count things), `argparse` (command line options), `subprocess` (run other programs), `hashlib`, `socket`, and third-party `requests`, `scapy`, `pandas`.
:: complex
### Regular expressions and the standard library
`re` finds patterns (IPs, emails, hashes), `ipaddress` understands networks, `hashlib` hashes, `base64` and `json` decode the formats you see everywhere, `datetime` parses timestamps:

```
$ python3 -c 'import ipaddress; print(ipaddress.ip_address("10.0.20.44") in ipaddress.ip_network("10.0.0.0/8"))'
$ python3 -c 'import hashlib; print(hashlib.sha256(b"0xday").hexdigest())'
```

### Writing scripts that last
- wrap the logic in functions and use `if __name__ == "__main__":`
- take inputs from `sys.argv` or `argparse` instead of hard-coding paths
- handle bad lines with `try/except` instead of crashing on line 40,000
- for real work: `requests` (HTTP), `scapy` (packets), `pandas` (big tables), `pwntools` (CTFs)

Edit scripts in the sandbox with `nano file.py`, save with Ctrl+S, exit with Ctrl+X.

### Idioms that make scripts short
```
from collections import Counter
import re
ips = re.findall(r"\d+\.\d+\.\d+\.\d+", open("auth.log").read())
for ip, n in Counter(ips).most_common(5):
    print(ip, n)
```
Generators (`yield`) process big files without loading them. `defaultdict(list)` groups items. `sorted(d.items(), key=lambda kv: kv[1], reverse=True)` sorts a dict by value. `enumerate` and `zip` replace manual index loops.

### Security tooling in Python
A TCP port check with `socket`, a hash of every file in a folder with `hashlib`, an HTTP header audit with `requests`, parsing PCAPs with `scapy`, decoding base64 with `base64`. Use `subprocess.run([...], capture_output=True, text=True)` with a list of arguments, never `shell=True` with user input, which invites command injection.

### Project hygiene
Use a virtual environment (`python3 -m venv .venv`), pin dependencies in `requirements.txt`, format with `black`, lint with `ruff`, test with `pytest`, and add type hints so mistakes show up before runtime. Never commit tokens or passwords; read them from environment variables.
