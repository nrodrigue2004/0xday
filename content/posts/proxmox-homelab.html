I wanted a place to practice attacking and defending something that looks like a real company network, so I built one at home on Proxmox. This post walks through the design and what I learned setting it up.

The lab

Seven VMs, split across isolated subnets:

  • pfSense as the firewall, handling rules, DHCP and NAT between segments
  • Kali Linux as the attacker box
  • Metasploitable 2 and DVWA / WebGoat (in Docker) as intentionally vulnerable targets
  • Windows Server 2022 as the Active Directory domain controller
  • A domain-joined Windows 11 workstation
  • Security Onion as the SIEM, watching traffic in real time

Remote access

Rather than opening ports, I used Tailscale with subnet routing so I can reach the lab from anywhere without exposing it to the internet.

tailscale up --advertise-routes=10.10.0.0/24,10.20.0.0/24
