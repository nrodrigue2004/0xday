## 0
Q: In the NIST incident response lifecycle, which phase comes first?
* Preparation
- Containment
- Eradication
- Lessons learned
? Preparation is plans, tools, training and contacts before anything happens.

Q: What is the goal of containment?
* Stop the incident spreading while preserving evidence
- Remove all traces of the attacker
- Restore normal operation
- Identify the attacker
? Isolating a host is usually better than powering it off.

Q: When is the lessons-learned review held?
* After the incident is resolved, to improve process and controls
- During containment
- Before preparation
- Only if data was lost
? It should produce actions with owners, not blame.

Q: In the order of volatility, which is collected before disk contents?
* Memory and running state
- Archived backups
- Printed logs
- Offline media
? The most volatile evidence disappears first.

## 1
Q: What does a write blocker do?
* Lets you read a drive without altering it
- Encrypts the drive
- Deletes free space
- Speeds up imaging
? It protects evidence integrity.

Q: Why take a hash of a forensic image?
* To prove later that the copy has not changed
- To compress it
- To encrypt it
- To find malware
? Matching SHA-256 values show the evidence is intact.

Q: What does chain of custody document?
* Who handled the evidence, when and why
- Which malware was found
- Backup schedules
- Network diagrams
? Gaps in the chain can make evidence unusable.

Q: How should disk analysis be done?
* On a forensic image, never the original drive
- Directly on the original drive
- On a compressed copy with edits
- Over the network from the live host
? A bit-for-bit image preserves deleted data too.

## 2
Q: What is Volatility used for?
* Analyzing memory images
- Capturing network traffic
- Cracking passwords on disk
- Scanning for vulnerabilities
? It parses processes, connections and more from RAM dumps.

Q: Why use psscan in addition to pslist?
* psscan can find hidden or terminated processes that pslist misses
- It is faster
- It lists services
- It shows file hashes
? Rootkits can unlink a process from the active list.

Q: What can memory hold that the disk may not?
* Running processes, network connections, keys and unpacked malware
- Old photos
- Installed program lists only
- BIOS updates
? That is why memory is captured early.

Q: Why capture memory before powering a machine off?
* RAM contents are lost when power is cut
- Disks lose data at power off
- It is faster
- Memory is always encrypted
? Once off, the evidence is gone.

## 3
Q: Which email headers help trace a message's origin?
* The Received headers
- The Subject line
- The Signature block
- The Date format
? Each server adds a Received line, so read them from the bottom up.

Q: What does SPF check?
* Whether the sending server is authorized for the domain
- That the message body is unchanged
- That the user is human
- That the attachment is safe
? SPF is a DNS record listing allowed senders.

Q: What does DKIM provide?
* A cryptographic signature that the message was not altered and came from the domain
- A list of allowed senders
- Spam scoring
- Encryption of the body
? DMARC then tells receivers what to do when SPF or DKIM fails.

Q: What is the safest way to inspect a suspicious attachment?
* In an isolated sandbox or analysis VM
- Open it on a work PC with antivirus
- Forward it to a colleague
- Open it in read-only mode on the mail server
? Analysis should never run where it can reach real data.
