## 0
Q: Which command lists files with their permissions, owner and size?
* ls -l
- pwd
- cat -p
- chmod -l
? ls -l gives the long listing.

Q: What access does chmod 640 give a file?
* Owner read and write, group read, others nothing
- Owner read and write, group read and write, others read
- Owner read only, group read and write, others nothing
- Everyone read and write
? 6 = rw-, 4 = r--, 0 = ---.

Q: Which command finds lines containing "Failed" in /var/log/auth.log?
* grep Failed /var/log/auth.log
- find Failed /var/log/auth.log
- cat -f Failed /var/log/auth.log
- ls Failed /var/log/auth.log
? find searches for files by name or attributes. grep searches inside files.

Q: What does sudo do?
* Runs a command with elevated privileges, as root by default
- Switches to a different shell
- Lists installed packages
- Locks the current user account
? sudo is governed by the sudoers configuration.

## 1
Q: In bash, what does $? hold?
* The exit status of the last command
- The process ID of the shell
- The number of arguments
- The current directory
? 0 means success, anything else is a failure.

Q: What does cmd1 | cmd2 do?
* Sends the standard output of cmd1 to the standard input of cmd2
- Runs cmd2 only if cmd1 fails
- Runs both commands in the background
- Writes the output of cmd1 to a file named cmd2
? The pipe connects two processes with a stream.

Q: What is the difference between > and >> when redirecting output?
* > overwrites the file, >> appends to it
- > appends, >> overwrites
- > redirects stderr, >> redirects stdout
- There is no difference
? Using > by accident on an existing file is a classic way to lose data.

Q: What does the first line #!/bin/bash in a script do?
* Tells the system which interpreter should run the script
- Marks the script as a comment block
- Makes the script executable
- Imports the bash library
? It still needs chmod +x to be run directly.

## 2
Q: How are PowerShell cmdlets named?
* Verb-Noun, such as Get-Process
- noun.verb, such as process.get
- A three-letter code, such as gps
- Camel case with no dash
? Aliases like gps exist, but the real names follow Verb-Noun.

Q: Which cmdlet lists Windows services?
* Get-Service
- List-Services
- Show-Service
- Get-Daemon
? Get-Service, Start-Service, Stop-Service.

Q: What is the key difference between a PowerShell pipeline and a bash pipeline?
* PowerShell pipes objects, bash pipes text
- PowerShell pipes text, bash pipes objects
- PowerShell cannot pipe
- They are identical
? Objects keep their properties, so you can filter on a property without parsing text.

Q: Which command shows full network configuration on Windows, including DNS servers and MAC address?
* ipconfig /all
- ifconfig -a
- netsh ping
- ip addr
? ifconfig and ip addr are the Linux equivalents.

## 3
Q: What does an Active Directory domain controller do?
* Stores the directory of users, computers and groups and authenticates logons
- Only serves DHCP leases
- Only hosts file shares
- Only routes traffic between VLANs
? Domain controllers hold the AD database and run Kerberos.

Q: In what order are Group Policy Objects processed?
* Local, Site, Domain, OU
- Domain, Site, Local, OU
- OU, Domain, Site, Local
- Site, Local, OU, Domain
? Often written LSDOU. Later ones win when settings conflict.

Q: What is an organizational unit (OU) used for?
* Grouping objects so you can delegate administration and link GPOs
- Encrypting a domain
- Storing user passwords
- Joining two forests
? Policies are linked to OUs, so the OU structure controls who gets what.

Q: Which authentication protocol does Active Directory use by default?
* Kerberos
- RADIUS
- TACACS+
- SAML
? NTLM is the fallback for older cases.
