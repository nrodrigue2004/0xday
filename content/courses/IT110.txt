## 0
Q: Which OSI layer handles IP addressing and routing?
* Layer 3, network
- Layer 2, data link
- Layer 4, transport
- Layer 7, application
? Routers forward packets based on IP addresses at layer 3.

Q: A standard (non-routing) switch forwards frames using which kind of address?
* MAC address
- IP address
- Port number
- Hostname
? Switches work at layer 2 and learn which MAC address sits behind which port.

Q: What best describes TCP compared with UDP?
* TCP is connection-oriented and provides reliable, ordered delivery
- TCP is faster because it skips acknowledgements
- TCP only works inside a LAN
- TCP is used only for DNS
? UDP is connectionless and has no delivery guarantees, which suits things like voice and DNS queries.

Q: What is the data unit at the transport layer for TCP called?
* Segment
- Frame
- Packet
- Bit
? Segment (TCP) or datagram (UDP) at layer 4, packet at layer 3, frame at layer 2.

## 1
Q: What is the default port for HTTPS?
* 443
- 80
- 8443
- 22
? 80 is plain HTTP and 22 is SSH.

Q: SSH uses which default transport and port?
* TCP 22
- UDP 22
- TCP 23
- TCP 3389
? Port 23 is Telnet (cleartext) and 3389 is RDP.

Q: Which description of DNS port use is correct?
* Port 53, mostly UDP for queries, TCP for large responses and zone transfers
- Port 25, TCP only
- Port 67, UDP only
- Port 110, TCP only
? 25 is SMTP, 67 is DHCP and 110 is POP3.

Q: Which protocol is used to send email from one mail server to another?
* SMTP
- IMAP
- POP3
- SNMP
? IMAP and POP3 are for clients retrieving mail.

## 2
Q: What is the subnet mask for a /24 network?
* 255.255.255.0
- 255.255.0.0
- 255.255.255.128
- 255.255.255.192
? 24 bits of network means three full octets of ones.

Q: How many usable host addresses are in a /26 subnet?
* 62
- 64
- 30
- 126
? A /26 has 64 addresses. The network and broadcast addresses are not usable, so 62.

Q: Which of these is a private (RFC 1918) address?
* 172.20.4.9
- 172.32.0.1
- 192.169.1.1
- 11.0.0.1
? Private ranges are 10/8, 172.16.0.0/12 (172.16 to 172.31) and 192.168/16.

Q: What are the four steps of a DHCP lease, in order?
* Discover, Offer, Request, Acknowledge
- Request, Offer, Discover, Acknowledge
- Hello, Assign, Confirm, Release
- Discover, Assign, Acknowledge, Renew
? Often remembered as DORA.

## 3
Q: Which command shows the hops a packet takes toward a destination (Windows spelling)?
* tracert
- ipconfig
- netstat
- arp
? On Linux and macOS it is traceroute.

Q: A PC shows an address like 169.254.12.7. What does that usually mean?
* It could not reach a DHCP server and gave itself a link-local address
- It is a valid public address
- It is the default gateway
- It was assigned by the router's NAT
? APIPA addresses are self-assigned and only work on the local link.

Q: What is the default gateway?
* The router a host sends traffic to when the destination is on another network
- The DNS server
- The DHCP server
- The switch the host is plugged into
? Anything outside the local subnet is handed to the gateway.

Q: What does ARP do?
* Resolves an IP address to a MAC address on the local network
- Resolves a hostname to an IP address
- Assigns IP addresses to clients
- Translates private addresses to public ones
? DNS resolves names, DHCP assigns addresses and NAT translates.
