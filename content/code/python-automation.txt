:: simple
A **script** is a program you run once to do a chore. In security the chores repeat: read a log, count something, look an IP up, write a report. Python is good at this because the standard library already reads files, parses JSON, handles dates and talks HTTP.

Every automation script has the same four steps:

- **Read** the input (a log file, a JSON export, a CSV)
- **Parse** each line into fields
- **Decide** what matters (count, filter, compare)
- **Report** the result (print it, write a file, send it)

```
$ python3 -c "print(sum(int(x) for x in '4 8 15 16 23 42'.split()))"
```

> Start with `print()` after every step. A script that prints what it thinks is easy to debug, and the prints become the report later.

### Parsing a log line
A log line is a string with structure. `line.split()` breaks it on whitespace and gives you a list. Pick fields by position, or look for a keyword and take the word after it.

```code
line = "Nov  7 03:00:05 bastion sshd[4104]: Failed password for root from 198.51.100.23 port 51329 ssh2"
parts = line.split()
ip = parts[parts.index("from") + 1]     # the word after "from"
print(ip)                               # 198.51.100.23
```
:: mid
### The standard-library toolbox
- `open(path)` and `for line in f` read a file one line at a time, so a 4 GB log does not fill memory
- `json.loads(line)` turns a JSON line into a dict, `json.load(f)` reads a whole file
- `collections.Counter` counts things: `Counter(ips).most_common(5)` is the top-5 table
- `re.search(r"from (\S+)", line)` pulls a field out with a regular expression when `split()` is too fragile
- `argparse` makes the script take `--log path` and `--threshold 5` instead of editing the code
- `pathlib.Path("logs").glob("*.log")` loops over files

### Enrich: join your data with someone else's
Enrichment means adding context. The alert has an IP; a reputation service knows how many engines flagged it. The pattern is always the same: load the lookup once into a dict, then look each item up.

```code
import json
from collections import Counter

rep = json.load(open("vt_cache.json"))        # {ip: {"malicious": 14, ...}}
hits = Counter()
for line in open("alerts.jsonl"):
    a = json.loads(line)
    if rep.get(a["src"], {}).get("malicious", 0) >= 5:
        hits[a["src"]] += 1
print(hits.most_common())
```

`dict.get(key, default)` is the safe lookup: an IP the service has never seen should count as zero, not crash the script.

### Calling a web API
Real enrichment calls an HTTP API. The shape never changes: build a URL, send a key in a header, check the status, parse the JSON.

```code
import os, requests

KEY = os.environ["VT_API_KEY"]                # never in the source file
def lookup(ip):
    r = requests.get(f"https://www.virustotal.com/api/v3/ip_addresses/{ip}",
                     headers={"x-apikey": KEY}, timeout=10)
    r.raise_for_status()                      # 4xx/5xx becomes an exception
    stats = r.json()["data"]["attributes"]["last_analysis_stats"]
    return stats["malicious"]
```

This lab does not call the network. The response was saved to `vt_cache.json`, which is also what you should do for real: cache lookups so one noisy log does not burn your daily quota. Public example IPs only, and read the provider's terms before scripting anything against them.
:: complex
### Make it a tool, not a throwaway
- **Keys come from the environment**, never from the file. A key in source ends up in git history (see the git chapter for how that goes).
- **Timeouts on every request.** `requests.get` waits forever by default; a hung API call stalls the whole script.
- **Respect rate limits.** Free tiers allow a few requests per minute. Sleep between calls, cache results, and back off when you see HTTP 429.
- **Retry with backoff** for 5xx and network errors: wait 1s, 2s, 4s, then give up and report the failure instead of silently skipping the IP.
- **Skip bad lines, count them.** Real logs contain garbage. `try/except json.JSONDecodeError` plus a `skipped += 1` counter beats a crash at line 90,211.
- **Stream, do not slurp.** Iterate the file instead of `f.read().splitlines()` unless it fits in memory.
- **Exit codes.** `sys.exit(1)` when the script finds something, so cron or CI can alert on it.

```code
import sys, json, argparse
from collections import Counter

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("log"); ap.add_argument("--min-bad", type=int, default=5)
    args = ap.parse_args()
    bad = Counter(); skipped = 0
    for line in open(args.log):
        try: a = json.loads(line)
        except json.JSONDecodeError: skipped += 1; continue
        bad[a["src"]] += 1
    print(f"{len(bad)} sources, {skipped} lines skipped")
    sys.exit(1 if any(n >= args.min_bad for n in bad.values()) else 0)

if __name__ == "__main__": main()
```

Complexity check: this is one pass, so **O(n)** in the number of lines, with O(1) average dict updates. Lookups in a list instead of a dict would turn it into O(n times k); see [Big-O](../bigo.html). Practice the same moves as katas in the [Python dojo](../dojo/python.html).
