# More glossary terms. Format:  Term | category | definition | links (space separated, or -) | aliases (comma separated, or -)
# Written in plain language. Links use prefix:slug (see chatdata.py) and are checked at build time.
# ---- networking ----
Ethernet | network | The standard wired LAN technology. Devices send frames to MAC addresses over cable (twisted pair or fiber) through switches. | g:computer-networks | wired network
Frame | network | The unit of data at layer 2 (data link). It wraps a packet with source and destination MAC addresses and a checksum. | b:osi-and-tcpip | -
Segment | network | The unit of data at layer 4. A TCP segment carries a chunk of a stream plus sequence numbers and flags. | b:osi-and-tcpip | datagram
Encapsulation | network | Wrapping data in headers as it moves down the layers: data, segment, packet, frame, bits. | b:osi-and-tcpip | -
MTU | network | Maximum transmission unit: the largest packet a link carries without fragmenting. 1500 bytes on standard Ethernet. | - | maximum transmission unit
TTL | network | Time to live: a counter in each IP packet that drops by one at every router. At zero the packet is discarded, which stops loops. Traceroute uses it. | - | time to live
Hop | network | One router a packet passes through on its way to the destination. | - | -
Unicast | network | Traffic from one sender to one receiver. | - | -
Broadcast | network | Traffic sent to every device on the local network, such as ARP requests and DHCP discovers. | - | broadcast domain
Multicast | network | Traffic sent to a group of subscribed devices, used for streaming and some routing protocols. | - | -
Collision domain | network | A network segment where two devices sending at once cause a collision. Each switch port is its own domain; a hub is one shared domain. | - | -
Default gateway | network | The router a device sends traffic to when the destination is outside its own subnet. | g:networking-tcp-ip-dhcp-nat-subnets | gateway address
Subnet mask | network | A value like 255.255.255.0 that says which part of an IP address is the network and which is the host. /24 is the same thing. | g:networking-tcp-ip-dhcp-nat-subnets | netmask
Domain name | network | A human-readable name like example.com that DNS maps to an IP address. | - | -
FQDN | network | Fully qualified domain name: the complete name of a host including every label, such as mail.example.com. | - | fully qualified domain name
TLD | network | Top-level domain: the last part of a domain name, such as .com, .org or .edu. | - | top level domain
URL | web | A web address: scheme, host, port, path, query and fragment, such as https://example.com:443/path?x=1. | b:http-and-the-web | uniform resource locator, web address, link
A record | network | A DNS record that maps a name to an IPv4 address. AAAA does the same for IPv6. | - | AAAA record, address record
CNAME | network | A DNS record that makes one name an alias for another name. | - | cname record, canonical name
MX record | network | A DNS record that says which mail servers accept email for a domain. | - | mail exchange
TXT record | network | A DNS record holding free text. Used for SPF, DKIM, DMARC and domain verification. | - | -
NS record | network | A DNS record naming the authoritative name servers for a zone. | - | name server
PTR record | network | A reverse DNS record that maps an IP address back to a name. | - | reverse dns
DNS resolver | network | The server that looks up names for clients, asking other servers and caching answers. Your ISP or 1.1.1.1 are resolvers. | - | recursive resolver
Authoritative DNS server | network | The server that holds the real records for a domain and gives the final answer. | - | authoritative name server
DNS over HTTPS | network | DoH: DNS lookups inside HTTPS so on-path observers can't read or change them. DNS over TLS (DoT) is the same idea on port 853. | s:pairs | DoH, DoT, DNS over TLS
DNSSEC | network | Signatures on DNS records so a resolver can check that an answer wasn't forged. It does not encrypt. | - | -
DNS poisoning | attacks | Putting a forged DNS answer into a resolver's cache so users are sent to the wrong address. | - | DNS cache poisoning, DNS spoofing
Zone transfer | attacks | A DNS feature that copies all records of a zone to another server. If left open to anyone, it leaks every hostname. | - | AXFR
HTTP | web | HyperText Transfer Protocol: the request and response protocol of the web. Stateless, text based, port 80 (443 with TLS). | b:http-and-the-web | hypertext transfer protocol
HTTP methods | web | The verbs of a request: GET reads, POST sends data, PUT replaces, PATCH changes part, DELETE removes, HEAD gets headers only, OPTIONS asks what is allowed. | b:http-and-the-web m:http | GET, POST, PUT, DELETE
HTTP header | web | Key-value metadata on a request or response, such as Host, Cookie, Content-Type and Set-Cookie. | m:http | headers, request header
Web server | web | Software that answers HTTP requests with pages or data. Apache, Nginx and IIS are common. | - | apache, nginx, iis
WebSocket | web | A persistent two-way connection between browser and server, used for chat and live updates. | - | websockets
Webhook | web | A URL your service calls when an event happens, so another system gets pushed the news instead of polling. | - | -
SMTP | email | The protocol that sends email between servers, port 25, and from clients on 587 or 465. | - | simple mail transfer protocol
IMAP | email | Email access protocol that keeps mail on the server and syncs across devices. Port 143, or 993 with TLS. | - | imaps
POP3 | email | Email access protocol that downloads mail to one device. Port 110, or 995 with TLS. | - | pop
SNMP | network | Simple Network Management Protocol: lets tools read status from routers, switches and printers. Use v3; v1 and v2c send community strings in cleartext. | - | simple network management protocol
NTP | network | Network Time Protocol: keeps clocks in sync. Accurate time matters for logs, Kerberos and certificates. | - | network time protocol
Telnet | network | An old remote shell protocol on port 23 that sends everything, including passwords, in cleartext. Replaced by SSH. | s:pairs | -
TFTP | network | Trivial FTP: a bare-bones file transfer over UDP port 69 with no authentication. Used to boot and configure network gear. | - | trivial file transfer protocol
SFTP | network | File transfer over SSH, port 22. Not the same as FTPS (FTP inside TLS). | s:pairs | ssh file transfer protocol
SMB | network | Server Message Block: the Windows file and printer sharing protocol, port 445. Attacked by relay and EternalBlue-style bugs. | - | smb protocol, cifs
NFS | network | Network File System: the Unix and Linux way to share directories over the network, port 2049. | - | network file system
RDP | network | Remote Desktop Protocol: Windows remote desktop, port 3389. Heavily attacked when exposed to the internet. | s:pairs | remote desktop, remote desktop protocol
VNC | network | Virtual Network Computing: remote desktop sharing over port 5900 with weak default security. Tunnel it. | - | -
RADIUS | access | A protocol for central network authentication, used for Wi-Fi (802.1X) and VPN logins. TACACS+ is the Cisco alternative for device admin. | - | tacacs+, tacacs
802.1X | access | Port-based network access control: a device must authenticate (often via RADIUS) before the switch port or Wi-Fi lets it on. | - | 8021x, dot1x
SSID | network | The name of a Wi-Fi network that you see in the list. | - | network name
WEP | network | The original Wi-Fi security. Broken in minutes by IV reuse. Never use it. | s:pairs | wired equivalent privacy
Access point | network | A device that provides Wi-Fi and connects it to the wired network. | - | wap, ap, wireless access point
Rogue access point | attacks | An unauthorized Wi-Fi access point connected to a network, or one set up to lure users. | - | rogue ap
Evil twin | attacks | A fake Wi-Fi access point that copies a real network's name so victims connect to the attacker. | - | -
Deauthentication attack | attacks | Sending forged Wi-Fi management frames that kick clients off a network, often to capture the handshake when they reconnect. | - | deauth attack, deauth
Modem | network | Converts the ISP's signal (cable, DSL, fiber) into Ethernet your router can use. | - | -
Bridge | network | A device that joins two network segments at layer 2. A switch is a multi-port bridge. | - | -
Stateful firewall | network | A firewall that tracks connections, so it allows replies to traffic you started and blocks unsolicited traffic. | g:firewalls-pfsense | stateless firewall, packet filtering
NGFW | network | Next-generation firewall: adds application awareness, intrusion prevention and user identity to a normal firewall. | - | next generation firewall
Port forwarding | network | A rule that sends traffic arriving at one public port to a specific internal host and port. | - | -
Port mirroring | network | Copying traffic from one switch port to another so a sensor or analyzer can watch it. Called SPAN on Cisco. | - | span port, span, tap, network tap
QoS | network | Quality of service: prioritizing some traffic, like voice, over other traffic. | - | quality of service
Jitter | network | Variation in packet delay. Bad jitter breaks voice and video calls. | - | -
Spanning Tree Protocol | network | STP: switches use it to block redundant links so loops don't flood the network. | - | stp
Trunk port | network | A switch port that carries traffic for many VLANs, tagged with 802.1Q. | - | 8021q, vlan trunk
Routing table | network | The list of networks a router knows and which next hop to use for each. | - | -
Static routing | network | Routes entered by hand. Dynamic routing protocols such as OSPF and BGP learn them automatically. | - | dynamic routing
MPLS | network | A carrier technology that forwards packets by labels instead of IP lookups. Used for private WAN circuits. | - | -
SD-WAN | network | Software-managed WAN that steers traffic over several links (broadband, LTE, MPLS) by policy. | - | software defined wan
Peer-to-peer | network | A design where devices share directly with each other instead of through a central server. | - | p2p
Client-server | network | A design where clients request things and a central server provides them. | - | -
Intranet | network | A private network or site used inside an organization. An extranet shares part of it with partners. | - | extranet
Loopback | network | The address a machine uses to talk to itself: 127.0.0.1 for IPv4, ::1 for IPv6. | - | 127.0.0.1
APIPA | network | The 169.254.x.x address Windows assigns itself when it can't reach a DHCP server. A sign DHCP is broken. | - | 169.254, link local
DHCP lease | network | The time a client may keep the IP address a DHCP server gave it before renewing. | - | lease
Socket | network | One endpoint of a network connection: an IP address plus a port. | - | -
Ephemeral port | network | A high temporary port (often 49152 and up) a client picks for the source side of a connection. | - | -
Well-known ports | network | Ports 0 to 1023, reserved for standard services such as 22 SSH, 53 DNS, 80 HTTP and 443 HTTPS. | b:ports-and-protocols | port numbers, common ports
Banner grabbing | recon | Connecting to a service and reading its greeting to learn its software and version. | - | banner
SYN flood | attacks | A DoS attack that sends many TCP SYNs and never finishes the handshake, filling the server's connection table. | - | syn attack
Smurf attack | attacks | A DDoS that sends ICMP echo requests with a spoofed source to a broadcast address so many hosts flood the victim. | - | -
MAC flooding | attacks | Overwhelming a switch's address table so it fails open and acts like a hub, letting an attacker sniff traffic. | - | cam table overflow
MAC spoofing | attacks | Changing a device's MAC address to impersonate another device or bypass filtering. | - | -
VLAN hopping | attacks | Sending traffic into a VLAN you shouldn't reach, by switch spoofing or double tagging. | - | -
Sniffing | attacks | Capturing traffic passing on a network to read it. Works on unencrypted protocols and on shared or mirrored links. | - | packet sniffing, eavesdropping
Promiscuous mode | network | A network card mode that accepts all frames it sees, not only those addressed to it. Needed for sniffing. | - | -
Network segmentation | hardening | Splitting a network into zones with controls between them so a breach can't spread everywhere. | - | segmentation
Air gap | hardening | Keeping a system physically disconnected from other networks. | - | air gapped
NAC | access | Network access control: checks a device's identity and health before it can join the network. | - | network access control
Bastion host | hardening | A hardened server exposed on purpose as the one way in to a private network. Also called a jump box. | - | jump box, jump host
BYOD | it | Bring your own device: staff use personal phones and laptops for work. MDM software enforces rules on them. | - | bring your own device, mdm, mobile device management
# ---- operating systems ----
Service | os | A background program with no window, such as a web server or print spooler. On Linux it is called a daemon. | - | daemon, services
systemd | linux | The init system on most modern Linux distros. It starts services and is controlled with systemctl. | g:linux-server-admin-ubuntu | systemctl, init
Boot process | os | Power on, firmware (BIOS/UEFI) runs, the bootloader loads, the kernel starts, then services and the login screen. | - | startup process
Bootloader | os | The small program that loads the operating system kernel. GRUB on Linux, Windows Boot Manager on Windows. | - | grub, boot manager
MBR | os | Master Boot Record: the first sector of a disk, holding boot code and a partition table. Limited to 2 TB disks. | - | master boot record
GPT | os | GUID Partition Table: the modern partition scheme that supports huge disks and is used with UEFI. | - | guid partition table
Partition | os | A separate section of a disk that is formatted and used on its own. | - | disk partition
File system | os | The structure that organizes files on a disk. NTFS (Windows), ext4 (Linux), APFS (macOS) and FAT32 (USB drives) are common. | - | filesystem, ext4, fat32, apfs, exfat
Inode | linux | The Linux file system record holding a file's metadata and where its data lives. The file name is stored in the directory. | - | -
Mount | linux | Attaching a file system to a directory so its files become reachable. | - | mounting
Swap | linux | Disk space used as overflow when RAM is full. Windows calls it the page file. | - | page file, swap space
Virtual memory | os | Giving each process its own address space, mapped to RAM or disk by the OS. | - | paging
System call | os | The way a program asks the kernel to do something, such as open a file or create a process. | - | syscall
User space and kernel space | os | Kernel space is the privileged part of memory where the OS runs. User space is where normal programs run, with limited rights. | g:operating-systems | kernel mode, user mode, privilege rings
Root | linux | The all-powerful Linux account (UID 0). The Windows equivalent is Administrator or SYSTEM. | - | superuser, uid 0
UAC | windows | User Account Control: the Windows prompt that asks before a program gets administrator rights. | - | user account control
sudo | linux | Runs a single command as root (or another user) after your password, according to /etc/sudoers. | m:linux | sudoers, su
Environment variable | os | A named value, such as PATH or HOME, that programs can read from their surroundings. | - | env var, path variable, path
Pipe | linux | The vertical bar symbol: connects the output of one command to the input of the next, as in ps aux piped into grep ssh. | g:linux-command-line m:linux | pipes, redirection
stdin, stdout and stderr | linux | The three standard streams of a program: input, normal output and error output. Redirection with >, >> and 2> changes where they go. | - | stdin, stdout, stderr
Exit code | linux | The number a program returns when it ends. 0 means success; anything else means some kind of failure. | - | return code, exit status
Package manager | os | A tool that installs, updates and removes software and handles dependencies: apt, dnf, brew, winget, pip, npm. | - | apt, yum, dnf, brew, winget, apt-get
WSL | windows | Windows Subsystem for Linux: runs a real Linux environment inside Windows without a separate VM. | - | windows subsystem for linux
Event Viewer | windows | The Windows tool for reading event logs (Application, Security, System). The first place to look when something fails. | - | windows event log, event log
Task Manager | windows | The Windows tool that lists processes and resource use. Ctrl+Shift+Esc opens it. | - | -
Safe mode | windows | A Windows startup with only core drivers and services, used to fix problems or remove malware. | - | -
Dual boot | os | Installing two operating systems side by side and picking one at startup. | - | -
Live USB | linux | Running an operating system straight from a USB stick without installing it. Used for rescue and forensics. | - | live cd, live boot
ISO image | os | A single file that is a copy of an optical disc, used to install an operating system. | - | iso
Snapshot | virtualization | A saved point-in-time state of a VM or disk that you can roll back to. Not a replacement for backups. | g:virtualization-proxmox | vm snapshot
SELinux | linux | Mandatory access control for Linux: policies limit what each process may touch, even when it runs as root. | - | apparmor, mac
chmod | linux | Linux command that changes file permissions, for example chmod 640 file or chmod +x script.sh. | d:linux-permissions | file permissions, rwx
chown | linux | Linux command that changes a file's owner and group. | d:linux-permissions | -
SSH key | access | A key pair used to log in over SSH without a password. The private key stays with you; the public key goes in ~/.ssh/authorized_keys on the server. | g:kali-linux | authorized_keys, ssh keys, ssh-keygen
Log rotation | linux | Automatically archiving and deleting old log files so they don't fill the disk. | - | logrotate
Shell script | linux | A text file of shell commands run as a program. | g:bash-scripting | bash script
Terminal | linux | The window where you type commands. The shell is the program inside it that interprets them. | - | command line, cli, tty, console
PID | os | Process ID: the number the OS gives each running process. | - | process id
Zombie process | os | A process that has finished but whose parent hasn't collected its exit status yet. | - | -
Fork | os | A system call that creates a copy of the running process. | - | fork bomb
Mutex | os | A lock that lets only one thread use a shared resource at a time. | - | semaphore, lock
Deadlock | os | Two or more processes each waiting for something the other holds, so none can continue. | - | -
Scheduler | os | The part of the OS that decides which process uses the CPU and for how long. | g:operating-systems | cpu scheduling, context switch
Page fault | os | What happens when a program touches memory that isn't currently in RAM, so the OS has to load it. | - | -
DLL | windows | Dynamic-link library: a Windows file of shared code that programs load at run time. Attackers abuse it with DLL hijacking and injection. | - | dll hijacking, dynamic link library
ELF | linux | The executable file format on Linux. Windows uses PE. | - | elf file
PE file | windows | Portable Executable: the Windows format for .exe and .dll files. | g:pe-format-pe-bear | pe format, portable executable
Executable | os | A file the OS can run as a program. | - | exe
Library | programming | A bundle of reusable code you call from your own program. | - | libraries
# ---- hardware ----
Motherboard | hardware | The main circuit board that connects the CPU, memory, storage and expansion cards. | g:hardware-diagnostics-and-repair | mainboard
PSU | hardware | Power supply unit: converts wall power into the voltages a computer uses. | g:hardware-diagnostics-and-repair | power supply
NIC | hardware | Network interface card: the hardware that connects a computer to a network. | - | network card, network adapter, network interface card
Core | hardware | One processing unit inside a CPU. More cores mean more tasks at once. | - | cpu core, multicore
Clock speed | hardware | How many cycles per second a CPU runs, in GHz. | - | ghz
x86 | hardware | The CPU instruction set family used in most PCs and servers. x64 or AMD64 is its 64-bit version. | g:c-x86-assembly | x64, amd64, x86-64
ARM | hardware | A CPU architecture common in phones, Macs and Raspberry Pis, known for low power use. | - | arm processor, apple silicon
Register | hardware | A tiny, very fast storage slot inside the CPU. On x86, examples are EAX, RSP and RIP. | g:c-x86-assembly | cpu register
Instruction set | hardware | The set of operations a CPU understands. Assembly language is a readable form of it. | - | isa
PCIe | hardware | The fast expansion bus used for graphics cards, NVMe drives and network cards. | - | pci express
SATA | hardware | The common interface for SSDs and hard drives. Slower than NVMe. | - | -
NVMe | hardware | A fast storage protocol that runs over PCIe, used by M.2 SSDs. | - | m.2
USB | hardware | Universal Serial Bus: the common connector for peripherals. A malicious USB device can act as a keyboard (BadUSB, Rubber Ducky). | - | usb drive, rubber ducky, badusb
TPM | hardware | Trusted Platform Module: a chip that stores keys and checks that boot software hasn't been tampered with. BitLocker and Windows 11 use it. | - | trusted platform module
HSM | hardware | Hardware security module: a tamper-resistant device that stores and uses cryptographic keys without exposing them. | - | hardware security module
Hardware security key | access | A small device such as a YubiKey that proves your identity with FIDO2/WebAuthn. It resists phishing. | - | yubikey, fido2 key, security key
Full disk encryption | hardening | Encrypting the whole drive so a stolen laptop or disk is unreadable. BitLocker, FileVault and LUKS do this. | s:3.3 | bitlocker, luks, filevault, fde
Embedded system | hardware | A small computer built into a device for one job, such as a router, thermostat or car controller. | - | embedded device, embedded
Microcontroller | hardware | A tiny computer on one chip with CPU, memory and I/O. Arduino boards use them. | - | arduino
Raspberry Pi | hardware | A cheap credit-card sized Linux computer, popular for homelabs and projects. | - | raspberry
Side-channel attack | attacks | Learning secrets from physical effects like timing, power use or cache behavior instead of attacking the algorithm. | - | timing attack
Spectre and Meltdown | vulns | CPU flaws from speculative execution that let a program read memory it shouldn't. Fixed partly in hardware, partly in software. | - | spectre, meltdown
Rowhammer | vulns | Repeatedly reading one memory row to flip bits in neighboring rows, which can break memory protections. | - | -
UART | hardware | A simple serial connection often exposed on devices as a debug console. Common first step in hardware hacking. | - | serial console, jtag
ECC memory | hardware | RAM that detects and corrects single-bit errors. Used in servers. | - | error correcting memory
Overclocking | hardware | Running a CPU or GPU faster than its rated speed. Faster, hotter, less stable. | - | -
# ---- attacks, malware and exploitation ----
Shellcode | attacks | A small piece of machine code injected into a process, usually to open a shell. | g:binary-exploitation | -
ROP | attacks | Return-oriented programming: chaining small snippets of existing code (gadgets) to run an attack when the stack can't execute code. | u:rev/rop-basics | return oriented programming, rop chain, gadget
ASLR | hardening | Address space layout randomization: loads programs and libraries at random addresses so attackers can't predict where code is. | u:rev/mitigations | address space layout randomization
DEP | hardening | Data execution prevention (NX): marks memory like the stack as non-executable so injected code can't run there. | u:rev/mitigations | nx, no execute, nx bit
Stack canary | hardening | A secret value placed before the return address; if a buffer overflow changes it, the program stops. | u:rev/mitigations | stack cookie, canary
Format string vulnerability | vulns | A bug where user input is used as the format string of printf-like functions, allowing memory reads and writes. | u:rev/format-strings | format string
Code injection | attacks | Getting a program to run attacker-supplied code. SQL injection, command injection and DLL injection are kinds of it. | - | injection
Process injection | attacks | Running malicious code inside another running process to hide and borrow its privileges. | - | dll injection, process hollowing
Persistence | attacks | The ways an attacker keeps access after a reboot: run keys, scheduled tasks, services, cron jobs, new accounts. | - | persistence mechanism
Pass the hash | attacks | Logging in with a stolen NTLM password hash directly, without ever cracking the password. | g:active-directory | pth
Pass the ticket | attacks | Reusing a stolen Kerberos ticket to authenticate as its owner. | g:active-directory | -

AS-REP roasting | attacks | Asking for authentication data for accounts that don't require Kerberos pre-authentication, then cracking it offline. | u:pentest/ad-attacks | asrep roasting
DCSync | attacks | Pretending to be a domain controller to ask for password hashes through directory replication. | u:pentest/ad-attacks | -
Mimikatz | tools | A tool that pulls passwords, hashes and Kerberos tickets out of Windows memory (LSASS). | u:pentest/ad-attacks | -
BloodHound | tools | A tool that maps Active Directory relationships to find the shortest path to Domain Admin. | u:pentest/ad-attacks | -
LSASS | windows | Local Security Authority Subsystem Service: the Windows process that holds credentials in memory. Dumping it is a common attack. | - | lsass.exe, credential dumping
Rainbow table | attacks | A precomputed table of hashes for reversing unsalted password hashes quickly. Salting defeats it. | g:password-cracking-john | rainbow tables
Dictionary attack | attacks | Trying passwords from a word list instead of every combination. | g:password-cracking-john | wordlist, word list
Hashcat | tools | A fast password cracker that uses GPUs. | g:password-cracking-john | -
John the Ripper | tools | A classic password cracking tool for many hash formats. | g:password-cracking-john | john, jtr
Hydra | tools | A tool that guesses logins against live services such as SSH, FTP and web forms. | - | thc-hydra
Credential harvesting | attacks | Collecting usernames and passwords, for instance through fake login pages. | - | -
Clickjacking | web | Tricking someone into clicking something hidden under what they think they're clicking, by layering a transparent frame. | w:owasp-top-10 | -
Drive-by download | attacks | Malware installed just by visiting a compromised page, with no click. | - | -
Malvertising | attacks | Malicious ads that deliver malware or send users to attacker sites. | - | -
Cryptojacking | malware | Secretly using someone's computer or cloud account to mine cryptocurrency. | - | cryptominer
Wiper | malware | Malware that destroys data instead of holding it for ransom. | - | -
Logic bomb | malware | Code that lies dormant until a condition is met, such as a date or a deleted account. | - | -
PUP | malware | Potentially unwanted program: bundled software like toolbars that isn't quite malware but isn't wanted. | - | potentially unwanted program, bloatware
Macro malware | malware | Malicious macros inside Office documents that run when a user enables content. | - | malicious macro, maldoc
Polymorphic malware | malware | Malware that changes its own code each time it spreads, to avoid signature detection. | g:malware-analysis | metamorphic malware
Packer | malware | A tool that compresses or encrypts a program so its real code is hidden until it runs. UPX is a common one. | u:rev/unpacking | packing, upx, crypter

Ghidra | tools | A free reverse engineering suite from the NSA, with a disassembler and decompiler. | g:ghidra-and-ida-pro | -
IDA Pro | tools | A leading commercial disassembler and debugger for reverse engineering. | g:ghidra-and-ida-pro | ida
Strings | tools | Pulling readable text out of a binary. Often the quickest hint about what a program does. | g:malware-analysis | strings command
VirusTotal | tools | A website that scans files, hashes and URLs with many antivirus engines. Don't upload sensitive files; they become visible to others. | - | virus total
TTP | soc | Tactics, techniques and procedures: how an attacker behaves, from goal to exact method. | u:detect/attack-mapping | tactics techniques procedures
Threat modeling | concepts | Thinking through what can go wrong with a system before building it, to design defenses. | u:sdl/threat-modeling | threat model
STRIDE | concepts | A threat modeling checklist: Spoofing, Tampering, Repudiation, Information disclosure, Denial of service, Elevation of privilege. | u:sdl/threat-modeling | -
Attack vector | threats | The path an attacker uses to get in, such as email, an exposed service, a USB drive or a supplier. | s:2.2 | threat vector
STIX and TAXII | soc | STIX is a format for describing threat intelligence. TAXII is the protocol for sharing it. | - | stix, taxii
MISP | tools | An open source platform for sharing threat intelligence and indicators. | - | -

NVD | vulns | National Vulnerability Database: the US database that adds severity scores and details to CVEs. | s:4.3 | national vulnerability database
