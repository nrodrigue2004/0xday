~/courses

Everything already on the site, grouped into courses with modules, a quiz per module and an exam. This is a self-study curriculum modeled on a degree plan, not an accredited one. Progress is saved in this browser only; ~/transcript has the rollup and a backup button.

Placement: every course has an exam. Score 80% or better without doing the modules and the course is marked tested out. Locks are soft: a course whose prerequisites are unfinished is flagged but never blocked.

# Foundations

  • IT100 How computers worknot started

    Number systems, hardware, what an OS does, and just enough basic electronics to read a circuit.

    needs: none · 4 modules · ~3.6 h · 16 questions

  • IT110 Networking basicsnot started

    OSI and TCP/IP, ports, addressing, subnets, DHCP and NAT.

    needs: IT100 · 4 modules · ~3.9 h · 16 questions

  • IT120 Linux and Windows adminnot started

    The command line on both sides, scripting, and the Active Directory basics every help desk touches.

    needs: IT100 · 4 modules · ~6.5 h · 16 questions

  • SEC100 Security+not started

    The five SY0-701 domains. This quiz is a quick check; the full study tools live in ~/secplus.

    needs: IT110 · 5 modules · ~9.5 h · 20 questions

# CS core

  • CS210 Hardware and basic EEnot started

    Ohm's law, basic circuits, how the CPU, RAM and storage connect, and the boot chain. Basic electronics only, no gate-level logic.

    needs: IT100 · 4 modules · ~4.2 h · 28 questions

  • CS220 Operating systemsnot started

    Processes, scheduling, virtual memory, file systems, concurrency and deadlock, with scheduler, paging and Banker's simulators.

    needs: CS210, IT120 · 7 modules · ~9 h · 49 questions

  • CS230 Databasesnot started

    Relational model, normalization, indexes, query plans, transactions and database security, with a dependency tool, an index demo and a serializability checker.

    needs: none · 6 modules · ~7.8 h · 40 questions
