CS310 Compilers

How source text becomes a running program: the pipeline, a lexer, a recursive-descent parser and a tree-walking interpreter you finish yourself.

needs: CS340 · 4 modules · ~5.5 h of study · not started

# modules

  1. 1. Source to machine code ~60 min

    ~/langs: source to machine code ~/learn: C and x86 assembly Compiler Explorer

  2. 2. The lexer ~60 min

    ~/langs: the lexer ~/drills: regex for logs

  3. 3. Grammars and the parser ~90 min

    ~/langs: grammars and the parser Crafting Interpreters (free book)

  4. 4. A tiny interpreter ~120 min

    ~/langs: a tiny interpreter Crafting Interpreters (free book)

    Stretch goal after the lab: add an if statement and a function call to the calculator language, then read the first half of Crafting Interpreters.

# exam

16 questions drawn from the whole course. Score 80% or better to pass. If you take it before doing any modules, a pass counts as tested out, which is how placement works. Retakes are fine and the best score is kept.
