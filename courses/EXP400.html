EXP400 Binary exploitation

How memory bugs become control of a program and how mitigations stop them: stack overflows, format strings, canaries, ASLR and ROP. Toy programs only, in a lab.

needs: MAL300 · 4 modules · ~4.8 h of study · not started

# exam

16 questions drawn from the whole course. Score 80% or better to pass. If you take it before doing any modules, a pass counts as tested out, which is how placement works. Retakes are fine and the best score is kept.
