AI310 Prompt engineering

Write prompts that work, test them like code, and know how they fail. Clear instructions, examples, structured output, reasoning, evals, and the defender's view of prompt injection and leakage. Fictional data throughout.

needs: IT100 · 4 modules · ~5.2 h of study · not started

# modules

  1. 1. Prompt basics ~60 min

    ~/ai: prompts, basics (lab: grade three versions) man prompts

  2. 2. Patterns: examples, roles, structure ~75 min

    ~/ai: prompts, patterns (lab: schema check)

  3. 3. Reasoning, iterating and testing ~90 min

    ~/ai: prompts, reasoning and testing (lab: compare versions)

  4. 4. Prompt security ~90 min

    ~/ai: prompts, security (lab: design review) ~/ai: attacking AI OWASP GenAI Security Project

# exam

20 questions drawn from the whole course. Score 80% or better to pass. If you take it before doing any modules, a pass counts as tested out, which is how placement works. Retakes are fine and the best score is kept.
