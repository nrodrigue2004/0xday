CS210 Hardware and basic EE

Ohm's law, basic circuits, how the CPU, RAM and storage connect, and the boot chain. Basic electronics only, no gate-level logic.

needs: IT100 · 4 modules · ~4.2 h of study · not started

# modules

  1. 1. Voltage, current, resistance ~60 min

    Khan Academy: electrical engineering All About Circuits: Volume 1, DC

    Voltage (volts, V) is the push between two points. Current (amps, A) is the flow of charge. Resistance (ohms) is how much a part opposes the flow. Ohm's law ties them together: V = I x R, so I = V / R and R = V / I. Example: 12 V across 4 kilohms gives 3 mA.

    Power (watts) is P = V x I. Combined with Ohm's law, P = I^2 x R = V^2 / R. A resistor must be rated for the power it burns: 5 V across 1 kilohm is 5 mA and 25 mW, fine for a 1/4 W part. Heat is where wasted power goes.

    DC has a fixed polarity (batteries, USB, every chip's supply). AC reverses direction (wall power). Chips run on low-voltage DC; the power supply in a PC converts AC to DC. Read the units carefully: milli = 1/1000, kilo = 1000, micro = 1/1,000,000.

  2. 2. Basic circuits and measuring ~75 min

    Falstad circuit simulator (free, in the browser) Tinkercad Circuits (free simulator) ~/learn: hardware diagnostics and repair

    Series: parts in a chain. The same current flows through all of them and resistances add (R = R1 + R2 + ...). Voltage splits in proportion to resistance. Parallel: parts across the same two points. Each branch sees the same voltage, currents add, and the combined resistance is lower than the smallest branch (1/R = 1/R1 + 1/R2; for two parts, R = R1 x R2 / (R1 + R2)).

    Voltage divider: two resistors in series split the input, Vout = Vin x R2 / (R1 + R2). It is how sensors and reference levels are made. LEDs: past their forward voltage (about 2 V red, 3 V blue) they conduct freely, so always add a series resistor, R = (Vsupply - Vf) / I. A 5 V supply, a 2 V LED and 10 mA needs 300 ohms.

    Meter use: measure voltage in parallel, current in series (break the circuit), resistance with the part unpowered. Never put an ammeter across a supply. A solderless breadboard connects the five holes in each short row; power rails run the length of the board. Build the LED circuit in a simulator first, then on a real breadboard if you have one.

  3. 3. How the CPU, RAM and storage connect ~75 min

    ~/learn: C and x86 assembly ~/basics: number systems Crash Course Computer Science (YouTube)

    The CPU repeats fetch, decode, execute forever. The program counter holds the next instruction's address; registers hold the working values; the ALU does the math. Everything outside the CPU is slower, so there is a hierarchy: registers (under 1 ns), L1/L2/L3 cache (SRAM, a few ns), RAM (DRAM, about 100 ns), SSD (about 100 microseconds), hard disk (milliseconds). Caches work because programs reuse nearby data and recent data (locality).

    The CPU talks to RAM over memory channels and to everything else over PCIe lanes, either directly or through the chipset. NVMe SSDs sit on PCIe; SATA drives use an older interface designed for spinning disks; USB and Ethernet reach the CPU through controllers. Devices can use DMA to move data into RAM without the CPU copying each byte, then raise an interrupt when done. Address width sets the ceiling: 32 bits reach 4 GiB, 64 bits far more.

    Security link: the same view explains why a malicious PCIe or Thunderbolt device can read memory unless an IOMMU limits DMA, and why exploits aim at the program counter. No gate-level logic is needed here; the goal is a mental map of the box.

  4. 4. Firmware and the boot chain ~45 min

    ~/learn: Windows deployment and drivers ~/learn: system hardening

    Power on: the firmware (UEFI on modern machines, legacy BIOS on old ones) runs POST, initializes hardware, then loads a bootloader from the EFI system partition or the disk's first sector. The bootloader loads the kernel, and the kernel starts the init system and your login screen. Disks use MBR (2 TiB limit with 512-byte sectors, 4 primary partitions) or GPT (64-bit addressing, backup header, required by UEFI boot).

    Secure Boot makes the firmware check a signature on each stage before running it. A TPM is a small tamper-resistant chip that holds keys and records measurements of the boot chain, so BitLocker can refuse to release the disk key if the chain changed. Bootkits and firmware implants load before the OS and hide from it, which is why defenders watch the chain itself.

    Practical hardening for a laptop: set a firmware password, lock the boot order to the internal disk, turn on Secure Boot, and use full-disk encryption. Anyone with ten minutes and a USB stick can otherwise read an unencrypted disk.
