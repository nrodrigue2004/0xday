CS201 Data structures and algorithms in depth

Sorting, hashing, trees, graphs, dynamic programming and proofs of cost, with a step-by-step visualizer, a lab per chapter and interview practice.

needs: none · 7 modules · ~14 h of study · not started

# modules

  1. 1. Sorting ~120 min

    ~/cs: sorting algorithms visualizer: sorting ~/bigo: cost tables

  2. 2. Hashing and hash tables ~90 min

    ~/cs: hash tables and hashing visualizer: hash tables

  3. 3. Trees, heaps and tries ~120 min

    ~/cs: trees, heaps and tries visualizer: trees and heaps

  4. 4. Graphs ~150 min

    ~/cs: graphs visualizer: BFS, DFS, Dijkstra

  5. 5. Dynamic programming, greedy and backtracking ~150 min

    ~/cs: dynamic programming visualizer: DP tables

  6. 6. Algorithm analysis and proofs ~90 min

    ~/cs: algorithm analysis ~/bigo: growth chart and drill

  7. 7. Interview practice ~120 min

    ~/interview: technical screen ~/dojo: coding katas ~/learn: data structures and algorithms guide

    Pick three problems per topic, solve each on paper first, then code it with a timer. State time and space cost out loud, then test with an empty input and a one-item input.

# exam

20 questions drawn from the whole course. Score 80% or better to pass. If you take it before doing any modules, a pass counts as tested out, which is how placement works. Retakes are fine and the best score is kept.
