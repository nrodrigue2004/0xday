CS330 AI and machine learning

Starts from zero: what machine learning is, in plain English. Then a short linear algebra refresher, regression, classifiers and honest evaluation, with a lab per chapter and a model you train in the browser. Security examples throughout.

needs: IT100 · 6 modules · ~7.8 h of study · not started

# modules

  1. 1. What is machine learning? ~60 min

    ~/ai: what is ML (lab: count words for a spam filter)

  2. 2. Math refresher ~60 min

    ~/ai: ML math refresher (with lab) 3Blue1Brown: Essence of linear algebra

  3. 3. Regression ~90 min

    ~/ai: regression (with lab) ~/learn: Python

  4. 4. Classifiers ~90 min

    ~/ai: classifiers (with lab)

  5. 5. Evaluating models ~90 min

    ~/ai: evaluating models (lab: read a classifier)

  6. 6. Train one and use it ~75 min

    ~/ai: ML playground ~/ai: how AI works ~/ai: attacking AI

# exam

20 questions drawn from the whole course. Score 80% or better to pass. If you take it before doing any modules, a pass counts as tested out, which is how placement works. Retakes are fine and the best score is kept.
