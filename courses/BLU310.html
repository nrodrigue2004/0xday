BLU310 Detection engineering and threat hunting

Write detections instead of just reading alerts: ATT&CK mapping, Sigma and YARA rules, and hypothesis-driven hunts.

needs: BLU200 · 4 modules · ~5.8 h of study · not started

# modules

  1. 1. ATT&CK and detection basics ~75 min

    ~/detect: ATT&CK and detection basics ~/learn: log analysis MITRE ATT&CK (attack.mitre.org)

  2. 2. Sigma rules ~90 min

    ~/detect: Sigma rules ~/learn: SIEM with Security Onion SigmaHQ rule repository

  3. 3. YARA rules ~90 min

    ~/detect: YARA rules ~/learn: malware analysis YARA documentation

  4. 4. Threat hunting ~90 min

    ~/detect: threat hunting ~/learn: network traffic analysis

    Finish by writing one hunt in the template from the chapter and a Sigma rule that would have caught what you found.

# exam

20 questions drawn from the whole course. Score 80% or better to pass. If you take it before doing any modules, a pass counts as tested out, which is how placement works. Retakes are fine and the best score is kept.
