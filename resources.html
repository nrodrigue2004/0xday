~/resources

Sites and tools I reach for. Each one says when to use it and what to be careful about.

check a file, link or hash

  • VirusTotal Scan a file hash, URL, domain or IP against ~70 AV engines and see what others found. ⚠ Uploads are PUBLIC to paying customers. Search by hash first; never upload private or work files.
  • Hybrid Analysis Free sandbox report: what a sample did when run (processes, network, dropped files). ⚠ Same rule: submissions can be shared.
  • ANY.RUN Interactive malware sandbox: watch a sample run live in a VM. ⚠ Free tier reports are public.
  • urlscan.io Safely load a suspicious link and see screenshot, redirects, requests and hosting. ⚠ Public scans are listed; mark private if the URL contains tokens.
  • MalwareBazaar Look up and download known malware samples by hash (for lab use only). ⚠ Handle only inside an isolated VM.
  • CyberChef Decode base64, hex, XOR, URL encoding and more by chaining operations. Runs in your browser.

passwords and hashes

  • CrackStation Paste an unsalted hash (MD5, SHA-1, NTLM...) and it looks it up in a huge table of known passwords. Shows why weak and unsalted hashes are dangerous. ⚠ Only hashes from your own labs or CTFs. Never paste a real account's hash: you'd be sending it to a stranger.
  • hashcat The GPU password-auditing tool, like John the Ripper. Used on your own lab to test how fast weak passwords fall. ⚠ Authorized targets only.
  • hashes.com hash identifier Paste a hash to see which type it is (MD5, bcrypt, NTLM...) before choosing a tool. ⚠ Lab hashes only.
  • Have I Been Pwned: Pwned Passwords Check if a password is in known breaches. Uses k-anonymity, so the full password never leaves your browser. ⚠ Still prefer the range API or a password manager's built-in check.

email and account checks

  • Have I Been Pwned Is my email in a known breach? Also check passwords through the k-anonymity range search. ⚠ Only enter your own addresses.
  • MXToolbox Check a domain's MX, SPF, DKIM and DMARC records, blacklists and header analysis.
  • Google Admin Toolbox: Messageheader Paste an email's headers to see the path and delays. Good for phishing triage. ⚠ Headers can contain addresses: redact before sharing.
  • EmailRep Reputation lookup for an email address (age, spam and breach signals).

history and OSINT

  • Internet Archive Wayback Machine See old versions of a page, recover deleted content, or save a snapshot as evidence.
  • archive.today Snapshot a page you want to preserve without visiting it again.
  • Shodan Search engine for internet-connected devices. Great for checking YOUR OWN exposure. ⚠ Look, don't touch anything that isn't yours.
  • crt.sh Certificate transparency search: find subdomains and certificates for a domain.
  • AbuseIPDB Is this IP reported for attacks? Check suspicious IPs from your logs.
  • WHOIS / DomainTools Whois Domain age and registrar. A days-old domain in an email is a red flag.

setup and software

  • Ninite Pick apps (Chrome, 7-Zip, VLC...) and get ONE installer that silently installs them with no toolbars. Handy for fresh Windows builds. ⚠ Only from ninite.com.
  • Chocolatey / winget Install and update Windows software from the command line.
  • Ventoy One USB stick that boots many ISO files. Copy ISOs on, pick at boot.
  • Sysinternals Process Explorer, Autoruns, TCPView and friends for Windows troubleshooting and forensics.
  • Microsoft Security Compliance Toolkit Baseline GPOs for hardening Windows.

bug bounty and web hacking: free training

  • PortSwigger Web Security Academy Free, self-paced web security course with a hands-on lab for every topic (SQL injection, XSS, access control, SSRF and more). The best free place to start. ⚠ Labs are made to be attacked. Never use these techniques on real sites you do not have written permission to test.
  • Hacker101 HackerOne's free video classes plus a CTF where flags teach real web bugs. Written for people who want to start bounty hunting. ⚠ The CTF is in a controlled environment; real programs have rules, see below.
  • TryHackMe Guided browser-based rooms with a target machine provided. The web and bug bounty related paths are a gentle start. I use this one. ⚠ Some rooms and paths need a paid subscription; the free tier is enough to start.
  • OWASP Juice Shop A deliberately insecure web shop to attack on your own machine, with a score board and hints. ⚠ Run it locally or in a container, not exposed to the internet.
  • OWASP WebGoat Guided lessons on common web flaws in a vulnerable Java app. ⚠ Same rule: local only.
  • OWASP Top 10 The list of most common web risks. Read it before the labs so the names mean something.
  • Bugcrowd University Free videos and slides on bug bounty methods from a bounty platform.
  • HackerOne program directory Public bounty programs and their scope and rules, so you can see what a real policy says. ⚠ Read the scope and safe-harbor policy of any program before you test anything. Out-of-scope testing can be illegal.
  • Bugcrowd programs Another list of public programs and disclosure policies. ⚠ Same warning: stay in scope, no data access beyond proof, report quickly.
  • PentesterLab free content Exercises and badges on web bugs; the free section has a good number of exercises. ⚠ Most of the library is paid.
