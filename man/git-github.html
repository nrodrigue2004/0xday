git-github - Git / GitHub commands and terms

SECTIONS starting everyday branches history undoing secrets and hygiene terms scripts in git

starting

git init
create a repository here
git clone URL
copy a remote repository
git config --global user.name "Name"
set your identity
git remote -v
show remotes

everyday

git status
what changed
git add -p
stage selected chunks
git commit -m "msg"
save a snapshot
git diff
unstaged changes
git diff --staged
staged changes
git pull
fetch and merge
git push
upload commits

branches

git branch
list branches
git switch -c name
create and switch
git switch name
change branch
git merge name
merge into the current branch
git rebase main
replay your work on top of main
git branch -d name
delete a merged branch

history

git log --oneline --graph --all
compact history graph
git show <commit>
one commit in full
git blame file
who last changed each line
git log -S"text"
commits that added or removed text
git log -p -- path
history of one file with diffs
git bisect start
find the commit that broke something

undoing

git restore file
discard edits in a file
git restore --staged file
unstage
git commit --amend
rewrite the last commit
git revert <commit>
new commit that undoes one
git reset --hard <commit>
discard everything after a commit
git reflog
recover lost commits
git stash / git stash pop
shelve work temporarily

secrets and hygiene

git ls-files
files being tracked
git rm --cached file
stop tracking but keep the file
.gitignore
patterns Git should skip
git filter-repo --path secrets.env --invert-paths
purge a file from history
gitleaks detect
scan history for secrets

terms

HEAD
the commit you are on
origin
default name of the remote
Fast-forward
merge that just moves the branch pointer
Detached HEAD
checked out a commit, not a branch
Fork
your own copy of someone's repo on GitHub

git show sha

git diff v1.4 HEAD
what a release changes
git bisect start
begin a binary search for a bad commit
git bisect run ./test.sh
automatic bisect with a test script
git revert sha
undo a commit safely on a shared branch
git tag v1.4
mark a deployed version
git check-ignore -v file
why is this file ignored?
