cmd - Windows Command Prompt: files, network, services, users and the built-in triage tools

SECTIONS files & folders system info networking processes, services & tasks users & permissions disk & repair logs & policy triage & forensics

files & folders

dir /a
list everything, including hidden and system files
dir /s /b *.log
recursive search for .log files, one full path per line
dir /r
show alternate data streams (a classic place to hide data)
cd /d D:\logs
change drive and folder in one step
tree /f C:\share
folder tree including files
type notes.txt | more
print a file, one screen at a time
copy a.txt b.txt
copy a file
robocopy C:\src D:\dst /e /copy:DAT /r:1 /w:1
copy a folder tree with data, attributes and timestamps; /mir also deletes extras in the destination
move a.txt archive\ · ren a.txt b.txt
move or rename
del /f /q file.txt · rmdir /s /q old
delete a file or a whole folder without prompting
mkdir a\b\c
create nested folders in one go
attrib +h +s file.txt
set hidden and system attributes; attrib alone lists them
where python
find which executable on PATH will run
fc /b a.bin b.bin
compare two files byte by byte
findstr /s /i /n "password" *.txt *.ini
grep for Windows: recursive, case-insensitive, with line numbers

system info

systeminfo
OS version and build, install date, boot time, domain, installed hotfixes
hostname · ver · winver
machine name, OS version (winver opens a dialog)
set
all environment variables; echo %PATH% for one
driverquery /v
installed drivers with paths and state
msinfo32
full hardware and software inventory (GUI, can export a report)

networking

ipconfig /all
IP, MAC, gateway, DNS servers and DHCP lease for every adapter
ipconfig /release · ipconfig /renew
drop and request a DHCP lease
ipconfig /displaydns · ipconfig /flushdns
show or clear the local DNS cache
ping -n 4 10.0.0.1
four echo requests (-t pings until Ctrl+C)
tracert -d 8.8.8.8
trace the route without reverse DNS lookups
pathping 8.8.8.8
traceroute plus per-hop packet loss
nslookup -type=mx example.com 1.1.1.1
query a record type against a specific DNS server
netstat -ano
every connection and listening port with its PID
netstat -anob
same, plus the executable name (run as admin)
arp -a
ARP cache: IP to MAC mappings on the local segment
route print
routing table
net use Z: \\fs01\finance /persistent:yes
map a network drive
net share · net view \\fs01
shares on this machine, shares on another host
netsh advfirewall show allprofiles
Windows Firewall state for domain, private and public profiles
netsh wlan show profiles
saved Wi-Fi networks
netsh wlan show profile name="SSID" key=clear
shows a saved Wi-Fi key in plaintext (admin), one reason local admin matters
curl -I https://example.com
HTTP headers only (curl ships with Windows 10 and later)

processes, services & tasks

tasklist /v
running processes with user and window title
tasklist /svc
which services live inside each process (useful for svchost.exe)
tasklist /m wininet.dll
processes that loaded a given DLL
taskkill /pid 4242 /f · taskkill /im notepad.exe /f
force-kill by PID or by image name
sc query state= all
every service and its state (the space after = is required)
sc qc Spooler
service config: start type, account and binary path
sc stop Spooler · sc config Spooler start= disabled
stop a service and keep it from starting
schtasks /query /fo list /v
scheduled tasks in detail, a common persistence spot
shutdown /r /t 0 · shutdown /a
reboot now, or abort a pending shutdown

users & permissions

whoami /all
current user, SID, group memberships and privileges
whoami /priv
token privileges; SeDebugPrivilege or SeImpersonatePrivilege are red flags for a low-priv account
net user · net user bob
list local accounts, or details for one
net user bob * /add
create a local user and prompt for the password
net localgroup administrators
who is a local admin
net localgroup administrators bob /add
add a user to local admins
net accounts
local password and lockout policy
net group "Domain Admins" /domain
members of a domain group
runas /user:LAB\admin cmd
start a program as another user
icacls C:\share
show NTFS permissions
icacls C:\share /grant "LAB\Finance:(OI)(CI)M"
grant Modify to a group, inherited by subfolders (CI) and files (OI)
takeown /f file.txt
take ownership of a file
cmdkey /list
credentials stored in Credential Manager
klist · klist purge
show or clear cached Kerberos tickets

disk & repair

chkdsk C: /f
check the file system and fix errors (schedules for next boot on C:)
sfc /scannow
verify and repair protected system files
DISM /Online /Cleanup-Image /RestoreHealth
repair the component store that sfc pulls from
diskpart → list disk, list volume
disk and partition management (destructive commands live here, be careful)
manage-bde -status
BitLocker status for every volume
cipher /w:C:\
overwrite free space so deleted files can't be carved back

logs & policy

wevtutil el
list every event log
wevtutil qe Security /c:20 /rd:true /f:text
newest 20 Security events as text
wevtutil cl Security
clear a log; this itself writes event 1102, which is worth alerting on
auditpol /get /category:*
which audit categories are enabled
gpupdate /force
re-apply Group Policy now
gpresult /r · gpresult /h gp.html
which GPOs applied to this user and machine

triage & forensics

reg query HKLM\Software\Microsoft\Windows\CurrentVersion\Run
machine-wide autostart entries (check HKCU too)
reg export HKLM\SYSTEM\CurrentControlSet\Services svc.reg
export a registry key for offline review
certutil -hashfile sample.exe SHA256
hash a file to look up or compare
certutil -urlcache -f http://host/x.exe x.exe
a built-in downloader that attackers abuse (living off the land); detect it, don't use it
netstat -anob > net.txt & tasklist /v > ps.txt
quick volatile snapshot before you pull the plug
