nmap - network exploration tool and port scanner

SECTIONS discovery port scans services & OS timing & output ports and services speed and output enumeration helpers metasploit console terms

discovery

nmap -sn 10.0.0.0/24
ping sweep: which hosts are up, no port scan
nmap -Pn 10.0.0.5
skip host discovery (treat host as up, useful when ICMP is blocked)
nmap -sL 10.0.0.0/24
list targets only, no packets sent

port scans

nmap -sS 10.0.0.5
TCP SYN (half-open) scan, the default when run as root
nmap -sT 10.0.0.5
full TCP connect scan, no root needed
nmap -sU --top-ports 50 10.0.0.5
UDP scan of the 50 most common UDP ports
nmap -p- 10.0.0.5
all 65535 TCP ports
nmap -p 22,80,443 10.0.0.5
specific ports
nmap --top-ports 1000 --open 10.0.0.5
common ports, show only open ones

services & OS

nmap -sV 10.0.0.5
probe open ports for service and version
nmap -O 10.0.0.5
OS fingerprinting
nmap -A 10.0.0.5
aggressive: -sV -O -sC plus traceroute
nmap -sC 10.0.0.5
run the default NSE scripts
nmap --script smb-enum-shares -p445 10.0.0.5
run a specific NSE script

timing & output

nmap -T4 10.0.0.5
faster timing template (T0 slowest, T5 fastest)
nmap -oA scan 10.0.0.5
save normal, XML and grepable output as scan.*
nmap -v --reason 10.0.0.5
verbose, and say why each port is in its state

ports and services

nmap -sS host
SYN scan, the default as root
nmap -sT host
full connect scan, no root needed
nmap -p- host
all 65535 TCP ports
nmap --top-ports 100 host
most common ports only
nmap -sU --top-ports 20 host
common UDP ports
nmap -sV -sC host
versions plus default scripts
nmap -A host
version, scripts, OS and traceroute

speed and output

nmap -T4 host
faster timing template
nmap --min-rate 1000 host
send at least 1000 packets a second
nmap -oA scan host
save in all formats
nmap --open host
show only open ports

enumeration helpers

gobuster dir -u http://host -w wordlist
brute-force web paths
nikto -h http://host
web server issue scan
smbclient -L //host -N
list SMB shares anonymously
enum4linux -a host
collect SMB and user info
dig axfr @ns domain
attempt a zone transfer
searchsploit name version
search the local Exploit-DB copy
whatweb http://host
identify web technologies
