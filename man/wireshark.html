WIRESHARK-FILTERS(7)0xDay Field ManualWIRESHARK-FILTERS(7)

wireshark-filters - display filters for Wireshark and tshark

addresses & ports

ip.addr == 10.0.0.5
traffic to or from a host
ip.src == 10.0.0.5 && ip.dst == 10.0.0.9
one direction between two hosts
tcp.port == 443
a TCP port in either direction
!(ip.addr == 10.0.0.0/8)
exclude internal traffic, leaves external flows

protocols

http.request
HTTP requests only
http.request.method == "POST"
HTTP POSTs (form submissions, uploads)
dns.qry.name contains "example"
DNS queries matching a name
tls.handshake.extensions_server_name
TLS ClientHellos that carry an SNI hostname
ftp || ftp-data
FTP control and data channels
smb2
SMB2/3 file sharing

TCP behavior

tcp.flags.syn == 1 && tcp.flags.ack == 0
connection attempts (SYNs), good for spotting scans
tcp.flags.reset == 1
resets
tcp.analysis.retransmission
retransmissions, a sign of loss or a struggling link
tcp.len > 1000
packets carrying a big payload

hunting

frame contains "password"
raw string search across frames
http.user_agent contains "curl"
scripted HTTP clients
dns && frame.len > 300
oversized DNS, possible tunneling
Follow > TCP Stream (Ctrl+Alt+Shift+T)
reassemble one conversation
File > Export Objects > HTTP
carve files transferred over HTTP
