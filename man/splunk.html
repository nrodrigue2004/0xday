splunk-spl - Splunk search basics: filter, extract, count, time, and a few detection searches

SECTIONS the shape of a search count and group (stats) fields, filters, extraction detections to start from working habits

the shape of a search

index=main sourcetype=linux_secure
start with where the data lives; always name an index and a time range
index=main "Failed password"
free-text term; quote phrases
index=web status=404 | stats count
pipe results into the next command, like the shell
earliest=-24h latest=now
time range inside the search
| head 20 · | tail 20
first or last rows
| table _time host user src
pick the columns to show
| sort - count
sort, with - for descending
| dedup src
keep the first event per distinct value

count and group (stats)

| stats count by src
how many events per source
| stats count by user, src | sort - count
two-field grouping
| stats dc(src) as sources by user
distinct count: how many different sources per user
| stats values(src) as srcs by user
all distinct values listed together
| stats earliest(_time) as first latest(_time) as last by src
first and last time seen
| top limit=10 src
fast top-N with percentages
| rare src
least common values, good for odd ones out
| timechart span=1h count by status
counts over time, ready to graph

fields, filters, extraction

| where count > 10
filter on a calculated value (use search for raw terms)
| search src!=10.*
filter with wildcards; != keeps events where the field is missing
| rex field=_raw "src=(?<src>\S+)"
extract a field with a named regex group
| rex "user=(?<user>\w+) result=(?<result>\w+)"
several fields in one pattern
| eval is_ext=if(NOT cidrmatch("10.0.0.0/8", src),1,0)
calculate a new field; cidrmatch tests address ranges
| eval hour=strftime(_time,"%H")
time pieces, to find activity at odd hours
| lookup bad_ips ip AS src OUTPUT threat
enrich with a lookup table
| fields - _raw
drop columns

detections to start from

index=win EventCode=4625 | stats count by src_ip | where count>20
password guessing: many failed Windows logons per source
index=win EventCode=4624 Logon_Type=10 | stats count by Account_Name, src_ip
who logs on over RDP and from where
index=win EventCode=4625 OR EventCode=4624 | stats count(eval(EventCode=4625)) as fails count(eval(EventCode=4624)) as oks by src_ip | where fails>5 AND oks>0
failures followed by a success from the same source
index=win EventCode=1102 OR EventCode=104
audit log cleared
index=win EventCode=4688 (New_Process_Name=*\\powershell.exe) CommandLine=*-enc*
encoded PowerShell command lines
index=dns | eval l=len(query) | where l>60 | stats count by src_ip
very long DNS names, possible tunneling
index=fw action=allowed | stats sum(bytes_out) as out by src_ip dest_ip | sort - out | head 10
who sends the most data out, a start for exfil hunting

working habits

narrow first
pick the index, source type and time range before anything else; broad searches are slow and expensive
test on a small window
one hour first, then widen once it works
save as alert
set a schedule and a threshold, and a throttle so one attacker does not page you 400 times
Settings > Fields
if a field you expect is missing, the extraction is the problem, not the data
Free practice
Splunk Free and Boss of the SOC datasets (BOTS) give real data to practice on
