operating-systems - Operating systems commands and terms

SECTIONS processes memory and disk inside a process permissions signals terms

processes

ps aux
all processes with owner and CPU
ps -ef --forest
process tree
top / htop
live resource use
kill -15 PID
ask politely to stop (SIGTERM)
kill -9 PID
force kill (SIGKILL)
nice -n 10 cmd
start with lower priority
jobs, bg, fg
manage shell background jobs

memory and disk

free -h
memory and swap
vmstat 1
memory, swap and CPU every second
cat /proc/meminfo
detailed memory info
df -h
file system usage
mount
what is mounted where
lsof -p PID
files a process has open

inside a process

strace -f -p PID
system calls of a running process
strace -e openat cmd
only file-open calls
ls -l /proc/PID/fd
open file descriptors
cat /proc/PID/maps
memory map
cat /proc/PID/cmdline
exact command line
ldd /bin/ls
shared libraries needed

permissions

ls -l
mode, owner and group
chmod 750 f
rwx for owner, rx for group, none for others
stat f
all metadata
umask
default permission mask
find / -perm -4000 2>/dev/null
setuid programs
getcap -r / 2>/dev/null
files with Linux capabilities

signals

SIGTERM (15)
polite stop request
SIGKILL (9)
cannot be caught
SIGINT (2)
Ctrl+C
SIGHUP (1)
hangup, often "reload config"
SIGSEGV
invalid memory access

terms

Kernel
core of the OS with full privilege
System call
request from a program to the kernel
Virtual memory
per-process address space mapped by the OS
Context switch
CPU moves to another process or thread
Deadlock
tasks waiting on each other forever
TOCTOU
time-of-check to time-of-use race
ASLR / NX
randomized addresses / non-executable data
