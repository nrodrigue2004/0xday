SECTIONS curl: requests methods status codes headers browser dev tools (F12) log hunting (combined format)

curl: requests

curl -i URL
print response headers and body
curl -I URL
headers only (sends HEAD)
curl -v URL
full request and response, including the TLS handshake
curl -s URL | jq .
quiet mode, pretty-print JSON
curl -X POST -d 'a=1&b=2' URL
form-encoded POST
curl -X POST -H 'Content-Type: application/json' -d '{"a":1}' URL
JSON POST
curl -H 'Authorization: Bearer $TOKEN' URL
send a bearer token
curl -b 'sid=abc' URL · curl -c jar.txt -b jar.txt URL
send a cookie / keep a cookie jar across calls
curl -L URL
follow redirects
curl -o out.bin URL · curl -O URL
save to a file / keep the remote file name
curl --max-time 10 --retry 2 URL
bound the wait, retry on failure
curl --resolve shop.example:443:10.0.0.5 https://shop.example
pin a hostname to an IP (test a backend directly)

methods

GET
read; safe and idempotent
POST
create or submit; not idempotent
PUT
replace the whole resource; idempotent
PATCH
change part of a resource
DELETE
remove; idempotent
OPTIONS
what is allowed (CORS preflight)
HEAD
GET without the body

status codes

200 · 201 · 204
OK · created · OK with no body
301 · 302 · 304
permanent redirect · temporary redirect · not modified
400 · 401 · 403 · 404
bad request · not authenticated · not allowed · not found
405 · 409 · 429
wrong method · conflict · rate limited
500 · 502 · 503 · 504
server error · bad upstream · unavailable · upstream timeout

headers

Host · User-Agent · Accept · Referer
who, what and from where the client says it is
Content-Type · Content-Length
type and size of the body
Authorization · Cookie
credentials and session state from the client
Set-Cookie: sid=..; Secure; HttpOnly; SameSite=Lax
server sets a cookie; the flags limit where it travels and who can read it
Location
target of a 3xx redirect
Strict-Transport-Security
force HTTPS for this host
Content-Security-Policy
limit where scripts and other content may load from
X-Content-Type-Options: nosniff · X-Frame-Options
no MIME guessing · no framing by other sites
Access-Control-Allow-Origin
CORS: which other origins may read the response
Server · X-Powered-By
version leaks, remove them

browser dev tools (F12)

Network tab
every request with status, timing, headers, payload, response; tick Preserve log
Network > Fetch/XHR
only the API calls
right-click request > Copy as cURL
replay the exact call in a terminal
Application tab
cookies and their flags, localStorage, sessionStorage
Console
JS errors, mixed content, CSP and CORS blocks, and a prompt
Elements
live DOM and CSS; see hidden form fields
Export HAR
save the whole session as JSON (strip cookies and tokens before sharing)

log hunting (combined format)

awk '{print $9}' access.log | sort | uniq -c | sort -rn
count status codes
awk '$9==404{print $1}' access.log | sort | uniq -c | sort -rn | head
IPs causing the most 404s (scanning)
grep -iE "union|%27|<script|\.\./" access.log
injection, XSS and traversal tells
awk '$9==200 && $10>20000' access.log
unusually large successful responses
