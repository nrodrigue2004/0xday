c-x86-assembly - C / x86 Assembly commands and terms

SECTIONS registers data movement arithmetic and logic compare and jump calls tools gdb commands

registers

rax
return value and accumulator
rdi rsi rdx rcx r8 r9
first six integer arguments (Linux System V)
rsp
stack pointer, top of the stack
rbp
frame pointer, base of the current frame
rip
instruction pointer
eax / ax / al
32, 16 and 8-bit parts of rax

data movement

mov rax, rbx
copy rbx into rax
mov eax, [rbp-4]
load 4 bytes from memory
lea rax, [rbx+rcx*4]
compute an address, no memory read
push rax
decrement rsp and store
pop rax
load and increment rsp

arithmetic and logic

add rax, 5
add
sub rsp, 16
subtract, used to reserve stack space
imul rax, rbx
signed multiply
xor eax, eax
set to zero
and / or / xor / not
bitwise operations
shl rax, 2
shift left, multiply by 4

compare and jump

cmp a, b
compute a - b, set flags only
test a, a
AND, set flags only, checks for zero
jmp label
unconditional jump
je / jz
jump if equal / zero
jne / jnz
jump if not equal / not zero
jg / jl
signed greater / less
ja / jb
unsigned above / below

calls

call func
push return address and jump
ret
pop return address into rip
leave
mov rsp, rbp then pop rbp
syscall
enter the kernel, number in rax

tools

gcc -S -masm=intel x.c
compile to Intel-syntax assembly
objdump -d -M intel prog
disassemble a binary
gdb ./prog
debugger
nasm -f elf64 x.asm && ld -o x x.o
assemble and link
readelf -h prog
ELF header details

run
start the program

step one instruction / step over calls
info registers
show registers

examine 8 words on the stack
