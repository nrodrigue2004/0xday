windows-ir - Windows security triage: event IDs, logon types, persistence spots, Sysinternals

SECTIONS logon & account events (Security log) logon types (field in 4624) process, service & task events persistence: where malware hides at boot useful paths Sysinternals & built-in triage

logon & account events (Security log)

4624
successful logon; read the Logon Type field
4625
failed logon; many in a row from one source is guessing, check Status/SubStatus (0xC000006A bad password, 0xC0000064 no such user)
4634 / 4647
logoff / user-initiated logoff
4648
logon with explicit credentials (runas, pass-the-hash tooling shows up here)
4672
special privileges assigned to a new logon: an admin-level session started
4720 / 4722 / 4726
user account created / enabled / deleted
4723 / 4724
password change attempt / password reset by someone else
4728 / 4732 / 4756
member added to a global / local / universal security group; watch Domain Admins and Administrators
4740
account locked out
1102 (Security) / 104 (System)
the audit log was cleared; always investigate
4768 / 4769 / 4771
Kerberos TGT requested / service ticket requested / pre-auth failed (4769 with RC4 can mean Kerberoasting)

logon types (field in 4624)

2 interactive
someone at the keyboard
3 network
file share, mapped drive, most remote admin; pass-the-hash shows as type 3 NTLM
4 batch / 5 service
scheduled task / service start
7 unlock
workstation unlocked
8 network cleartext
password sent in cleartext, rare and bad
9 new credentials
runas /netonly
10 remote interactive
RDP; an RDP logon at 3 a.m. to a server deserves a question
11 cached interactive
logon with cached domain credentials, no domain controller reached

process, service & task events

4688
a process was created (turn on command-line logging to make this useful)
4697 / 7045
a service was installed (Security / System log); common for malware and PsExec
4698 / 4702
scheduled task created / updated
4104 (PowerShell)
script block logging: the real code that ran, even if it was obfuscated
Sysmon 1 / 3 / 11
process create / network connection / file create
Sysmon 7 / 8 / 10
image load / CreateRemoteThread / process access (LSASS access is a credential theft sign)
Sysmon 13
registry value set

persistence: where malware hides at boot

HKLM\Software\Microsoft\Windows\CurrentVersion\Run
machine-wide autostart
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
per-user autostart; needs no admin rights
C:\Users\<user>\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
startup folder
schtasks /query /fo list /v
scheduled tasks
sc query / Get-Service
services; check the binary path and the account
HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon
Shell and Userinit values: should be explorer.exe and userinit.exe
WMI event subscriptions
fileless persistence: Get-WmiObject -Namespace root\subscription -Class __EventFilter
Image File Execution Options (IFEO)
a Debugger value redirects a program to another; classic sticky-keys backdoor

useful paths

C:\Windows\System32\winevt\Logs\
the .evtx log files
C:\Windows\Prefetch\
evidence that a program ran (name, run count, last run times)
C:\Windows\System32\drivers\etc\hosts
local name overrides; check for tampering
C:\Windows\System32\config\
SAM, SYSTEM, SECURITY, SOFTWARE hives (locked while Windows runs)
%APPDATA%, %LOCALAPPDATA%, %TEMP%
where user-level malware likes to live
C:\ProgramData\
writable by all, common malware drop spot

Sysinternals & built-in triage

autoruns
every autostart location in one tool; hide Microsoft entries and check signatures
procexp / Process Explorer
process tree, signer, VirusTotal check, loaded DLLs
procmon / Process Monitor
live file, registry and process activity, filterable
tcpview or netstat -ano
which process owns which connection
sigcheck -u -e C:\Windows\System32
list unsigned executables
strings.exe sample.exe
readable strings in a binary
Get-WinEvent -FilterHashtable @{LogName='Security';Id=4625} -MaxEvents 20
newest 20 failed logons in PowerShell
wevtutil qe Security /q:"*[System[EventID=4688]]" /c:10 /f:text
same idea from cmd
