mobile - Android and iOS testing commands and OWASP MASVS areas

SECTIONS adb analysis manifest flags ios and mobile storage testing tools OWASP MASVS areas

adb

adb devices
list connected devices and emulators
adb shell
open a shell on the device
adb install app.apk
install an APK
adb pull /sdcard/f .
copy a file off the device
adb logcat
stream the device log (look for leaked data)

analysis

apktool d app.apk
decode manifest and resources
jadx -d out app.apk
decompile to Java source
unzip app.apk -d out
unpack the APK as a zip
frida -U -f com.example.app
start an app with Frida attached

manifest flags

exported="true"
other apps may call this component
debuggable="true"
a debugger can attach
allowBackup="true"
app data may be extracted by backup
usesCleartextTraffic
permits plain HTTP

ios and mobile storage

Keychain
OS-managed secret store for tokens, passwords and keys
Secure Enclave
hardware that holds private keys and signs without exposing them
Data Protection
file encryption tied to the passcode and lock state
ATS
App Transport Security, enforces HTTPS and modern TLS by default
UserDefaults
plain preferences, never put secrets here

testing tools

frida / objection
runtime hooking and mobile test toolkit
mitmproxy / Burp
intercept test-device traffic
MobSF
automated static and dynamic mobile analysis

STORAGE | CRYPTO | AUTH | NETWORK | PLATFORM | CODE | RESILIENCE
