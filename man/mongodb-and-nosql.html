mongodb-and-nosql - MongoDB & NoSQL commands and terms

SECTIONS mongosh operators aggregation stages admin terms

mongosh

show dbs / use shop
list databases / switch to one
show collections
list collections
db.users.find({})
all documents
db.users.find({age:{$gt:18}})
filter with an operator
db.users.find({}, {name:1,_id:0})
projection: only the name field
db.users.insertOne({...})
add a document
db.users.updateOne({q},{$set:{..}})
change fields
db.users.deleteMany({q})
remove matching documents
db.users.createIndex({email:1},{unique:true})
unique index on email
db.users.find(q).explain()
see whether an index was used

operators

$eq $ne $gt $gte $lt $lte
comparison
$in $nin
value in / not in a list
$and $or $nor $not
logic
$exists $type
field presence and type
$regex
pattern match (watch out: slow and injectable)
$set $unset $inc $push $pull
update operators

aggregation stages

$match
filter documents
$group
group and compute sums, counts, averages
$sort $limit $skip
order and page
$project
choose or compute fields
$lookup
left join with another collection
$unwind
one document per array element

mongorestore backup/
restore from a dump

Document

Collection
group of documents
BSON
binary JSON with extra types
ObjectId
default 12-byte unique _id
Replica set
primary plus secondaries for failover
Shard
one partition of a very large collection
