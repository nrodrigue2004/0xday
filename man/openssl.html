OPENSSL(7)0xDay Field ManualOPENSSL(7)

openssl - openssl commands for keys, certificates, hashes and TLS checks

SECTIONS openssl symmetric modes openssl keys sign and verify terms openssl x509 and s_client attack patterns grep targets in code review

openssl symmetric

openssl enc -aes-256-cbc -pbkdf2 -salt -in f -out f.enc
encrypt a file with a password-derived key
openssl enc -d -aes-256-cbc -pbkdf2 -in f.enc -out f
decrypt it
openssl rand -hex 16
16 random bytes as hex (for a key or nonce)
openssl dgst -sha256 f
SHA-256 of a file
openssl dgst -sha256 -hmac KEY f
HMAC of a file

modes

ECB
blocks encrypted independently, leaks patterns, do not use
CBC
chained with an IV, needs padding, no integrity
CTR
counter stream, nonce must never repeat
GCM
CTR plus authentication tag (AEAD), the default choice
AEAD
encryption that also detects tampering

openssl keys

openssl genpkey -algorithm ed25519 -out key.pem
generate an Ed25519 private key
openssl genrsa -out rsa.pem 3072
generate a 3072-bit RSA key
openssl ecparam -name prime256v1 -genkey -noout -out ec.pem
generate a P-256 key
openssl pkey -in key.pem -pubout -out pub.pem
extract the public key
openssl pkey -in key.pem -text -noout
print key details and size

sign and verify

openssl dgst -sha256 -sign key.pem -out f.sig f
sign a file
openssl dgst -sha256 -verify pub.pem -signature f.sig f
verify a signature (prints Verified OK)

terms

RSA-OAEP / RSA-PSS
recommended padding for encrypting / signing with RSA
ECDHE
ephemeral elliptic-curve Diffie-Hellman, gives forward secrecy
Ed25519 / X25519
modern curve for signatures / key exchange
KEM
key encapsulation mechanism, used by post-quantum key exchange

openssl x509 and s_client

openssl s_client -connect host:443 -servername host
open a TLS connection and print the chain
openssl s_client -connect host:443 -tls1_3
force TLS 1.3 to test support
openssl x509 -in c.pem -noout -text
print a certificate in full
openssl x509 -in c.pem -noout -subject -issuer -dates
subject, issuer, validity
openssl x509 -in c.pem -noout -ext subjectAltName
list the names the cert covers
openssl verify -CAfile ca.pem c.pem
check a cert against a CA file
openssl req -new -newkey rsa:3072 -nodes -keyout k.pem -out c.csr
key and certificate signing request

attack patterns

nonce reuse
same key and nonce twice, XOR of ciphertexts = XOR of plaintexts
padding oracle
error difference reveals CBC padding validity
Bleichenbacher
RSA PKCS#1 v1.5 error oracle
length extension
forge hash(secret||msg) extensions, use HMAC
downgrade
force an older protocol or weak suite
CRIME / BREACH
compression leaks secrets mixed with attacker data

grep targets in code review

ECB
AES.new(key, AES.MODE_ECB) or Cipher "AES/ECB"
weak hash
md5( / sha1( used for passwords or signatures
weak random
Math.random() / rand() / random.random() for tokens
trust-all TLS
verify=False, TrustAllCerts, rejectUnauthorized: false
