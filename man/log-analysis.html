log-analysis - Log analysis commands and terms

SECTIONS searching counting and sorting time and fields windows common event ids http status codes

searching

grep "Failed password" auth.log
failed SSH logins
grep -c "Failed password" auth.log
how many
grep -E "Accepted|Failed" auth.log
successes and failures
grep -v "^#" file
ignore comment lines
zgrep "word" file.log.gz
search rotated compressed logs
journalctl -u ssh --since "2 hours ago"
systemd journal for one service

counting and sorting

awk '{print $1}' access.log | sort | uniq -c | sort -rn | head
top ten client IPs
awk '$9==404' access.log
requests with status 404
awk '{print $9}' access.log | sort | uniq -c
status code counts
cut -d' ' -f1 access.log | sort -u | wc -l
number of distinct IPs
grep "Failed" auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -rn
failed attempts per IP

time and fields

awk '{print $1,$2,$3}' syslog
timestamps only
sed -n '100,120p' file
print lines 100 to 120
date -d '@1700000000'
convert epoch to date
jq '.[] | select(.level=="error")' log.json
filter JSON logs
