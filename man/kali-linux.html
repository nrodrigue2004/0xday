system

update the whole system
apt install kali-linux-default
the standard toolset
apt install kali-tools-top10
just the top ten tools
apt search tool
find a tool package
cat /etc/os-release
which Kali release you are on

information gathering

nmap -sV -sC target
services and default scripts
whois domain
registration data
dnsrecon -d domain
DNS enumeration
theHarvester -d domain -b all

web

gobuster dir -u URL -w list
hidden directories
ffuf -u URL/FUZZ -w list
fast web fuzzer
nikto -h URL
known web server issues
sqlmap -u "URL?id=1" --batch
test a parameter for SQL injection

passwords

john --wordlist=rockyou.txt hashes.txt

john --show hashes.txt

hashcat -m 0 hashes.txt rockyou.txt

hydra -l user -P list ssh://host
online brute force of a login
