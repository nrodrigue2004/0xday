aws - AWS CLI commands for identity, storage, compute and logs

identity and account

aws configure
store access key, secret and default region in a profile (prefer SSO or roles)
aws sts get-caller-identity
who am I, which account
aws iam list-users
list IAM users
aws iam list-access-keys --user-name NAME
key ids, status and creation date for a user
aws iam list-mfa-devices --user-name NAME
MFA devices for a user
aws iam generate-credential-report
build the account-wide key and MFA report
aws iam get-credential-report
download that report (CSV, base64)

storage and compute

aws s3 ls
list buckets
aws s3 ls s3://BUCKET --recursive
list objects
aws s3api get-public-access-block --bucket BUCKET
is Block Public Access on
aws s3api get-bucket-policy --bucket BUCKET
read the bucket policy
aws ec2 describe-instances
instances, IPs, groups and state
aws ec2 describe-security-groups
firewall rules
aws ec2 terminate-instances --instance-ids ID
delete an instance (stop only pauses compute billing)
aws lambda list-functions
serverless functions

logs and cost

aws cloudtrail lookup-events --lookup-attributes AttributeKey=EventName,AttributeValue=ConsoleLogin
recent console logins
aws logs tail GROUP --follow
stream a CloudWatch log group
aws guardduty list-findings --detector-id ID
threat findings
aws budgets describe-budgets --account-id ID
spend alarms
aws ce get-cost-and-usage
cost by service and time
