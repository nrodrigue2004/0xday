PHISHING-ANALYSIS(7)0xDay Field ManualPHISHING-ANALYSIS(7)

phishing-analysis - Phishing analysis commands and terms

SECTIONS headers authentication investigation commands online tools lookalike tricks terms

headers

From
what the user sees, easy to forge
Return-Path
where bounces go, often reveals the real sender
Reply-To
where replies go, a mismatch is a warning sign
Received
each mail hop, read from the bottom up
Message-ID
unique ID, useful for searching and pulling mail
Authentication-Results
SPF, DKIM and DMARC verdicts
X-Originating-IP
sender IP when present

authentication

SPF pass
IP is authorized for the envelope domain
DKIM pass
signature verified, content intact
DMARC pass
SPF or DKIM passed and aligned with From
p=none / quarantine / reject
what to do with failures

investigation commands

whois domain
registrar and creation date
dig domain any
DNS records
dig +short TXT domain
SPF and DMARC policies (_dmarc.domain)
curl -sIL URL
follow redirects, see headers only
sha256sum attachment
hash for lookup
file attachment
real type of the file

online tools

VirusTotal
reputation of files, URLs and domains
urlscan.io
safe screenshot and requests of a page
crt.sh
certificates issued for a domain
MXToolbox
header analyzer and email checks
CyberChef
decode base64, URL encoding and more

lookalike tricks

rn vs m
paypa1.com, rnicrosoft.com
Homoglyphs
Cyrillic letters that look Latin
Subdomain trick
paypal.com.evil.example, the real domain is the last part
Extra words
login-microsoft-support.example

terms

BEC
business email compromise, fraud without malware
Spear phishing
targeted at a specific person
Pretexting
invented story to build trust
Quishing
phishing through QR codes
Credential harvesting
fake login page collecting passwords
