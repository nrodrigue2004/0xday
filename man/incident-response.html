SECTIONS linux live triage windows live triage evidence phases terms

linux live triage

date; uptime; who
time, uptime and logged-in users
ps auxf
process tree
ss -tulpn
listening ports and their processes
ss -tn state established
current outbound connections
lsof -i
open network files per process
last -a
login history
cat /etc/passwd
accounts, look for new UID 0 entries
crontab -l; ls /etc/cron.*
scheduled persistence
find / -mtime -2 -type f 2>/dev/null
files changed in the last two days
ls -la /tmp /var/tmp /dev/shm
common drop locations
cat ~/.ssh/authorized_keys
unexpected keys

windows live triage

tasklist /v
running processes with owners
netstat -ano
connections with PIDs
schtasks /query /fo LIST /v
scheduled tasks
net user / net localgroup administrators
accounts and admins
reg query HKLM\Software\Microsoft\Windows\CurrentVersion\Run
autostart entries
Get-WinEvent -FilterHashtable @{LogName='Security';Id=4624,4625}
logons
wmic process list brief
process list with paths

evidence

sha256sum file
hash before and after copying
dd if=/dev/sdb of=disk.img bs=4M
raw disk image (use a write blocker)
dc3dd if=/dev/sdb of=disk.img hash=sha256
imaging with built-in hashing
tar -czf evidence.tgz folder
package collected files
