virtualization-proxmox - Virtualization / Proxmox commands and terms

vm commands (qm)

qm list
all VMs and their status
qm config 100
show the settings of VM 100
qm start 100
power on
qm shutdown 100
clean shutdown through the guest agent
qm stop 100
hard power off
qm snapshot 100 pre-update
take a snapshot
qm rollback 100 pre-update
go back to it
qm clone 9000 120 --name web1
clone a template into a new VM
qm template 9000
turn a VM into a template
qm set 100 --memory 4096
change a setting
qm unlock 100
clear a stale lock after a failed backup

container commands (pct)

pct list
all containers
pct enter 200
get a shell inside container 200
pct config 200
container settings
pct start 200
start it

host and storage

pvesm status
storage pools and free space
pvecm status
cluster and quorum state
pveversion -v
installed versions
vzdump 100 --storage backup --mode snapshot
backup a guest now
qmrestore backup.vma.zst 130
restore a backup to a new ID
journalctl -u pveproxy
web UI logs
ip a
bridges and addresses
cat /etc/network/interfaces
bridge and VLAN config

terms

vmbr0
the default Linux bridge, acts as a virtual switch
local-lvm
thin-provisioned storage for guest disks
local
directory storage for ISOs, templates and backups
VirtIO
paravirtualized disk and network drivers, fastest option
QEMU guest agent
in-guest helper for IP reporting and clean shutdowns
Snapshot
point-in-time state kept on the same storage, not a backup
Quorum
majority of cluster nodes needed to make changes
