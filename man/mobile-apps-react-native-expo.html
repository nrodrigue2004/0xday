mobile-apps-react-native-expo - Mobile apps (React Native / Expo) commands and terms

expo and node

npx create-expo-app app
start a new project
npx expo start
run the dev server, show the QR code
npx expo install pkg
add a package at a compatible version
npx expo-doctor
check for version problems
npx tsc --noEmit
type-check without building
eas build -p android
cloud build for Android

core components

View
container box
Text
all text must be inside Text
Image
picture (source and size)
TextInput
text field (value, onChangeText)
Pressable
tappable area (onPress)
FlatList
efficient scrolling list
ScrollView
scroll everything it contains
StyleSheet.create
define styles

hooks

useState
remember a value; setter re-renders
useEffect(fn, deps)
run after render; deps decides when
useMemo / useCallback
cache a value / a function between renders
useContext
read shared data without passing props
useRef
mutable value that does not re-render

terms

Props
read-only inputs from a parent
State
data a component remembers
Re-render
React calls the component again
Expo Go
phone app that runs your project in development
Bundle
the JavaScript shipped inside the app
Deep link
URL that opens a specific screen
