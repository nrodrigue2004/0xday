group-policy - Group Policy commands and terms

SECTIONS client commands management console powershell processing order (LSDOU) terms

client commands

gpupdate /force
refresh all policy now
gpupdate /target:computer
refresh only the computer side
gpresult /r
summary of applied GPOs
gpresult /h report.html
detailed HTML report
rsop.msc
resultant set of policy viewer
whoami /groups
groups that affect security filtering

management console

gpmc.msc
open Group Policy Management
gpedit.msc
local policy editor on one machine
Default Domain Policy
domain-wide password and Kerberos settings
Default Domain Controllers Policy
settings for DCs

powershell

Get-GPO -All
list every GPO
Get-GPOReport -Name "SEC - Baseline" -ReportType Html -Path r.html
export a report
Backup-GPO -Name "SEC - Baseline" -Path C:\gpo-backup
back up a GPO
New-GPLink -Name "SEC - Baseline" -Target "OU=Workstations,DC=corp,DC=local"
link a GPO to an OU
Get-GPInheritance -Target "OU=Workstations,DC=corp,DC=local"
what applies to an OU

processing order (LSDOU)

Local
machine's own policy, applied first
Site
AD site
Domain
domain-wide
OU
nested OUs, closest to the object wins

terms

Link
connects a GPO to a container
Enforced
cannot be overridden below
Block inheritance
stop parent GPOs applying here
Security filtering
limit a GPO to chosen users, groups or computers
WMI filter
apply only when a WMI query is true
SYSVOL
share on DCs where GPO files live
Loopback
apply user settings by computer location
