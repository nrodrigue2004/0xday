bash-scripting - Bash scripting commands and terms

SECTIONS script basics variables special variables tests control flow redirection useful patterns

script basics

#!/usr/bin/env bash
shebang line, picks the interpreter
set -euo pipefail
stop on errors, unset variables and failed pipes
chmod +x s.sh
make executable
bash -x s.sh
run with command tracing
shellcheck s.sh
static checker for common bugs

variables

x=5
assign, no spaces around =
"$x" or "${x}"
expand, always in quotes
${x:-default}
use default if empty or unset
${x%.log}
remove a suffix
${x#prefix}
remove a prefix
${#x}
length of the value
$(cmd)
capture a command's output

special variables

$0
script name
$1 $2 ...
positional arguments
$@
all arguments, each quoted
$#
number of arguments
$?
exit code of the last command
$$
current process ID

tests

[[ -f f ]]
f is a regular file
[[ -d d ]]
d is a directory
[[ -z "$x" ]]
string is empty
[[ "$a" == "$b" ]]
strings equal
[[ $n -gt 5 ]]
number comparison
[[ $x =~ ^[0-9]+$ ]]
regex match

control flow

if cond; then ... fi
conditional
for i in a b c; do ... done
loop over a list
while read -r l; do ... done < f
loop over lines of a file
case "$x" in a) ...;; esac
multi-way branch
cmd1 && cmd2
run cmd2 only if cmd1 succeeded
cmd1 || cmd2
run cmd2 only if cmd1 failed

redirection

cmd > f
overwrite file
cmd >> f
append
cmd 2>&1
send stderr to stdout
cmd 2>/dev/null
discard errors
cmd1 | cmd2
pipe output into the next command
cmd <<< "text"
feed a string as input

useful patterns

trap 'rm -f "$tmp"' EXIT
cleanup on exit
tmp=$(mktemp)
safe temp file
find . -name '*.log' -print0 | xargs -0 gzip
handle odd filenames safely
command -v jq >/dev/null || exit 1
require a tool
