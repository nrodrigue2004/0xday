VOLATILITY3(1)0xDay Field ManualVOLATILITY3(1)

volatility3 - memory forensics framework (Volatility 3 syntax)

orientation

vol -f mem.raw windows.info
OS version, build and kernel details of the image
vol -f mem.raw banners.Banners
identify a Linux kernel image
vol -f mem.raw -r csv windows.pslist > ps.csv
any plugin to CSV for spreadsheets or grep

processes

vol -f mem.raw windows.pslist
processes from the active process list
vol -f mem.raw windows.pstree
parent/child tree, spot odd parents (e.g. Word spawning cmd)
vol -f mem.raw windows.psscan
scan for process structures, finds hidden or exited ones
vol -f mem.raw windows.cmdline
command line each process was started with
vol -f mem.raw windows.dlllist --pid 1234
DLLs loaded by a process

network & persistence

vol -f mem.raw windows.netscan
sockets and connections, with owning process
vol -f mem.raw windows.registry.hivelist
loaded registry hives
vol -f mem.raw windows.registry.printkey --key "Software\Microsoft\Windows\CurrentVersion\Run"
classic Run-key persistence
vol -f mem.raw windows.svcscan
services

malware hunting

vol -f mem.raw windows.malfind
memory regions that look injected (RWX, PE headers)
vol -f mem.raw windows.handles --pid 1234
open handles: files, mutexes, registry keys
vol -f mem.raw -o out/ windows.dumpfiles --pid 1234
extract files mapped by a process
vol -f mem.raw windows.hashdump
local account NTLM hashes
