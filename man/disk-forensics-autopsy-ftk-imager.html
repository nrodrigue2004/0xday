disk-forensics-autopsy-ftk-imager - Disk forensics (Autopsy / FTK Imager) commands and terms

acquisition

sha256sum disk.dd
hash an image; compare with the acquisition record
dd if=/dev/sdb of=disk.dd bs=4M conv=noerror,sync
raw copy from a read-only attached drive (Linux)
ewfinfo disk.E01
show case metadata of an E01 image
ewfverify disk.E01
verify an E01 image against its stored hash

sleuth kit

mmls disk.dd
partition table with sector offsets
fls -r -o 2048 disk.dd
recursive file list; deleted entries marked with *
icat -o 2048 disk.dd 4417
extract the file with inode 4417
istat -o 2048 disk.dd 4417
metadata and timestamps for one inode
tsk_recover -o 2048 disk.dd out/
recover deleted files into out/
fsstat -o 2048 disk.dd
filesystem type, cluster size, serial

autopsy views

Deleted Files
file-table entries flagged deleted
Data Artifacts
browser, USB, recent docs, programs, downloads
Timeline
every timestamp on one axis
Hash Lookup
compare against known-good and known-bad sets
Extension Mismatch
name says .jpg, signature says .zip

terms

E01
EnCase image format with compression, hashes and case metadata
MFT
NTFS master file table, one record per file
MACB
modified, accessed, changed, born timestamps
Unallocated space
not owned by any file; may hold deleted data
File carving
rebuilding files from signatures, ignoring the file table
Chain of custody
log of who handled the evidence
