ghidra-and-ida-pro - Ghidra and IDA Pro keys, views and a first-hour workflow

navigation (IDA / Ghidra)

G
go to an address or symbol
X (IDA) / Ctrl+Shift+F (Ghidra)
cross-references to the selected item
Shift+F12 (IDA) / Window > Defined Strings (Ghidra)
open the strings list
Esc (IDA) / Alt+Left (Ghidra)
go back
Space (IDA)
switch between graph and text view
F5 (IDA) / Window > Decompile (Ghidra)
show the decompiler

editing

N (IDA) / L (Ghidra)
rename the selected variable or function
Y
change a type or signature
; (IDA) / ; (Ghidra)
add a comment
D / C
convert bytes to data / to code (IDA)
Ctrl+Z
undo

analysis targets

Imports
which APIs the program calls
Strings
URLs, paths, error messages, commands
Exports
functions a DLL offers
Entry point
where execution starts
Xrefs to string
which function prints, sends or compares it
Xrefs to API
where the dangerous call is made

terms

Static analysis
studying a binary without running it
Dynamic analysis
studying it while it runs
Disassembler
machine code to assembly
Decompiler
assembly to C-like pseudocode
Cross-reference (xref)
place where an item is used
FUN_xxxxxxxx
Ghidra's default name for an unnamed function
Hex-Rays
IDA's decompiler plugin
