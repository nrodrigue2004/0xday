vpn-tailscale - VPN / Tailscale commands and terms

tailscale cli

tailscale up
connect and log in
tailscale down
disconnect
tailscale status
peers, addresses and connection state
tailscale ip -4
your tailnet IPv4 address
tailscale ping host
test connectivity, shows direct or relayed
tailscale ssh host
SSH using Tailscale identity
tailscale file cp f host:
send a file to another device
tailscale netcheck
diagnose NAT and relay reachability

up flags

--advertise-routes=10.0.0.0/24
share a local subnet with the tailnet
--advertise-exit-node
offer to carry others' internet traffic
--exit-node=host
send your traffic out through that node
--accept-routes
use subnet routes advertised by others
--ssh
enable Tailscale SSH on this device
--shields-up
refuse all incoming connections

wireguard basics

wg genkey | wg pubkey
generate a private key and its public key
wg show
interfaces, peers, last handshake and transfer
wg-quick up wg0
bring up a tunnel from /etc/wireguard/wg0.conf
AllowedIPs
which destinations go through this peer
Endpoint
public address and port of the peer
PersistentKeepalive = 25
keep NAT mappings alive

terms

Tailnet
your private Tailscale network
MagicDNS
automatic names for devices
DERP
Tailscale relay used when a direct path fails
ACL
policy that decides who can reach what
Subnet router
node that bridges a whole LAN into the tailnet
Exit node
node that carries your internet traffic
Split tunnel
only some traffic goes through the VPN
