PASSWORD-CRACKING-JOHN(7)0xDay Field ManualPASSWORD-CRACKING-JOHN(7)

password-cracking-john - Password cracking / John commands and terms

SECTIONS john hashcat extractors hash prefixes in /etc/shadow terms

john

john hashes.txt
try default modes
john --wordlist=rockyou.txt hashes.txt
wordlist attack
john --wordlist=rockyou.txt --rules hashes.txt
wordlist plus mangling rules
john --incremental hashes.txt
brute force
john --format=raw-md5 hashes.txt
force a format
john --list=formats
supported formats
john --show hashes.txt
print cracked passwords
john --restore
resume an interrupted session

hashcat

hashcat -m 0 -a 0 hashes.txt rockyou.txt
MD5 with a wordlist
hashcat -m 1000 -a 0 ntlm.txt rockyou.txt
NTLM
hashcat -m 1800 -a 0 sha512crypt.txt rockyou.txt
Linux sha512crypt
hashcat -m 0 -a 3 hash.txt ?u?l?l?l?l?d?d
mask attack
hashcat -a 0 -r best64.rule hash.txt list.txt
wordlist with a rule file
hashcat --show hash.txt
display cracked results

extractors

unshadow passwd shadow
merge into a crackable file
zip2john file.zip
hash from a zip
ssh2john id_rsa
hash from an SSH private key
office2john file.docx
hash from an Office file
hashid 'hash'
guess the hash type

hash prefixes in /etc/shadow

$1$
MD5-crypt, obsolete
$5$
SHA-256 crypt
$6$
SHA-512 crypt, common on Linux
$y$
yescrypt, newer default
$2b$
bcrypt

terms

Salt
random value added before hashing
KDF
slow password-hashing function such as bcrypt or Argon2
Rainbow table
precomputed hashes, defeated by salts
Spraying
one password against many accounts
Credential stuffing
reuse of leaked passwords on other sites
