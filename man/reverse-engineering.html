first look

file prog
type, architecture, stripped or not
strings -n 6 prog
readable strings
strings -el prog
UTF-16 strings
ltrace ./prog
library calls
strace ./prog
system calls
readelf -s prog
symbols
objdump -d -M intel prog
disassembly

gdb

gdb ./prog
start the debugger
break main
breakpoint at main
run
start the program
n / s
next line / step into
si / ni
instruction step / over
x/s $rdi
print a string at a register's address
x/16xb $rsp
16 bytes at the stack top
set $rax = 1
change a register

ghidra shortcuts

G
go to an address
X
cross-references to the selected item
L
rename a variable or function
Ctrl+L
retype a variable
;
add a comment

radare2

r2 -A prog
open and analyze
afl
list functions
pdf @ main
print disassembly of main
iz
strings in the data section
s sym.main
seek to main

pattern recognition

xor in a loop
simple decoding or encryption
cmp then jne fail
a check you may want to change
strcmp with a literal
password stored in the binary
Stack of pushes before a call
arguments in 32-bit code
256-entry table

nop sled
overwrite code with no-ops to skip it
je to jne
flip a branch
frida -f prog -l hook.js

angr
symbolic execution to find inputs that reach a goal
