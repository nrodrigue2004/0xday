cryptography-applied - Cryptography (applied) commands and terms

SECTIONS hashing and encoding symmetric encryption keys and signatures certificates algorithm guide terms

hashing and encoding

echo -n "text" | sha256sum
SHA-256 of a string (-n avoids the newline)
sha256sum file
checksum a file
sha256sum -c SHA256SUMS
verify against a checksum list
echo -n "hi" | base64
encode
echo "aGk=" | base64 -d
decode
echo -n "hi" | xxd -p
hex encode
openssl dgst -sha256 file
hash with OpenSSL

symmetric encryption

openssl enc -aes-256-cbc -pbkdf2 -in a.txt -out a.enc
encrypt with a password
openssl enc -d -aes-256-cbc -pbkdf2 -in a.enc -out a.txt
decrypt it
gpg -c file
symmetric encrypt with GPG
gpg file.gpg
decrypt

keys and signatures

openssl genpkey -algorithm ed25519 -out key.pem
create a private key
ssh-keygen -t ed25519
create an SSH key pair
openssl rand -hex 32
32 random bytes as hex
gpg --verify file.sig file
verify a signature
gpg --gen-key
create a PGP key pair

certificates

openssl x509 -in cert.pem -noout -text
read a certificate
openssl s_client -connect host:443 -servername host
inspect a live TLS handshake
openssl req -new -x509 -days 365 -nodes -out c.pem -keyout k.pem
self-signed cert for a lab
openssl verify -CAfile ca.pem cert.pem
validate a chain

algorithm guide

AES-GCM / ChaCha20-Poly1305
symmetric, authenticated encryption
RSA 2048+ / ECDSA / Ed25519
signatures and key exchange
SHA-256 / SHA-3
hashing
Argon2id / bcrypt / scrypt
password storage
HMAC-SHA256
message authentication
MD5 / SHA-1 / DES / RC4
broken, do not use

terms

Nonce / IV
value that must not repeat with the same key
Forward secrecy
past traffic stays safe if a long-term key leaks
PKI
system of CAs and certificates that binds names to keys
Salt
random value mixed into a password hash
Entropy
unpredictability, the raw material of keys
