cloud - AWS and Azure side by side: the terms that map to each other

SECTIONS shared vocabulary identity terms: AWS vs Azure networking terms storage and compute terms detection and response terms lab hygiene

shared vocabulary

IaaS / PaaS / SaaS
how much of the stack the provider runs, least to most
shared responsibility
provider secures the cloud, customer secures what is in it (data, identity, config)
region
geographic area with several data centers
availability zone (AZ)
independent data center(s) inside a region, for high availability
egress
data leaving the cloud, usually billed; ingress is usually free
elasticity
scale out and back in automatically with demand
control plane vs data plane
management APIs vs the traffic to the running service
IaC
infrastructure as code: CloudFormation, Bicep/ARM, Terraform
CSPM / CASB / CWPP
posture scanning / cloud app policy gateway / workload protection

identity terms: AWS vs Azure

IAM user / group / role
AWS identities. Roles are assumed and give temporary credentials
Entra ID (Azure AD)
Azure's directory of users, groups, apps and service principals
managed identity
Azure identity for a resource, no secret to store (AWS analog: instance profile / role)
policy (JSON)
AWS permission document: Effect, Action, Resource, Condition
role assignment
Azure: principal + role + scope
Owner / Contributor / Reader
Azure built-in roles: all + grant access / all except grant / view only
SCP
AWS service control policy: organization-wide permission ceiling
PIM
Azure Privileged Identity Management: just-in-time admin
Conditional Access
Entra rules: require MFA or healthy device depending on context
ARN
AWS Amazon Resource Name, the unique ID of a resource

networking terms

VPC / VNet
your private virtual network and address range
subnet
slice of the network; public if its route table has an internet gateway
security group
AWS stateful allow-only instance firewall
NSG
Azure network security group: allow/deny rules by priority
NACL
AWS stateless subnet-level rules
NAT gateway
lets private resources reach out without being reachable in
bastion
hardened jump host (or managed Bastion / Session Manager) for admin access
0.0.0.0/0
"the entire internet" as a rule source; avoid for SSH, RDP and databases
VPC endpoint / Private Endpoint
reach a cloud service privately without the public endpoint
flow logs
per-connection metadata for the virtual network

storage and compute terms

bucket / container
object storage namespace (S3 bucket, Azure Blob container)
object / blob
one stored file plus metadata
Block Public Access
S3 switch that overrides policies and ACLs that would make data public
bucket policy
resource-based JSON policy on a bucket; "Principal": "*" means everyone
SAS token / pre-signed URL
signed link giving time-limited access; treat like a password
KMS / Key Vault
managed encryption keys and secrets
EBS / Managed Disk
block storage for VMs
EC2 / Azure VM
virtual machines
Lambda / Azure Functions
serverless code on events
ECS, EKS / AKS
container services, Kubernetes
IMDSv2
AWS metadata service requiring a token, blunts SSRF credential theft

detection and response terms

CloudTrail / Activity Log
audit log of control-plane API calls
GuardDuty / Defender for Cloud
managed threat detection and posture findings
CSPM
cloud security posture management: finds misconfiguration
CIS Benchmark
consensus hardening checklist per cloud and service
StopLogging / DeleteTrail
CloudTrail events that mean someone is hiding activity
CreateAccessKey
persistence signal when done by an unexpected identity
quarantine security group
deny-all group to isolate an instance without destroying evidence
credential rotation
replace keys/secrets after exposure, even if "only briefly" public

lab hygiene

budget alert
tiny spend threshold that emails you before the bill grows
free tier
quota- or time-limited free usage; terms change, read the current page
resource group delete
Azure: remove everything in the lab in one command
terraform destroy
tear down everything a Terraform lab created
LocalStack
local emulator for AWS APIs, no account needed
Azurite
local emulator for Azure Storage
.gitignore
keep keys, .env, .pem and tfstate out of git
secret scanning
detect committed credentials; rotate any that leak
