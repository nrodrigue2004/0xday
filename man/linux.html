linux - Linux shell: files, text, permissions, processes, networking, logs and packages

SECTIONS files & navigation text & data permissions users & groups processes & services networking firewall logs disk & system packages security & forensics

files & navigation

ls -lah
long listing, hidden files, human-readable sizes
cd -
jump back to the previous directory
find / -name '*.conf' 2>/dev/null
search by name, hiding permission errors
find /var/www -type f -mmin -60
files modified in the last hour
file mystery.bin
identify a file by its contents, not its extension
stat file
size, owner, and access/modify/change timestamps
cp -a src/ dst/
copy preserving permissions, owners and timestamps
mkdir -p a/b/c · ln -s /opt/tool/bin/tool ~/bin/tool
nested folders, symbolic link
rm -rf dir
delete recursively without asking; check the path twice
tar -czvf logs.tgz logs/ · tar -xzvf logs.tgz
create and extract a gzip tarball
du -sh * | sort -h
what's eating the space here
which python3 · type ll
where a command comes from (type also shows aliases)

text & data

less /var/log/syslog
page through a file (/ to search, q to quit)
head -n 20 file · tail -n 50 file
first or last lines
tail -f /var/log/auth.log
follow a log as it grows
grep -rin 'password' /etc 2>/dev/null
recursive, case-insensitive search with line numbers
grep -v '^#' sshd_config | grep -v '^$'
strip comments and blank lines to see the real config
cut -d: -f1 /etc/passwd
pull one field from delimited text
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head
top client IPs in a web log
sed -i 's/old/new/g' file
find and replace in place
diff -u a.conf b.conf
unified diff of two files
strings -n 8 sample.bin | less
printable strings in a binary
xxd sample.bin | head
hex dump
sha256sum file · md5sum file
hash a file
echo 'aGVsbG8=' | base64 -d
decode base64

permissions

chmod 640 file
owner rw, group r, others nothing (r=4 w=2 x=1)
chmod u+x script.sh
make a script executable for its owner
chown www-data:www-data -R /var/www
change owner and group recursively
umask
default permission mask for new files
getfacl file · setfacl -m u:bob:r file
view or add fine-grained ACLs
lsattr file · chattr +i file
file attributes; +i makes it immutable even to root until removed
sudo -l
what this user may run with sudo, the first privesc check

users & groups

whoami · id
current user, UID, GID and groups
w · who
who is logged in and what they are doing
last · sudo lastb
login history, and failed login attempts
sudo useradd -m -s /bin/bash bob && sudo passwd bob
create a user with a home folder, then set a password
sudo usermod -aG sudo bob
add to a group (-a keeps existing groups; wheel on RHEL)
sudo userdel -r bob
remove a user and their home folder
getent passwd · getent group sudo
accounts and group members, including LDAP/AD ones
sudo chage -l bob
password age and expiry
su - bob
switch user with a login shell

processes & services

ps aux
every process with user, CPU and memory
ps -ef --forest
process tree: who spawned what
top · htop
live view (htop if installed)
pgrep -a ssh
find PIDs and command lines by name
kill 4242 · kill -9 4242 · pkill -f miner
terminate politely, force, or by pattern
nohup ./long.sh & · jobs · fg %1
run in the background, list jobs, bring one back
lsof -p 4242
files and sockets a process has open
ls -l /proc/4242/exe
the binary behind a PID; '(deleted)' means it removed itself from disk
systemctl status ssh
service state and its latest log lines
sudo systemctl enable --now nginx
start now and on every boot
systemctl list-units --type=service --state=running
running services
systemctl list-timers · crontab -l · ls /etc/cron.*
scheduled jobs, a common persistence spot

networking

ip a · ip r · ip neigh
addresses, routes, ARP neighbors
ss -tulpn
listening TCP/UDP ports and the process that owns each
ss -tanp state established
live TCP connections
ping -c 4 10.0.0.1 · tracepath 8.8.8.8
reachability and the path there
dig example.com +short · dig -x 8.8.8.8
DNS lookup and reverse lookup
cat /etc/resolv.conf /etc/hosts
which DNS server is used, and static overrides
curl -sI https://example.com
just the HTTP response headers
wget -q https://example.com/file.tgz
download a file
nc -zv 10.0.0.5 20-25 · nc -lvnp 4444
quick port check, or listen on a port
sudo tcpdump -i eth0 -nn port 53 -w dns.pcap
capture DNS traffic to a file for Wireshark
ssh -L 8080:127.0.0.1:80 user@host
local port forward: reach the remote's port 80 on localhost:8080
scp file user@host:/tmp/ · rsync -avz src/ host:dst/
copy files over SSH
nmcli device status
NetworkManager view of interfaces

firewall

sudo ufw status verbose
Ubuntu's firewall front end
sudo ufw default deny incoming && sudo ufw allow 22/tcp && sudo ufw enable
deny by default, allow SSH, turn it on
sudo iptables -L -n -v --line-numbers
raw iptables rules with counters
sudo nft list ruleset
nftables, the modern replacement
sudo firewall-cmd --list-all
firewalld on RHEL and Fedora

logs

journalctl -u ssh --since '1 hour ago'
one service's logs for a time window
journalctl -f · journalctl -p err -b
follow everything, or only errors since boot
/var/log/auth.log · /var/log/secure
authentication log on Debian/Ubuntu, and on RHEL
grep 'Failed password' /var/log/auth.log | awk '{print $(NF-3)}' | sort | uniq -c | sort -rn
SSH brute force: failed attempts per source IP
dmesg -T | tail
kernel messages with readable timestamps (USB, disks, drivers)

disk & system

df -h · free -h · uptime
disk space, memory, load
lsblk -f · blkid
block devices, file systems and UUIDs
sudo fdisk -l
partition tables
mount | column -t
what is mounted where, with options
sudo dd if=/dev/sdb of=sdb.img bs=4M status=progress
bit-for-bit disk image (double-check if= and of=)
uname -a · cat /etc/os-release · lscpu
kernel, distro, CPU

packages

sudo apt update && sudo apt upgrade
Debian/Ubuntu: refresh the index, then upgrade
sudo apt install nmap · sudo apt purge nmap
install, or remove with its config
apt list --installed · dpkg -l | grep ssh
what's installed
sudo dnf upgrade · sudo dnf install nmap · rpm -qa
Fedora/RHEL equivalents
sudo pacman -Syu · sudo pacman -S nmap
Arch: full upgrade, install

security & forensics

find / -perm -4000 -type f 2>/dev/null
SUID binaries, a top privesc path
getcap -r / 2>/dev/null
binaries with Linux capabilities (cap_setuid is a red flag)
cat ~/.bash_history
what a user typed (attackers often clear or unlink it)
cat ~/.ssh/authorized_keys
keys that can log in as this user; a quiet persistence method
sudo rkhunter --check · sudo chkrootkit
rootkit scanners
openssl s_client -connect example.com:443 -servername example.com
inspect a server's TLS certificate and handshake
openssl x509 -in cert.pem -text -noout
read a certificate file
ssh-keygen -t ed25519 -C lab
generate a modern SSH key pair
gpg -c secrets.txt
symmetric-encrypt a file with a passphrase
shred -u old.key
overwrite then delete (not reliable on SSDs or journaling file systems)
