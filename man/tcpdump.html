tcpdump-tshark - capture and read packets from a terminal: BPF filters, flags, tshark one-liners

SECTIONS capture BPF filters reading a line tshark one-liners text-only analysis (no Wireshark needed)

capture

tcpdump -nn -i eth0
live capture on an interface; -nn skips name and port lookups (always use it when investigating)
tcpdump -nn -i any -c 100
any interface, stop after 100 packets
tcpdump -nn -i eth0 -w cap.pcap
write raw packets to a file for Wireshark (-s 0 for full packets on old versions)
tcpdump -nn -r cap.pcap
read a saved capture
tcpdump -nn -tttt -r cap.pcap
readable date and time on every line
tcpdump -nn -A -r cap.pcap
print payload as ASCII, handy for cleartext HTTP
tcpdump -nn -X -r cap.pcap
hex and ASCII side by side

BPF filters

host 10.0.5.23
traffic to or from a host
src host 10.0.5.23 · dst host 192.0.2.99
one direction
net 10.0.5.0/24
a whole subnet
port 53 · portrange 1-1024
a port or a range
tcp · udp · icmp
a protocol
host 10.0.5.23 and not port 22
combine with and, or, not (so your own SSH session does not flood the output)
'tcp[tcpflags] & tcp-syn != 0'
only packets with SYN set
'tcp[tcpflags] & (tcp-syn|tcp-ack) == tcp-syn'
SYN without ACK: connection attempts, the scan filter
'tcp[tcpflags] & tcp-rst != 0'
resets
greater 1000 · less 100
packets bigger or smaller than N bytes

reading a line

10.0.5.23.51515 > 203.0.113.50.443:
source ip.port, the arrow, destination ip.port
Flags [S] [S.] [.] [P.] [F.] [R]
SYN, SYN-ACK, ACK, push-ACK, FIN-ACK, reset
seq 1001:2449
bytes numbered 1001 up to but not including 2449
ack 5001
the next byte the sender expects from the other side
length 1448
bytes of data in this packet (0 is just control)
A? example.com.
a DNS query for an A record

tshark one-liners

tshark -r cap.pcap -q -z conv,tcp
TCP conversations with byte totals
tshark -r cap.pcap -q -z endpoints,ip
bytes per IP address
tshark -r cap.pcap -Y 'dns' -T fields -e ip.src -e dns.qry.name
DNS names asked, by who
tshark -r cap.pcap -Y 'http.request' -T fields -e ip.src -e http.host -e http.request.uri
web requests
tshark -r cap.pcap -Y 'tls.handshake.type==1' -T fields -e ip.dst -e tls.handshake.extensions_server_name
SNI names from TLS ClientHellos
tshark -r cap.pcap -Y 'ip.src==10.0.5.23' -T fields -e ip.dst -e frame.len | sort | uniq -c | sort -rn | head
where one host sent the most
tshark -r cap.pcap --export-objects http,out/
pull files transferred over HTTP out of a capture
tshark -r cap.pcap -q -z io,phs
protocol hierarchy: what the capture is made of

text-only analysis (no Wireshark needed)

tcpdump -nn -r cap.txt | awk '{print $3}' | sort | uniq -c | sort -rn | head
who sent the most packets
... | grep 'length 1448' | awk '{print $5}' | sort | uniq -c
who received bulk data
... | grep 'Flags \[S\]' | awk '{print $5}' | sort | uniq -c
who got the most connection attempts
