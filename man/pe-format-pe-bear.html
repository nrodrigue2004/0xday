PE-FORMAT-PE-BEAR(7)0xDay Field ManualPE-FORMAT-PE-BEAR(7)

pe-format-pe-bear - PE format (PE-bear) commands and terms

headers

MZ
first two bytes of the DOS header; the file is a PE candidate
PE\0\0
signature of the PE header (e_lfanew points to it)
Machine
CPU: 0x14c is x86, 0x8664 is x64
NumberOfSections
how many sections follow
TimeDateStamp
build time (can be forged)
AddressOfEntryPoint
RVA where execution begins
ImageBase
preferred load address
Subsystem
2 GUI, 3 console, 1 driver/native

sections

.text
code
.data
writable globals
.rdata
read-only data, often imports
.rsrc
resources: icons, dialogs, embedded files
.reloc
relocations for ASLR
Entropy
0 to 8; above ~7 means compressed or encrypted
VirtualSize vs RawSize
in memory vs on disk; big gap means unpacking space
Characteristics
R/W/X flags; W+X is a red flag

imports

CreateRemoteThread + WriteProcessMemory
process injection
VirtualAlloc + VirtualProtect
allocating or changing executable memory
LoadLibrary + GetProcAddress
resolving APIs at runtime, common in packed code
URLDownloadToFile
downloads a file from a URL
RegSetValueEx
writes registry values, often for persistence
IsDebuggerPresent
anti-debug check

tools

PE-bear
GUI viewer for headers, sections, imports, hex
strings -n 8 f.exe
printable strings of 8+ chars
sha256sum f.exe
hash for lookup and reporting
upx -d f.exe
unpack a UPX-packed file
pefile (Python)
read PE fields from scripts
imphash
hash of the import table order
