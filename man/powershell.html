powershell - everyday Windows administration and incident response in PowerShell

SECTIONS discover & help files pipeline & output system processes, services & tasks networking users & access event logs registry defense & forensics packages & remoting discovery system information filtering and shaping files and text network remote and events automation: powershell

discover & help

Get-Help Get-WinEvent -Examples
worked examples for any cmdlet
Get-Command *firewall*
find cmdlets by name
Get-Process | Get-Member
see the properties and methods an object has
Get-Alias ls
what an alias really runs (ls, dir and gci are all Get-ChildItem)
$PSVersionTable
PowerShell version and edition

files

Get-ChildItem -Recurse -Force -Filter *.log
recursive listing including hidden files
Get-ChildItem C:\Users -Recurse -File | Where-Object LastWriteTime -gt (Get-Date).AddDays(-1)
files changed in the last 24 hours
Get-Content app.log -Tail 50 -Wait
the tail -f equivalent
Select-String -Path *.log -Pattern 'failed'
the grep equivalent
Copy-Item, Move-Item, Rename-Item, Remove-Item -Recurse -Force
the basic file verbs
New-Item -ItemType Directory -Path C:\lab\logs
create a folder (intermediate folders included)
Get-FileHash .\sample.exe -Algorithm SHA256
hash a file
Get-Item .\file.txt -Stream *
list alternate data streams
Compress-Archive logs logs.zip · Expand-Archive logs.zip
zip and unzip

pipeline & output

Get-Process | Sort-Object CPU -Descending | Select-Object -First 10
top 10 processes by CPU time
Get-Service | Where-Object Status -eq 'Running'
filter objects by a property
... | Format-Table -AutoSize · ... | Format-List *
table view, or every property
... | Export-Csv out.csv -NoTypeInformation
save results for Excel or a report
... | ConvertTo-Json -Depth 3
JSON output for scripts and APIs
... | Measure-Object
count the results

system

Get-ComputerInfo
OS, build, BIOS, domain and more in one object
Get-CimInstance Win32_OperatingSystem | Select-Object Caption,Version,LastBootUpTime
OS details and last boot
Get-CimInstance Win32_LogicalDisk
drives with size and free space
Get-HotFix | Sort-Object InstalledOn -Descending
installed updates, newest first
Restart-Computer -ComputerName ws01 -Force
reboot a local or remote machine

processes, services & tasks

Get-Process -Name notepad | Stop-Process -Force
find and kill a process
Get-CimInstance Win32_Process | Select-Object ProcessId,ParentProcessId,Name,CommandLine
parent PID and full command line, the two things you want when hunting
Get-Service | Where-Object StartType -eq 'Automatic'
services that start on boot
Restart-Service Spooler · Set-Service Spooler -StartupType Disabled
restart, or disable at boot
Get-CimInstance Win32_Service | Select-Object Name,StartName,PathName
service account and binary path (look for unquoted paths with spaces)
Get-ScheduledTask | Where-Object State -ne 'Disabled'
active scheduled tasks

networking

Get-NetIPConfiguration
ipconfig as objects
Get-NetTCPConnection -State Listen | Select-Object LocalPort,OwningProcess
listening ports and the PID behind each
Test-NetConnection 10.0.10.5 -Port 445
can I reach this port? (ping + TCP test)
Resolve-DnsName example.com -Type MX
DNS lookup for any record type
Get-DnsClientCache
local DNS cache, handy for spotting beacon domains
Get-NetNeighbor -AddressFamily IPv4
ARP cache
Get-NetFirewallRule -Enabled True -Direction Inbound
active inbound firewall rules
New-NetFirewallRule -DisplayName 'Block 4444' -Direction Inbound -Protocol TCP -LocalPort 4444 -Action Block
block a port
Invoke-WebRequest https://example.com -OutFile page.html
download a file (iwr)
Invoke-RestMethod https://api.github.com/users/nrodrigue2004
call a JSON API and get objects back

users & access

Get-LocalUser · Get-LocalGroupMember Administrators
local accounts and local admins
New-LocalUser bob -Password (Read-Host -AsSecureString)
create a user without typing the password in clear
Add-LocalGroupMember -Group Administrators -Member bob
add to a local group
Disable-LocalUser bob
lock an account during an incident
Get-Acl C:\share | Format-List
NTFS permissions on a path
Get-ExecutionPolicy -List
script execution policy at each scope (a guard rail, not a security boundary)
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
allow local scripts, require downloaded ones to be signed

event logs

Get-WinEvent -LogName Security -MaxEvents 50
latest Security events
Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4625; StartTime=(Get-Date).AddDays(-1)}
failed logons in the last 24 hours (fast, filtered at the source)
4624 · 4625 · 4688 · 4720 · 4732 · 1102
Security log IDs to know: logon, failed logon, process created, user created, added to a local group, log cleared
7045
System log: a new service was installed (common for malware and lateral movement)
Get-WinEvent -LogName 'Microsoft-Windows-PowerShell/Operational' | Where-Object Id -eq 4104
script block logging: the actual PowerShell code that ran

Set-ItemProperty -Path HKCU:\Software\Lab -Name Mode -Value 1
create or change a value
