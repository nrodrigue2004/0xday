numbers - Binary, hex, decimal and octal: conversions on the command line, bit tricks, ASCII and common values

SECTIONS bash and printf bc python3 dumps and encodings powers of two ascii and magic numbers

bash and printf

echo $((2#11001010))
binary to decimal (202)
echo $((16#CA))
hex to decimal
echo $((8#312))
octal to decimal
printf '%d\n' 0xCA
hex to decimal with printf (for binary input use the 2# form above)
printf '%x\n' 202
decimal to hex (lowercase; %X for uppercase)
printf '%o\n' 202
decimal to octal
printf '%08d\n' $(echo 'obase=2;202'|bc)
decimal to zero-padded 8-bit binary
echo $((0xC0A8010A & 0xFFFFFF00))
bitwise AND (mask) in bash; also | ^ ~ << >>

bc

echo 'obase=2; 202' | bc
decimal to binary
echo 'obase=16; 202' | bc
decimal to hex
echo 'ibase=2; 11001010' | bc
binary to decimal
echo 'ibase=16; CA' | bc
hex to decimal (hex digits must be uppercase in bc)
echo 'obase=2; ibase=16; CA' | bc
hex to binary in one go: obase is set first, so it is read in base 10

python3

bin(202) / hex(202) / oct(202)
decimal to '0b11001010' / '0xca' / '0o312'
int('11001010', 2)
binary string to int (use 16 for hex, 8 for octal, 0 to honor a 0x prefix)
format(202, '08b')
zero-padded 8-bit binary
format(202, '02x')
two-digit hex
bytes.fromhex('48656c6c6f')
hex string to bytes (b'Hello')
'Hello'.encode().hex()
text to hex
ord('A') / chr(65)
character to number and back
x & 0xFF, x | 0x80, x ^ 0x41, ~x & 0xFF
AND, OR, XOR, 8-bit NOT
x << 4, x >> 1
shift left (multiply by 16), shift right (divide by 2)
int.from_bytes(b'\x00\x10\x40\x00','little')
bytes to int with explicit endianness
import ipaddress; int(ipaddress.ip_address('192.168.1.10'))
IPv4 to a single 32-bit integer

dumps and encodings

xxd file
hex dump with offsets and ASCII view
xxd -p file
plain hex, no formatting
xxd -r -p hex.txt
plain hex back to bytes
xxd -b file
bytes as binary
echo -n 'Hi!' | xxd
hex of a string (-n stops echo adding a newline 0a)
od -An -tx1 file
hex bytes with od
base64 / base64 -d
encode and decode base64 (3 bytes become 4 characters)
python3 -c "import urllib.parse as u;print(u.quote('a b<'))"
