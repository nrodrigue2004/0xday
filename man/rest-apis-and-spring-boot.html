rest-apis-and-spring-boot - REST APIs & Spring Boot commands and terms

SECTIONS http methods status codes spring annotations curl and tools terms

http methods

GET
read, no body, safe to repeat
POST
create, or an action
PUT
replace a whole resource
PATCH
change part of a resource
DELETE
remove a resource

status codes

200 / 201 / 204
OK / created / ok with no body
301 / 302
redirect
400
bad request or failed validation
401
missing or invalid credentials
403
authenticated but not allowed
404
not found
409
conflict (duplicate)
429
too many requests
500 / 503
server error / unavailable

spring annotations

@SpringBootApplication
main class; starts the app
@RestController
class returns JSON
@RequestMapping("/api/x")
base path
@GetMapping @PostMapping @PutMapping @DeleteMapping
map methods to handlers
@PathVariable @RequestParam @RequestBody
read from path, query string, body
@Valid @NotBlank @Size
validate input
@Service @Repository @Component
beans Spring manages
@PreAuthorize
method-level access rule

curl and tools

curl -i URL
show status line and headers
curl -X POST -H "Content-Type: application/json" -d '{..}' URL
send JSON
curl -H "Authorization: Bearer T" URL
authenticated request
jq .
pretty-print JSON
./mvnw spring-boot:run
run the app from source

terms

REST
style of API over HTTP using resources and methods
JSON
text format for objects and lists
JWT
signed token carrying identity claims
DTO
data shape used only for the API
IDOR
using someone else's id to reach their data
CORS
browser rule for cross-site API calls
