databases-and-sql - Databases & SQL commands and terms

SECTIONS design acid postgres mysql sqlite admin and security terms

design

Primary key
uniquely identifies a row
Foreign key
column that references another table's key
Index
structure that speeds lookups at a cost to writes
Constraint
rule the database enforces (NOT NULL, UNIQUE, CHECK)
Normalization
removing duplicated data across tables
View
saved query that behaves like a table

acid

Atomicity
all steps happen or none do
Consistency
data stays valid under the rules
Isolation
simultaneous transactions do not corrupt each other
Durability
committed data survives a crash

postgres

psql -U user -d db
connect
\dt
list tables
\d table
describe a table
\du
list roles
pg_dump db > db.sql
back up a database
psql db < db.sql
restore from a dump

mysql

mysql -u user -p
connect
SHOW DATABASES;
list databases
SHOW TABLES;
list tables
DESCRIBE t;
table structure
SHOW PROCESSLIST;
running queries
mysqldump db > db.sql
back up

sqlite

sqlite3 file.db
open a database
.tables
list tables
.schema
show all definitions
.dump
export everything as SQL

admin and security

CREATE USER app WITH PASSWORD '...'
create an account
GRANT SELECT, INSERT ON t TO app
give only what is needed
REVOKE ALL ON t FROM app
take rights away
EXPLAIN ANALYZE query
show the query plan and real timing

terms

RPO / RTO
acceptable data loss / acceptable downtime
Replication
copying data to another server
Sharding
splitting data across servers
Injection
untrusted input changes the query's meaning
