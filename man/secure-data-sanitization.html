secure-data-sanitization - Secure data sanitization commands and terms

SECTIONS linux tools windows tools verification nist 800-88 summary documentation fields terms

linux tools

shred -vzn 1 /dev/sdX
overwrite a disk once, then zeros
dd if=/dev/zero of=/dev/sdX bs=1M status=progress
zero a disk
hdparm -I /dev/sdX
check if Secure Erase is supported and not frozen
hdparm --user-master u --security-set-pass p /dev/sdX
set a temporary password before secure erase
hdparm --security-erase p /dev/sdX
ATA Secure Erase
nvme format /dev/nvme0n1 -s 1
NVMe format with user-data erase
blkdiscard /dev/sdX
TRIM the entire SSD
cryptsetup luksErase /dev/sdX
destroy LUKS keyslots, making data unreadable

windows tools

cipher /w:C:\
overwrite free space on a volume
diskpart → clean all
zero a whole disk
Reset this PC → Remove everything
consumer reset, clear-level only
Manage-bde -off C:
decrypt BitLocker if required (not a wipe)

verification

sha256sum /dev/sdX
hash proves a zero or pattern fill if you know the expected value
xxd /dev/sdX | head
look at the start of the disk
photorec
try recovery on a wiped disk as a spot check

nist 800-88 summary

Clear
logical overwrite, resists simple recovery
Purge
resists laboratory recovery (secure erase, crypto erase, degauss)
Destroy
media can no longer be used (shred, disintegrate)

documentation fields

Asset tag and serial
which device
Media type
HDD, SSD, flash, tape
Method and tool
what you did exactly
Operator and date
who and when
Verification
how you confirmed it
Disposition
reused, sold, recycled

terms

Degauss
magnetic erase for HDD and tape
Crypto erase
delete the key so encrypted data is unreadable
Legal hold
data that must not be destroyed
Certificate of destruction
vendor proof listing serials destroyed
