web-sec - Web security: OWASP Top 10, Burp, HTTP and JWT quick reference

SECTIONS categories related burp attack types terms sqli xss defenses cookies jwt hashing idor and access csrf ssrf finding the spec testing

categories

A01 Broken Access Control
missing server-side authorization; IDOR, path traversal
A02 Cryptographic Failures
weak or missing encryption of data in transit or at rest
A03 Injection
untrusted input interpreted as code or query (includes XSS)
A04 Insecure Design
missing threat modeling, no abuse cases
A05 Security Misconfiguration
defaults, debug, open storage, missing headers
A06 Vulnerable Components
outdated libraries with known CVEs
A07 Auth Failures
weak login, sessions, no MFA or throttling
A08 Integrity Failures
unsigned updates, insecure deserialization, weak CI
A09 Logging Failures
no logs, no alerts, no response
A10 SSRF
server fetches attacker-chosen URLs

related

ASVS
OWASP's numbered verification checklist, three levels
CWE
catalog of weakness types (CWE-89 SQLi, CWE-79 XSS, CWE-639 IDOR)
CVE
ID for one specific vulnerability in one product
STRIDE
threat modeling mnemonic
SAST / DAST / SCA
static analysis / running-app scan / dependency scan
SBOM
software bill of materials, the component inventory

burp

Proxy > HTTP history
every request/response seen
Proxy > Intercept
hold and edit a request before it leaves
Repeater (Ctrl+R)
resend one request with edits
Intruder (Ctrl+I)
automate variations of a request
Target > Scope
which hosts you are allowed to test
Decoder
base64, URL, hex, gzip conversions
Comparer
diff two responses
Copy as curl command
turn a request into a shell command for the report

attack types

Sniper
one position, payloads one at a time
Battering ram
same payload in every position
Pitchfork
one list per position, walked in parallel
Cluster bomb
every combination of every list

terms

CA certificate
lets Burp read HTTPS by acting as the middle
Scope
the hosts and paths you may test
Baseline
the normal response you compare edits against
Collaborator
callback server that proves blind bugs

sqli

'
first probe: a quote that breaks the string
' OR '1'='1
always-true condition (lab only)
ORDER BY 3--
find column count
UNION SELECT NULL,NULL--
match column count for UNION
SLEEP(5)
time-based blind test (MySQL)
sqlmap -u URL --batch
automated testing, with permission only

xss

<script>alert(1)</script>
classic reflected probe (lab only)
"><img src=x onerror=alert(1)>
break out of an attribute (lab only)
javascript:alert(1)
URL scheme in a link
innerHTML vs textContent
innerHTML parses HTML, textContent does not

defenses

Parameterized query
value sent separately from the SQL text
Output encoding
turn <, > and & into entities for the context
CSP
header that limits which scripts may run
HttpOnly
cookie flag; JavaScript cannot read it
Least privilege DB user
limits what a SQLi can reach

cookies

Set-Cookie: sid=...; Secure; HttpOnly; SameSite=Lax
the recommended minimum flags
Max-Age=0
delete a cookie
__Host- prefix
cookie must be Secure, path / and no Domain

jwt

echo PAYLOAD | base64 -d
decode a JWT part in the shell (pad with = if needed)
alg: none
unsigned token; servers must reject it
HS256 / RS256
HMAC with shared secret / RSA signature
exp, iat, sub
expiry, issued-at, subject claims
jwt.io
decoder (use for lab tokens only, never paste a real production token)

hashing

bcrypt, scrypt, Argon2
slow password hashes; use one of these
salt
unique random value so equal passwords hash differently
pepper
secret value stored outside the database

idor and access

GET /resource/ID
try IDs you do not own, with two test accounts
Autorize (Burp)
replays requests with a low-privilege cookie
403 vs 404
404 avoids confirming that a record exists
deny by default
no rule means no access

csrf

Anti-CSRF token
unguessable value tied to the session, checked on POST
SameSite=Lax
cookie not sent on cross-site POSTs
Origin / Referer check
reject requests from foreign sites

ssrf

http://169.254.169.254/
cloud instance metadata address (block it)
IMDSv2
AWS metadata that requires a session token header
allow-list
only permit named destinations
DNS rebinding
name that flips to an internal IP after the check

finding the spec

/openapi.json
common OpenAPI document path
/swagger.json /v2/api-docs
older Swagger paths
/graphql
single GraphQL endpoint; try introspection in a lab
Postman collection
exported list of endpoints

testing

curl -H "Authorization: Bearer T" URL
send an authenticated request
curl -X PATCH -d '{"role":"admin"}' URL
mass assignment probe (lab only)
change /v3/ to /v1/
look for old, weaker versions
401 vs 403
not authenticated vs not allowed
