help-desk-ticketing-osticket - Help desk / ticketing (osTicket) commands and terms

SECTIONS ticket statuses priority windows quick fixes user accounts questions to ask terms

ticket statuses

Open
new, nobody working it yet
In progress
an agent is on it
Waiting on user
blocked until the user replies
Resolved
fix applied, awaiting confirmation
Closed
confirmed and documented

priority

P1 critical
business stopped or security incident, respond in minutes
P2 high
many users or a key person blocked
P3 normal
one user, workaround exists
P4 low
request or cosmetic

windows quick fixes

ipconfig /all
network settings
ipconfig /flushdns
clear DNS cache
sfc /scannow
repair system files
DISM /Online /Cleanup-Image /RestoreHealth
repair the component store
gpupdate /force
refresh policy
net use
mapped drives
whoami
who the session runs as
msinfo32
system summary
eventvwr.msc
event viewer

user accounts

Unlock-ADAccount -Identity user
unlock an AD account
Set-ADAccountPassword user -Reset
reset password
net user user /domain
account status

questions to ask

What exactly happens, and what do you see?
get the real symptom
When did it last work?
find the change
Does it affect others?
scope
Can you send a screenshot?
evidence
What changed recently?
updates, new software, moves

terms

SLA
agreed response and resolution times
Escalation
pass to a higher tier with context
KB
knowledge base of fixes
Root cause
the underlying reason, not the symptom
Workaround
temporary way to keep working
