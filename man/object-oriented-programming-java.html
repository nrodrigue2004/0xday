object-oriented-programming-java - Object-oriented programming (Java) commands and terms

SECTIONS class syntax visibility and modifiers core relationships object methods principles terms

class syntax

class A { }
declare a class
A a = new A();
create an object
this.x = x;
refer to the current object's field
extends
inherit from a class
implements
promise to provide an interface's methods
super(...)
call the parent constructor
@Override
tell the compiler this replaces a parent method

visibility and modifiers

private
this class only
protected
this package and subclasses
public
everywhere
static
belongs to the class, not an object
final
cannot be reassigned, overridden or extended
abstract
incomplete class or method, must be extended

core relationships

Is-a
inheritance (Admin is a User)
Has-a
composition (Car has an Engine)
Interface
contract with no state
Abstract class
partial implementation plus contract

object methods

toString()
readable description
equals(Object o)
logical equality
hashCode()
must match equals, used by HashMap
clone()
copy, best avoided

principles

Encapsulation
hide state, expose behavior
Polymorphism
one call, many behaviors
SRP
one reason to change per class
Liskov
children must honor the parent's contract
Favor composition
build by combining, not extending

terms

Instance
one object of a class
Constructor
initializes a new object
Getter / setter
read / change a private field
Immutable
cannot change after creation
Defensive copy
copy mutable data in and out
