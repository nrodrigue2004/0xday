prompts - Prompt engineering: the five parts, patterns, testing and security checks

SECTIONS structure patterns testing common failures security checks

structure

task: one verb + object
summarize, classify, rewrite, compare; one task per prompt
context: audience + data
who reads it, what the input is, what you already know
constraints: limits + exit
length, tone, 'if unsure reply NOT ENOUGH DATA'
format: exact shape
bullets, table, or JSON with named keys
example: one good answer
strongest lever for style and format
<data>...</data>
delimiters separate your instructions from the material

patterns

zero-shot
instructions only, no examples
few-shot
2 to 5 examples; cover edge cases; keep labels identical
role / audience
'you are a tier-1 SOC analyst'; changes tone, adds no knowledge
JSON only + schema
'Reply with JSON only', list keys and enum values, validate in code
step by step
ask for steps, then 'ANSWER:' on the last line
evidence quotes
require line numbers or quoted text per claim, then check them

testing

eval set
10 to 30 inputs with expected results, incl. edge and 'cannot tell' cases
one change at a time
version prompts v1, v2; log what changed and the score
hold-out cases
keep a few cases untouched until the end
run twice
sampling is random; lower temperature for checks
validate output in code
parse JSON, check enums and lengths, retry once on failure

common failures

invented facts
add the source text, allow 'unknown', require quotes
ignores a rule
move it, shorten the prompt, remove conflicting lines
chatty or too long
state a limit and exact format
label drift
enum + 'no other values' + validation
fine in tests, bad live
add messy real inputs to the eval set

security checks

secret in prompt?
remove it; enforce in code, the model can leak it
untrusted input + private data + outbound path
remove at least one of the three
tool allow-lists
destinations, paths and recipients checked in code
human approval
for send, delete, pay, run; show the real action
treat output as untrusted
escape before HTML, shell or SQL
per-user retrieval
enforce access in the query, not the prompt
injection regression set
fictional documents with planted instructions; judge the action log
