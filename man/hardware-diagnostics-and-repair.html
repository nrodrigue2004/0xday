hardware-diagnostics-and-repair - Hardware diagnostics & repair commands and terms

SECTIONS drives memory and cpu system info warning signs safety

drives

smartctl -H /dev/sda
health verdict
smartctl -a /dev/sda
full SMART attributes
smartctl -t short /dev/sda
start a short self-test
lsblk
list disks and partitions
ddrescue /dev/sda disk.img map.log
copy a failing drive, retrying bad areas
badblocks -sv /dev/sdb
read test for bad sectors (data safe in read mode)
chkdsk C: /f
check and fix a Windows volume

memory and cpu

memtester 1G 1
user-space memory test on Linux
free -h
memory in use
lscpu
CPU details
sensors
temperatures and fan speeds
stress-ng --cpu 4 --timeout 60s
load test to see if temperatures hold

system info

lspci / lsusb
list PCI and USB devices
dmidecode -t memory
RAM slots and modules
journalctl -k
kernel messages, look for I/O errors
dmesg | grep -i error
recent hardware errors
Get-PhysicalDisk
disk health in PowerShell
wmic memorychip list brief
installed RAM on older Windows

warning signs

Clicking or grinding drive
mechanical failure, copy data immediately
Rising reallocated sectors
drive is dying
Beep codes at power on
check the board manual: RAM, GPU or CPU
Shutdown at the same temperature
cooling or thermal paste
Swollen battery
stop using, handle as hazardous

safety

ESD strap
ground yourself before touching components
Unplug power
hold the power button to drain residual charge
Lithium batteries
never puncture, recycle properly
