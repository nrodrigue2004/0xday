ad-powershell - Active Directory administration with the ActiveDirectory module

users

Get-ADUser jdoe -Properties *
everything about one user
Get-ADUser -Filter 'Enabled -eq $false'
disabled accounts
Search-ADAccount -LockedOut
locked-out accounts
Unlock-ADAccount jdoe
unlock an account
Set-ADAccountPassword jdoe -Reset -NewPassword (Read-Host -AsSecureString)
reset a password
New-ADUser -Name 'Jane Doe' -SamAccountName jdoe -Path 'OU=Users,DC=lab,DC=local' -Enabled $true -AccountPassword (Read-Host -AsSecureString)
create a user

groups

Get-ADPrincipalGroupMembership jdoe | Select Name
which groups a user is in
Get-ADGroupMember 'Domain Admins' -Recursive
who is effectively a domain admin
Add-ADGroupMember 'Finance-Share-Read' -Members jdoe
add a user to a group (they must sign out and in again)
Remove-ADGroupMember 'Finance-Share-Read' -Members jdoe
remove a user

computers & OUs

Get-ADComputer -Filter * -Properties LastLogonDate
computers and when they last checked in
Get-ADOrganizationalUnit -Filter * | Select Name,DistinguishedName
OU layout
Move-ADObject (Get-ADUser jdoe).DistinguishedName -TargetPath 'OU=IT,DC=lab,DC=local'
move an object to another OU

group policy & troubleshooting

gpupdate /force
re-apply Group Policy now
gpresult /r
which GPOs applied to this user and computer
Get-GPO -All | Select DisplayName,GpoStatus
list GPOs
whoami /groups
groups in the current access token (stale until re-logon)
Test-ComputerSecureChannel -Repair
fix a broken trust relationship with the domain
