ids-snort - IDS / Snort commands and terms

SECTIONS rule header rule options running it tuning terms

rule header

alert
log an alert and continue
drop / reject
IPS only: discard (and send reset)
pass
ignore matching traffic
tcp udp icmp ip
protocol
$HOME_NET / $EXTERNAL_NET
variables for inside and outside
->
direction, source to destination (<> for both)

rule options

msg:"text"
alert message
content:"bytes"
find these bytes in the payload
content:"|0d 0a|"
match hex bytes inside pipes
nocase
case-insensitive content match
http_uri / http_header
restrict content to a URI or header
pcre:"/regex/i"
regular-expression match
flow:to_server,established
only requests in an established session
threshold:type both,track by_src,count 5,seconds 60
rate-based firing
sid:1000001
unique rule ID, 1000000+ for local rules
rev:2
revision number, bump on edits
classtype:web-application-attack
category

running it

snort -T -c /etc/snort/snort.conf
test the config
snort -A console -q -c snort.conf -i eth0
live alerts to the console
snort -r file.pcap -c snort.conf -A alert_fast
run rules over a capture
suricata -T -c /etc/suricata/suricata.yaml
test the config
suricata -r file.pcap -l ./out
process a capture
tail -f /var/log/snort/alert
watch alerts arrive

tuning

suppress gen_id 1, sig_id 2100498, track by_src, ip 10.0.0.5
silence one rule for one host
event_filter gen_id 1, sig_id 2100498, type limit, track by_src, count 1, seconds 60
cap alert rate

terms

IDS / IPS
detect only / detect and block
True positive
alert on real malicious traffic
False positive
alert on harmless traffic
False negative
missed attack, the worst kind
Preprocessor
decodes protocols before rules run
