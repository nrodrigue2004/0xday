./ossim

~/ossim operating-system simulators

Three small tools for CS220. Do the problem by hand first, then check yourself here. Everything runs in your browser.

CPU scheduler

One process per line: name arrival burst [priority], whole numbers. Lower priority number runs first. Load the 24/3/3 example and compare FCFS (average wait 17) with SJF (3) and round robin.

Page replacement

Reference string of page numbers, and how many frames. FIFO, LRU and optimal run side by side. The Belady button loads the classic string where FIFO gets worse from 3 to 4 frames.

Deadlock avoidance: Banker's algorithm

One row per process. Enter the allocation matrix, the max-demand matrix and the available vector. The tool computes need, looks for a safe sequence, and can test a request (process r1 r2 r3, e.g. 1 1 0 2).
