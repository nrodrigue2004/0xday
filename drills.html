~/drills

Short, focused practice: each drill teaches one skill at three depths (simple, mid, complex) and ends with a hands-on lab on realistic but made-up data. Addresses come from the documentation ranges, domains end in .example, and nothing here touches a real system.

# drills

  • [----]read a packet capture Text captures line by line: handshakes, scans, uploads. Lab: find who got the datashell
  • [----]Linux permissions ls -l, chmod, SUID, cron. Lab: the writable file root runsshell
  • [----]Windows permissions NTFS, shares, inheritance, nested groups. Lab ticket: why can the intern see Payrollticket
  • [----]regex for logs Patterns from zero, encodings and false hits. Lab: count path traversal attemptsshell
  • [----]parse logs with pipes Narrow, extract, count on key=value logs. Lab: the one outside admin loginshell
  • [----]Security Onion intrusion hunt A night of fictional alerts, conn and DNS logs. Lab ticket: which host is beaconing, and to whereticket
  • [----]password hygiene audit Reuse, MFA and SSH keys on a made-up lab. Lab: the one password protecting too muchshell
