ai --chat

~/ai/chat

A study assistant for this site. It searches the guides, Security+ notes, flashcards, glossary and cheatsheets, and answers with links to the pages it used. It runs in your browser: no server, no API key, no tracking.

Read this first. Search mode quotes the site and never invents anything, but it matches words, not meaning, so it can pull the wrong passage. Local model mode writes sentences and can be wrong and sound sure. Verify anything that matters against the linked page or official docs. How it works: ~/ai/ai-chatbot.

ghost-ai@0xday [search]
advanced: local model (off, optional download)

Runs a small language model on your own graphics card through WebGPU and uses the passages found by search as its source. Your questions never leave the tab. Requires a recent Chrome or Edge on desktop. It loads a library from jsDelivr and the weights from Hugging Face, which are third-party hosts, and it caches the weights in your browser storage. Small models are weak: expect basic rewording of the search results, not deep reasoning.

Why no hosted model like Claude or GPT? A static site can't keep an API key secret; anything in the page is public. A hosted model needs a small server in the middle to hold the key. See how it works.
