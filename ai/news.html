This is a curated reading list, not a live feed. The site is static, so I add links by hand. Dates are when the item was published or the event happened; check each source for anything newer. Last curated 2026-11-07.

# primary sources to follow

Check these directly for current news. No dates because they update continuously.

  • ongoing OWASP GenAI Security Project: LLM Top 10OWASP

    The standard list of LLM application risks. Start here.

  • ongoing MITRE ATLASMITRE

    ATT&CK-style matrix of attacks on AI systems, with case studies.

  • ongoing NIST AI Risk Management FrameworkNIST

    Governance-level guidance. Useful vocabulary for interviews.

  • ongoing NIST AI 100-2: Adversarial Machine Learning taxonomyNIST

    Names and classifies attacks on ML systems and their mitigations.

  • ongoing CISA: Artificial IntelligenceCISA

    US government guidance on secure AI use and deployment.

  • ongoing Simon Willison on prompt injectionsimonwillison.net

    Running, readable record of real prompt injection cases.

  • ongoing FIRST EPSSFIRST

    A model that scores how likely a CVE is to be exploited. A good example of useful boring ML.
