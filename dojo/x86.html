~/dojo/x86 9 katas

Raw 32-bit x86, the dialect Ghidra and IDA show you. Each kata is a routine: the harness loads registers and memory, calls your code, and checks the result when you ret.

[runs in your browser] runtime: 32-bit x86 emulator (Intel syntax, NASM-style) written for this site

Supported: mov movzx movsx lea xchg add sub adc sbb inc dec neg not and or xor test cmp shl shr sar rol ror imul mul div idiv cdq push pop call ret jmp, every jcc, and loop. Registers eax-edi plus ax/al/ah style parts. Memory is a 64 KiB sandbox; size memory operands with byte/word/dword when the register doesn't say. Comments start with ;.

0/9 solved

  1. The harness puts two numbers in ecx and edx. Return their sum in eax. Every routine ends with ret.

  2. Return the larger of ecx and edx in eax, treating both as signed 32-bit numbers. That decides which conditional jump you need: jg/jl are signed, ja/jb are unsigned.

  3. Return ecx! in eax (with 0! = 1). Inputs stay small enough to fit in 32 bits.

  4. esi points at a NUL-terminated string. Return its length in eax. Read one byte at a time with byte [esi + eax] or by walking esi.

  5. esi points at an array of ecx signed 32-bit integers. Return their sum in eax. Remember each element is 4 bytes, so use a scaled index like [esi + edx*4]. Try the loop instruction.

  6. esi points at a NUL-terminated ASCII string. Uppercase every a-z in place (other bytes stay). Return the number of letters you changed in eax. Lowercase and uppercase differ by exactly one bit, 0x20.

  7. The classic malware string decryptor. esi points at ecx encrypted bytes and dl holds a one-byte key. XOR every byte with the key in place. Then return the first decrypted byte in eax (zero-extended) so the caller can sanity-check it.

  8. Return the number of 1 bits in ecx in eax. Same problem as the C kata, now with shr and the carry flag, or the x & (x - 1) trick.

  9. Convert the unsigned number in eax to decimal ASCII at edi, NUL-terminated, and return the number of digits in eax. div ecx divides edx:eax by ecx (quotient in eax, remainder in edx), so zero edx before every divide. Digits come out backwards; the stack is a handy way to flip them.

Keys inside the editor: Tab indents, Ctrl+Enter runs the tests, Esc leaves the editor. Progress is saved in this browser only.
