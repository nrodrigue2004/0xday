~/dojo/javascript 7 katas

Modern JavaScript for the web side of security: parsing what a browser sends, decoding tokens, and async code that has to survive flaky networks.

[runs in your browser] runtime: your browser's own JS engine, inside a Web Worker

0/7 solved

  1. Write isIPv4(s) that returns true for a dotted-quad address: exactly four parts, each a decimal number 0-255, no leading zeros (so "01" is invalid but "0" is fine), no signs or spaces.

  2. Write parseQuery(qs) for strings like "?q=sql%20injection&tag=web&tag=sec". Return an object mapping each key to an array of values in order. Strip a leading ?, decode with decodeURIComponent, and treat + as a space. A key with no = gets the value "".

  3. Write groupBy(items, keyFn) that returns an object whose keys are keyFn(item) and whose values are arrays of the items with that key, in their original order. Don't use Object.groupBy.

  4. Write flatten(arr, depth = Infinity) that flattens nested arrays up to depth levels, like Array.prototype.flat (which you can't use here).

  5. A JWT is three base64url chunks joined by dots: header.payload.signature. Write decodeJwt(token) that returns { header, payload } as parsed objects. base64url uses - and _ instead of + and /, and drops the = padding. Throw an Error if there aren't three parts. (Decoding is not verifying. Never trust a payload you didn't check the signature on.)

  6. Write async retry(fn, attempts, delayMs) that calls the async function fn. If it rejects, wait delayMs, double the delay, and try again, up to attempts calls total. Resolve with the first success; if every attempt fails, reject with the last error.

  7. Build class Emitter with on(event, fn), off(event, fn), once(event, fn) and emit(event, ...args). emit calls listeners in the order they were added and returns how many it called. once listeners fire one time. off must also remove a once listener if you pass the original function. A listener that calls off on itself mid-emit must not make others get skipped.

Keys inside the editor: Tab indents, Ctrl+Enter runs the tests, Esc leaves the editor. Progress is saved in this browser only.
