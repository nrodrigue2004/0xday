~/dojo/c 12 katas

Pointers, bytes and bit twiddling: the C you need to read malware and write exploits. Each kata is one function; the test harness calls it.

[runs in your browser] runtime: picoc (a C interpreter) compiled to WebAssembly; every kata also exports a gcc self-test

The in-browser runtime is picoc, so a few corners of C aren't there: function pointers, pointer subtraction, anonymous structs, and several fields declared on one line inside a struct. The katas stay clear of them. Use [ self-test ] to run the exact same tests under gcc.

0/12 solved

  1. Write int popcount(unsigned int x) that returns how many bits are 1 in x. No builtins like __builtin_popcount.

  2. Write int my_strlen(char *s) that counts characters up to (not including) the NUL terminator. Walk the string with a pointer, no <string.h>.

  3. Write void reverse(char *s) that reverses the string in its own buffer, no second buffer. Swap from both ends toward the middle.

  4. x86 is little-endian, network byte order is big-endian. Write unsigned int bswap32(unsigned int x) that reverses the byte order: 0x12345678 becomes 0x78563412. Shifts and masks only.

  5. Write int is_palindrome(char *s) that returns 1 if s reads the same both ways when you skip anything that isn't a letter or digit and ignore case, else 0. "A man, a plan, a canal: Panama" is a palindrome.

  6. Write unsigned int ip_to_u32(char *ip) that turns dotted-quad text like "192.168.1.10" into 0xC0A8010A. Parse the digits yourself (no inet_aton, no sscanf). Return 0xFFFFFFFF if there aren't exactly four parts or any part is over 255.

  7. zlib uses Adler-32. Keep two 16-bit sums mod 65521: a starts at 1 and adds each byte, b starts at 0 and adds a after every byte. The result is (b << 16) | a. Write unsigned int adler32(char *data, int len). Treat bytes as unsigned.

  8. Write int my_atoi(char *s): skip leading spaces, accept one optional + or -, then read digits until the first non-digit. No digits means 0. You don't need to handle overflow.

  9. Write unsigned int crc32(char *data, int len) for the standard CRC-32 used by zip, PNG and Ethernet. Start with crc = 0xFFFFFFFF. For each byte, XOR it into the low byte of crc, then 8 times: if the low bit is set, crc = (crc >> 1) ^ 0xEDB88320, else crc >>= 1. Return ~crc at the end.

  10. Write int balanced(char *s) that returns 1 if every (, [ and { is closed by the matching bracket in the right order, else 0. Ignore other characters. Inputs are under 256 characters, so a fixed-size array works as the stack.

  11. Given struct node { int v; struct node *next; };, write struct node *reverse_list(struct node *head) that reverses the list by relinking the nodes (no new allocations) and returns the new head. The harness builds lists with malloc and prints them as "1>2>3".

  12. Write void b64(unsigned char *in, int len, char *out) that writes the Base64 encoding of len bytes into out (with = padding) and NUL-terminates it. The caller guarantees out is big enough.

Keys inside the editor: Tab indents, Ctrl+Enter runs the tests, Esc leaves the editor. Progress is saved in this browser only.
