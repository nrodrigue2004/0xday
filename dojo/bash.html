Shell one-liners and functions for the box you just landed on. Write the function here, copy the self-test, run it in a real terminal, and paste the output back.

[runs in your own shell] runtime: your own bash 4+ (Linux, macOS with brew bash, WSL, or the Kali box)

0/7 solved

  1. Write a function count_lines that reads stdin and prints how many lines it got, as a bare number with no padding.

  2. Write shout that prints its first argument in upper case followed by !. Use bash parameter expansion, not tr or awk.

  3. Write is_ipv4 that returns exit code 0 if $1 is a valid dotted-quad (four parts, each 0-255) and 1 otherwise. Print nothing. Tests call it like is_ipv4 10.0.0.1 && echo yes || echo no.

  4. Write top_ip that reads web access log lines on stdin (the client IP is the first field) and prints the single most frequent IP. Ties go to the IP that sorts first. The classic cut | sort | uniq -c | sort pipeline.

  5. Write rev_words that prints its arguments in reverse order on one line, separated by single spaces. Use a bash array, no tac or rev.

  6. Write parse_conf that reads key = value lines from stdin into an associative array, then prints them as key=value, sorted by key. Skip blank lines and # comments, trim spaces around keys and values, and let a later duplicate key win.

  7. Write failed_report that reads auth.log lines on stdin and prints the top 3 source IPs for Failed password lines as COUNT IP, highest count first, ties broken by IP. The IP is the field after the word from (careful: invalid user lines have extra words).
