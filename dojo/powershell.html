~/dojo/powershell 5 katas

The Windows admin side: objects down the pipeline, hashtables, and the kind of quick triage you run on a domain controller. Write the function here, copy the self-test, run it, paste the output back.

[runs in your own shell] runtime: your own PowerShell 7 (pwsh) or Windows PowerShell 5.1

0/5 solved

  1. Write an advanced function Get-Square with a mandatory [int] parameter -Number that outputs its square. Tests call it both by name (Get-Square -Number 4) and positionally (Get-Square 4).

  2. Write Get-Initials that takes a full name string and outputs the upper-case initials, e.g. "ada lovelace" gives AL. Extra spaces between names don't count.

  3. Write ConvertFrom-Kv that turns a string like "host=dc01; port=389; tls=true" into a hashtable. Pairs are separated by ;, keys and values are trimmed, and empty pairs are skipped. Values stay strings.

  4. Write Get-TopMemory that takes an array of process-like objects (each has Name and MemMB) and outputs the names of the -Top heaviest ones (default 3), biggest first. Ties go to the name that sorts first.

  5. Write Get-SubnetHosts that takes a CIDR like "192.168.1.0/30" and outputs every usable host address (network and broadcast excluded), one per line, for prefixes /24 to /30. Do the math on a 32-bit number, not by string-poking the last octet.

Keys inside the editor: Tab indents, Ctrl+Enter runs the tests, Esc leaves the editor. Progress is saved in this browser only.
