~/dojo/python 11 katas

Scripting, parsing and a bit of crypto, the Python I actually reach for during labs and CTFs. Stdlib only, and no importing your way out of the interesting part.

[runs in your browser] runtime: CPython 3.12 compiled to WebAssembly (Pyodide), standard library included

0/11 solved

  1. Write caesar(text, k) that shifts every letter k places through the alphabet, wrapping from z back to a. Keep the case of each letter and leave everything else (digits, spaces, punctuation) untouched. k can be negative or bigger than 26.

  2. Scanners take port specs like 22,80,8000-8003. Write expand_ports(spec) that returns a sorted list of unique port numbers. Ignore spaces. Ranges are inclusive.

  3. A config dump leaked sha256(pin) for a 4-digit PIN (leading zeros allowed, so 0042 is valid). Write crack_pin(hexdigest) that returns the PIN as a 4-character string, or None if no 4-digit PIN matches.

  4. Write failed_by_ip(lines) that takes auth.log lines and returns a dict of {ip: count} for lines containing Failed password. The IP is the word right after from. Ignore everything else.

    Nov  7 03:12:01 lab sshd[811]: Failed password for root from 10.0.0.5 port 50122 ssh2
Nov  7 03:12:04 lab sshd[811]: Failed password for invalid user admin from 10.0.0.5 port 50124 ssh2
Nov  7 03:13:00 lab sshd[815]: Accepted password for nate from 10.0.0.9 port 50200 ssh2

  5. Write rle_encode(s) that turns "aaabccdddd" into "3a1b2c4d", and rle_decode(s) that reverses it. Counts can be more than one digit ("12x" is twelve x's). Input to encode is letters only.

  6. Malware loves single- and multi-byte XOR to hide strings. Write xor_bytes(data, key) that XORs each byte of data with the key, repeating the key as needed. Both arguments are bytes; return bytes.

  7. Write in_cidr(ip, cidr) that returns True if the IPv4 address is inside the network, e.g. in_cidr("10.0.5.9", "10.0.0.0/16"). Do it with bit math. The ipaddress module is off limits for this one.

  8. Packed or encrypted sections of a binary have high entropy. Write entropy(data) that returns the Shannon entropy of a bytes object in bits per byte (0.0 to 8.0), rounded to 3 decimals. Empty input is 0.0.

    The formula: for each byte value with probability p, add -p * log2(p).

  9. Write b64encode(data) that returns the standard Base64 string for bytes, with = padding, without importing base64 or binascii. Every 3 input bytes become 4 output characters of 6 bits each.

  10. Build class LRU with LRU(capacity), get(key) (returns the value or -1) and put(key, value). When it's full, put evicts the least recently used key. Both a get and a put count as a use. Aim for O(1) per operation.

  11. Write calc(expr) that evaluates integer arithmetic with + - * /, parentheses and unary minus, using normal precedence. / is integer division that truncates toward zero, like C. Spaces can appear anywhere. No eval(), exec() or ast allowed. Raise ValueError on garbage like "2 +".

    A recursive-descent parser is the classic approach:

    expr   := term (('+' | '-') term)*
term   := factor (('*' | '/') factor)*
factor := '-' factor | NUMBER | '(' expr ')'

Keys inside the editor: Tab indents, Ctrl+Enter runs the tests, Esc leaves the editor. Progress is saved in this browser only.
