~/dojo/java 6 katas

Java, the language I built JavaShooter in. These run on a real JVM: write your class here, copy the self-test, and launch it with java Main.java. Paste the output back to log the belt.

[runs in your own shell] runtime: your own JDK 11+ (single-file launch, no build step)

0/6 solved

  1. Write static String reverseWords(String s) in class Kata that reverses the order of words. Words are separated by one or more spaces; the result uses single spaces and no leading or trailing space.

  2. Write static boolean isAnagram(String a, String b): true if the two strings use exactly the same letters the same number of times, ignoring case and spaces.

  3. Write static int indexOf(int[] sorted, int target) that returns the index of target in an ascending array, or -1. O(log n), no Arrays.binarySearch. Watch the midpoint overflow trap.

  4. Write static int[][] transpose(int[][] m) that returns a new matrix with rows and columns swapped. The input is rectangular (not necessarily square).

  5. Write static int rpn(String expr) that evaluates Reverse Polish Notation like "3 4 + 2 *" (which is 14). Tokens are integers (possibly negative, like -3) and + - * /, separated by spaces. / is integer division. Throw IllegalArgumentException if the expression is malformed.

  6. Write static int[][] merge(int[][] intervals): given [start, end] pairs in any order, merge every overlapping or touching pair ([1,3] and [3,5] touch) and return the result sorted by start. Useful for collapsing port ranges or IP ranges from a scan.
